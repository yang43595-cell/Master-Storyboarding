# 业务项目目录

本文件是项目规则的职责细则；适用范围及默认流程以 [项目总规则](../../PROJECT_RULES.md) 为准。只在本轮职责或明确选用的分支内读取。

## 项目目录按生产流程排列

新项目由 `scripts/init_desktop_project.py` 创建下列目录。各 Skill 交付写入对应目录，产物清单中的路径相对项目根目录；读取以登记路径为准。

| 目录 | 内容 |
| --- | --- |
| `00_项目管理` | 需求、状态、产物登记、确认记录、执行上下文 |
| `01_原始资料` | 原片、原始文案、校对转写、真实参考和证据抽帧 |
| `02_编导` | 编导稿、最终对白、故事正文、叙事包及独立资产需求表 |
| `03_导演` | 导演镜头方案及对应结构化导演包 |
| `04_资产` | Web 选用及制作的候选、母版、视觉资产清单；正式导出放 `母版/` |
| `05_分镜` | 分镜制作文档、候选图与正式分镜图 |
| `06_视频` | 视频提示词及执行文档、生成片段；下载片段放 `片段/` |
| `07_声音与配音` | 声音参考清单、声音母版与配音 |
| `99_历史与废弃` | 有追溯价值的旧版本和试验记录 |

编号仅用于文件归属，不增加串行门禁：资产可按既有规则与导演并行，声音和分镜按需执行。旧项目按已登记路径继续读取；迁移同步路径引用，保留确认正文和必要迁移记录，不重新初始化已有项目。
