# 执行分工与自查

本文件是项目规则的职责细则；适用范围及默认流程以 [项目总规则](../../PROJECT_RULES.md) 为准。只在本轮职责或明确选用的分支内读取。

## Skill 执行分工

### 创作执行开始前：干净上下文

- 新一轮编导生产或实质重跑，必须由全新、专属的生产 agent 执行，不继承长主会话。导演稿、视频提示词等创作阶段的新轮同理；多案例分别执行，不把其他案例的草稿或推测带入本轮。主对话负责范围协调、澄清和结果检查，不边聊边直接写完整生产稿。
- 只交接当前有效项目规则与目标 Skill 入口、可实际读取的原始素材、适用于本轮的用户约束与已确认决定（保留准确依据）、现行版本与未决事项，以及本轮目标、范围和停止点。排除废弃候选、失效推测及无关讨论；干净上下文不等于丢弃有效决定，也不能只传摘要替代原片、原文或真实参考。
- 专属 agent 是本轮生产执行者，负责必要资料与方法阅读、来源核对、适用的准备流程、候选写作和自查；不因新开 agent 跳过现行 Skill、对白核对、来源或确认门禁。同一轮的逐段推进、局部返修和工具调用可继续原执行者，不为每段或每次调用重新开 agent；目标、来源或执行基线发生重大变化时重新开一轮。
- 普通查问、只读检索、纯错字/排版维护不因此要求新 agent。此规则只用宿主已有委派能力，不新增多 agent 运行时、审批层或交接格式，也不构成创建本地 Codex、切换电脑或突破用户指定执行环境的授权。无法实际创建干净上下文 agent 时如实说明限制，暂停该轮生产，不用当前主会话续写冒充独立执行。

### 图片生产批次

- 资产图和按需分镜的图片生产，由协调方直接创建**干净上下文的专属图片子 agent**，不继承长主会话。委派的是完整闭环：实际读取本批输入、适用方法与原参考，编写和自查提示词，在已有授权内生成，实看准确成图并作必要修正，独占落盘，再交回准确身份、用途和自查结果；不只把一次生图工具调用外包。图片执行者不再递归派发生图子 agent。无法创建这种执行者时报告真实缺口，不由长主会话顶替。
- **每个图片执行者只承接一批、最多 8 张目标图**，无需凑满，新批次另建干净执行者。同批同目标的返修沿用原执行者和目标身份，生成新文件版本；不得追加第 9 张目标或把换一个任务名当成清空上下文。批次上限不改变单请求 `max_images`、单状态候选数、四格／四视图的生产规范、工具并发限制或费用授权，也不表示无限返修许可。工具失败或结果未知不自动重提；视觉问题可在本轮已有授权与既定目标内修正，需改上游、增加目标或扩展授权时退回阶段负责人。
- 阶段负责人按角色、场景、服装、状态和实际参考依赖分组并固定准确来源。基础母图或共同设计须先确定，依赖它的后续批次再启动；仅已具备各自有效参考且互不等待的批次可并行。关联状态图、机位图及跨镜不变量沿现有方法一起核对，不按张数机械打断连续性，也不拿失败图串联垫图。
- 每批使用自己的真实执行者／任务身份和本批输入证据，不能继承阶段负责人或其他批次的阅读声明。普通对话按[共享读取入口](../../skills/_shared/knowledge-access.md)隔离准备目录，资产 Web 继续使用本次 task-package 的受限读取流程，不叠加普通 prepare。网页已经一图一独立会话的制作项可继续保持，不为批量上限合并上下文。
- 阶段负责人先分配互不覆盖的目标身份和候选路径。图片执行者只写独占分配的本批候选、提示词及现有制作／请求记录，不并发改整份 manifest、当前资产清单、阶段状态或其他批次记录；多个批次共用一个记录文件时，由阶段负责人接收准确内容与定位后统一写入。共享登记、正式采用、网站送审及最终阶段状态由阶段负责人核对后统一更新；已确认文件始终保留，返修另存新版本。
- 图片执行者交回文件夹绝对路径、准确文件名、AST/output 或 artifact/请求与镜号身份、revision/字节依据、实际参考及用途、自查可见事实、修正结果和未满足项。证据沿现有候选、制作／审核备注、请求、`quality_evidence` 与采用记录保存，不新增平行 QA 账本。后续从登记身份定位目录中的准确文件，不能按“最新图”或整个文件夹猜选。
- 本批实看与自查由图片执行者负责；跨批相关图需要合看时，阶段负责人明确交给能读取这些准确图和来源的图片执行者，记录实际范围。主协调方核目标覆盖、依赖和回执，不默认重复加载全量图片；下游仍按当前用途实看适用图，不冒称自己做过上游观察。**资产图仍走网站准确版本人审，分镜图仍按本轮入口自主验收或兼容人工路径处理。** 批次自查不代替网站人审、全片复核或合法采用，不自动进入下一阶段。

### 本轮执行与自查

- 上述创作轮由专属生产 agent 直接完成本 Skill 工作；图片生产按图片批次委派。其他任务默认由当前执行者完成，只有用户明确要求或独立子任务有清楚的并行收益时才委派。生产执行者不递归为同一轮再派生产 agent；图片批次由协调方直接分派。
- 除上述创作轮与图片批次的生产委派外，可委派范围仍限于只读检索与整理、隔离组件开发、不写真源的有界候选分析、对已完成结果的独立检查。生产 agent 按已交接的目标与整体创意方向写本轮候选，主对话检查结果；候选分析只交建议、依据与影响，由生产执行者选择并写回。**不得把目标解释或整体创意方向的最终决定、同一份核心稿的并发改写、费用与账户授权、用户最终审批或发布委派出去**；阶段负责人保留阶段依赖、完整验收与正式采用责任，不各自持有互相冲突的当前状态。
- 确定性步骤不再套一层模型：能由脚本或现有 CLI 完成的校验、转换、下载、转写、渲染、打包、巡检直接执行，不把子 agent 当调度器。除上述干净上下文生产轮与图片批次外，只为真正需要独立判断的边界任务增加 agent，不为了看起来更工程化而扩编制。
- 本项目的生产、维护及子任务协调均执行[等待与工具回传](../../docs/development/token-budget.md#等待与工具回传)：不人为过早返回制造二次等待，不在无新问题时叠加进度查询；先筛选再回传，不依赖截断处理大结果。首次必读原文、必要视觉核验与及时沟通仍按各自要求执行。
- 本轮生产执行者完成创作、自查、修改和复核；新开生产 agent 不使其成为独立审核者。只有用户明确要求独立审核时才启动独立审核，不因初稿、重要修改或提交前检查自动另派审核 agent。
- 整稿交付、重大改动或反复出错时，可向用户建议独立审核；建议不是授权，不据此自动派发或阻塞阶段。日常小改仍在当前生产对话自查。
- 自查对照当前原始证据和既定验收要求，检查正文、镜头/对白承载、时长与素材决定的一致性；不能只看程序通过。发现问题由当前执行者修改候选，再检查改动及直接影响；已确认产物仍须新版本，不原地覆盖。来源或授权缺口仍报告并暂停相关执行，不自行补造事实。
- 自查复用本执行者仍有效的材料；图片批次在图片执行者中自查，不为模拟两个角色另建 review-pack、reviewer 身份、producer-response 或重复交接文件。必要的问题与修复证据记在现有任务记录，明确结论为“自查”，不冒充独立审核。技术检查、用户确认和付费授权边界不变。
- 用户明确要求独立审核时，才按 [审核方法](../../skills/stage-reviewer/modules/review-method.md) 向独立审核者交当前候选、准确来源和验收范围；返修仍由当前执行者完成，必要复审回原审核者。此时文件是交接事实源，只传路径、未决 ID、实际改动及直接影响，不传完整对话或全部历史。
- 用户确认、付费或提交的明确授权，以及不覆盖已确认产物的边界仍然生效；兼容人工流程需用户确认并明确要求继续；默认统一入口按网站准确通过回执及既有自主执行授权流转，不要求重复确认。



## 逐场创作与全片复核

以下创作安排适用于默认统一入口及兼容人工流程；确认方式仍按项目总规则选择，不把创作段落等同于停等用户的节点。

导演稿与视频提示词默认按创作段落逐段写作、自查；用户明确要求整稿交付时可整稿完成。创作段落按场景、时空转换或完整剧情阶段划分，短且完整的戏可整段完成；不按固定秒数或镜头数切割，不截断连续动作。同一场景可含多个创作段落，但不新增或改写上游场景、故事、对白编号。创作段落不同于生成片段，生成分段仍按视频 Skill 的模型承载能力与现行优先级。

顺序为：全片统筹 → 逐段完善导演稿并按所选流程验收 → 全片导演稿复核及结构化 → 按需检查分镜素材 → 逐段完善视频提示词并按所选流程验收 → 全片提示词复核。导演全片未完成并正式交接前，不进入正式提示词阶段。统一入口逐段自查后继续，不停等逐段人审；兼容人工流程才按准确段落确认后继续。

- 全片统筹写在现有导演 JSON 内，记录各创作段落的作用、情绪走向、来源范围及前后衔接；统筹不代表各段拍法已经完成或确认。
- 每轮完成当前完整创作段落，说明本轮范围、已完成与待完成部分，核当前段及跨段依赖；尚未细写的后段不宣称已检查。
- 全部段落完成且按所选流程验收后，核全片对白、镜头覆盖、节奏及衔接，再校验完整 JSON 并按现有合同登记。视频提示词同样做全片复核，不能以逐段自查替代。
- 追加内容不改变已确认范围；需改动已确认内容时另作修订，重查直接影响并重新取得相应范围依据。不默认新增逐段副本、任务表或局部导演包；结构化与正式交接要求全片完整。

人工确认的准确范围及机器字段见 [确认范围](artifacts.md#确认范围)，兼容停等步骤只在明确选用时读取 [兼容流程](legacy-review.md#逐场创作与确认)。
