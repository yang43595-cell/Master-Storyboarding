使用宿主子 agent：一组 `fork_turns=none`，另一组 `fork_turns=all` 继承本轮完整父会话（含旧规则和此前修改历史）。两组均从当前磁盘 AGENTS 入口重新读取，没有直接提供期望的细则路径与答案。任务只判断路由与停止点，不执行虚拟业务。

| 场景 | 两组实际判断 |

## 本轮发现与修复

1. **通用逐场要求误放兼容文件。** 原先默认 prepare 排除 legacy，却把全片统筹、创作分段、完整导演先于提示词、整稿复核及确认范围一同放在其中。现将通用创作要求放回 execution，确认字段放回 artifacts；兼容文件只保留人工逐段停等及导演网页审核步骤，默认 Skill 链接同步调整。新增回归确保默认依赖中确有这些要求。
2. **跨文件方位词及旧标题。** 兼容细则中的“上节”改明确链接；资产及共享入口的旧主文件标题改实际正文定位，普通 PROP 例外保持。链接无断裂，共享产品约束没有因此给所有阶段加视觉细则。
3. **资产 Web 单项裁剪仍指旧主文件章节。** 裁剪映射改到迁移后文件，单项写词不带无关采用／导演流程，资产调整与通用约束保留；批量包仍保留全文。新增实际组包检查。
4. **恢复时细则不够显眼。** 总规则明确长会话、压缩和恢复后的重读入口；普通阶段启动包展示本轮实际冻结的细则准确路径。原文已不在上下文时须补读，不以阅读登记或旧摘要替代。视频与资产 Web 继续各自读取方式，不恢复退役 prepare。

独立语义对照使用 HEAD 的原 PROJECT_RULES 与当前总规则、细则和加载入口；未发现剩余阻塞性遗漏。它是本轮覆盖范围内的审查结论，不是所有未来任务零遗漏的保证。
