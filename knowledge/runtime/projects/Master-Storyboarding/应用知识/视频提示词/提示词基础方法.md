# 提示词基础方法

## 适用条件

仅用于 `voiceover-to-video-script` 的明确视频提示词任务，输入为已确认导演包和真实素材清单。执行流程、输入确认、平台参数、CLI 与授权要求见 [项目 Skill](C:/Users/LIUYANG/Documents/Master-Storyboarding/skills/voiceover-to-video-script/SKILL.md) 及其本地合同。

## 组织整份提示词

按“内容设定 → 素材职责 → 整体基调 → 事件与镜头结构”审阅。内容设定写事件、地点/时间和可观察拍摄条件；整体基调只写跨段基线；事件结构写状态变化、下一步行为和切换条件。素材职责的具体做法见 [[projects/Master-Storyboarding/应用知识/视频提示词/素材职责与引用方法]]。

## 写单段正文

按“开场真实状态 → 主体与身份 → 空间关系 → 动作顺序 → 原导演镜头要求 → 声音策略 → 必要约束 → 可观察完成条件”表达，让人能依次核对：开始时是什么、谁在何处、接着发生什么、镜头怎样表现、声音怎样进入、怎样算完成。

事件状态、动作顺序和切换条件来自已确认的 `storyboard.package`。动作与声音表达已有导演决定和声音策略；不新增、改写或补全镜头、对白、调度和切点。缺口返回导演阶段处理，不能靠提示词补齐。

## 细化表达，不补导演决定

“紧张、缓慢、自然、电影感”等概括词只能根据已确认导演包中的可观察证据展开。例如，已确认的起始姿态、动作方向、空间关系、镜头要求、声音安排或状态变化可以写得更明确；没有证据时保留原有概括程度，并记录需要导演确认的缺口。

对白、动作、静止和转场的先后或同时关系同样要有来源依据。动作确实由台词触发时，说明已确认的触发关系；没有这种依据时，不假定口型同步、动作时机或声画重叠。

不得为了让画面“更自然”补写微表情、伴随动作、隐藏动机、摄影机变化、切点、转场、资产或产品使用步骤。人物表演、镜头设计、产品事实和资产制作分别回到其上游事实源处理。

## 检查与适用限制

逐段对照上述顺序，检查是否把原导演决定完整表达，并能观察到本段完成状态。正文必须自包含，不能只写内部编号、文件路径或“见导演包”来代替镜头、动作、声音和状态。具体文件、产品参考、对白和声音来源检查见素材方法；离线检查能验证来源、文件、链接和现有合同，不能证明模型一定按文字生成。

这套顺序是项目写作约定，不是即梦或其他平台的官方模板，尚未通过同模型、同素材、同参数 A/B 生成证明效果最优。“动作不拆细更自然”也仍是假设，不能据此改写已确认动作。具体模型的字段、输入限制和能力以已核实的本地技术合同为准；模型名、时长、输入上限和参数在提交前核对当前 CLI/官方文档，不把写作顺序当作平台参数。
