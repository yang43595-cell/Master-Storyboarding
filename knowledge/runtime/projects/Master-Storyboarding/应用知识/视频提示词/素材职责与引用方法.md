# 素材职责与引用方法

## 适用条件

仅用于 `voiceover-to-video-script` 的明确视频提示词任务，输入为已确认导演包和真实素材清单。与 [[projects/Master-Storyboarding/应用知识/视频提示词/提示词基础方法]] 配合使用；确认、上传字段和授权要求见 [项目 Skill](C:/Users/LIUYANG/Documents/Master-Storyboarding/skills/voiceover-to-video-script/SKILL.md) 及其本地合同。

## 登记素材证据

写稿时逐项登记拟上传的准确文件、项目确认状态、来源路径和它要解决的可观察问题；平台操作后在同一映射核实际上传和原生身份，不把计划写成已执行。缺文件、缺确认或缺原镜头依据时记录缺口；提示词不能补造资产、产品结构、授权声音或事实。素材编号须对应本段选中文件，并在操作后核实传入关系，不以编号代替正文中的具体描述。

## 分配主职责

每个 `@素材` 明确一个主职责，可以附带有依据且相容的用途；把实际继承范围合写一处，存在串用风险或边界不清时补充不得借用的内容：

| 素材 | 主职责 |
|---|---|
| 人物 | 身份 |
| 场景 | 空间与光向 |
| 已有动作或白模参考 | 姿态路径与调度 |
| 产品 | 真实外观 |
| 声音 | 已授权的节奏或声音策略 |

以上按实际素材选择，不要求为每类补齐文件。同一图同时提供人物身份与已有站位等相容信息时，可合并表达，不为形式拆图或另写“不能拆分”的原因；附加用途仍须有来源和适用依据。存在身份、年龄、衣装、动作相位或空间冲突时核具体继承边界，不能以多职责为由混用。

白模、预演或动作参考视频只有在本轮已经提供且确认可用时，才承担姿态路径或调度参考；它们不是提示词阶段必须补做的前置材料。场景图、状态图、多角度图和产品使用视频是否需要制作，也由上游事实、产品资料和导演包决定。

## 核查引用与串用

先检查每个 `@` 是否对应真实文件且主职责明确，产品是否来自真实参考，对白/声音是否有来源与授权。再人工核对是否把人物、场景、动作或产品的无关特征相互借用；相容附加用途按实际继承范围检查，不能一概当成错误。

异常形成具体问题记录，指出冲突的素材、导演要求或确认事实；不靠增加否定词、补图或自行改写导演决定掩盖冲突。真实文件和职责表可离线核验；“职责表减少串用”的效果仍需同模型、同素材、同参数 A/B 生成验证，不宣称任一模型必然遵守。
