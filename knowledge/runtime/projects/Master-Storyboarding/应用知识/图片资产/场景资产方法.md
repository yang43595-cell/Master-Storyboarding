# 场景资产方法

本页由现有仓库专业段落等义分流，不新增理论。第一层输入、字段、模板、生成数量、用户确认与工具授权仍以本 Skill 当前执行合同为准；Web 的明确类别比例、依赖和视图顺序按其模式合同执行。方法不能新增 AST、扩展本次需求或覆盖已确认事实。

## 八、母图模式

### 默认：超宽主视觉或空间骨架

适用于大多数室内、街道、开放空间和动画场景。母图必须同时解释入口、核心区、通道和主要资产关系。画面可以是超宽主视觉，也可以是具有空间可读性的高位斜俯视骨架，但不能是符号化平面图代替最终视觉母版。

### 可选：360°等距柱状全景

仅用于围绕单一中心观察的连续空间。要求 2:1、完整上下结构、左右连续、无重复入口与资产。第一次生成若出现明显接缝、重复或球面错误，即退回空间骨架模式。

### 微观机制世界

必须明确主体、舞台和容器结构，例如毛孔位于皮肤表面、产品实验室位于面膜碗内。锁定更大的身体或容器结构，避免变成无来源的洞穴、太空或奇幻场景。

## 十二、文字规则

- 一级文字：剧情关键文字、机构或场景名称。必须准确；模型不稳定时减少文字并计划后期覆盖。
- 二级文字：功能区和短标签。保持简短，尽量准确。
- 三级文字：远处菜单和说明。使用信息块或图标，不生成密集伪文字。
- 真实品牌未经授权不得生成；使用虚构标识时在资产清单中注明。

## 专业表达与检查

- 空间一致性优先于单张美感。

- 摄影参数用于描述空间关系；二维动画、三维卡通或科普动画不得被强制转成真实照片。

重点锁定重复资产的数量和间距，例如门、卡座、桌椅、柱子、窗户、设备或毛孔开口。不得只写“很多桌子”“若干设备”。

当视频会大幅横移、绕行或露出母图外空间时，优先补一张能同时展示侧墙、台阶、通道或纵深关系的侧机位场景图，不只依赖正面空间图让模型猜测画外区域。

### 永久不可变

- 场景整体形状、尺度和边界。
- 门、窗、入口、出口、走廊和功能区位置。
- 地面高差、台阶和主要建筑结构。
- 核心资产的款式、尺寸、材质、颜色和基础位置。
- 光源方向、时间、天气和窗外环境。
- 整体装修语言与文化来源。

## 九、机位职责库

根据场景等级从下列职责中选择，不强制每个场景都生成九张：

1. 主视觉定场全景。
2. 入口视角。
3. 主视觉反向机位。
4. 左侧横向机位。
5. 右侧横向机位。
6. 核心功能区中景。
7. 标志性资产特写。
8. 高位空间关系验证镜头。
9. 环境氛围空镜。

高位验证必须是自然斜俯视，不得变成无屋顶建筑平面图，不得为展示布局移动家具。

## 相关表达与专业自查

- 默认使用超宽主视觉或空间骨架母图；只有环绕关系重要且测试结果无重复、无接缝错误时才使用 360°母图。

- 360°失败时退回空间骨架，不反复硬修错误全景。

- [ ] 母图模式符合场景尺度，没有强行使用 360°。

- [ ] 空间方向、入口、通道和功能区可以互相解释。

- [ ] 建筑、门窗、家具、资产数量和光源一致。

- [ ] 状态变化来自状态表，没有把剧情状态误判成漂移。

- [ ] 场景延续正式风格母版。

- [ ] 文字按等级处理，无密集乱码。
