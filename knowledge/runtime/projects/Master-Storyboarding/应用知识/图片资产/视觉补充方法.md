# 视觉补充方法

本页从现有分镜图 Skill 等义分流缺口证据、参考覆盖和状态继承判断，不新增分镜设计方法。适用于已确认导演镜头的静态视觉补充；启动条件、可消费来源、请求字段、生成数量、上游退回、授权和确认仍以本地 Skill 合同为准。共用背景固定层与单变量派生判断读取 [[projects/Master-Storyboarding/应用知识/图片资产/图片连续性方法]]，不在此复制。

## 缺口证据与目标

写出缺口的可观察证据，以及不补图会影响什么；“想更直观”不是证据。

将目标压缩为一个静态状态，列出必须出现、禁止出现和必须保留内容。

## 参考覆盖判断

先判断现有来源能否共同覆盖请求中的唯一目标状态、必须出现、禁止出现和保留项。判断结果交给本地请求流程决定复用或补图；不把增加图片数量当作解决缺口的依据。

## 状态继承判断

- 继承：来源镜头指定的主体关系、画面状态、已确认资产身份、空间锚点、真实产品事实、适用的光色意图。
- 不继承：其他镜头的表情、动作、污损、临时光效、构图偶然项，以及资产 manifest 明确列入 `must_not_inherit` 的内容。

本页的方法检查是核对现有参考是否覆盖唯一目标、保留项是否对应来源镜头、排除项是否属于其他状态；不是重新设计导演镜头，也不代替用户视觉终审。
