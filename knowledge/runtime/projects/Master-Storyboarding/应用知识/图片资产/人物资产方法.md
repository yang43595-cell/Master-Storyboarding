# 人物资产方法

本页由现有仓库专业段落等义分流，不新增理论。第一层输入、字段、模板、生成数量、用户确认与工具授权仍以本 Skill 当前执行合同为准；Web 的明确类别比例、依赖和视图顺序按其模式合同执行。方法不能新增 AST、扩展本次需求或覆盖已确认事实。

## 三、人物资产分级

### 身份高风险人物

只从下列项目中选择 AST 明确需要的最小集合：

1. 三分之二全身身份母图，作为唯一身份参考。
2. 正面半身或面部验证图。
3. 侧面或四分之三侧面验证图。
4. 全身比例与服装验证图。
5. 克制表情验证板：常态、压怒、紧张、悲伤或角色需要的核心情绪。

### 身份低风险人物

一张身份母图足够时不机械增加面部、全身或情绪变体。

### 背景群众

以群体设计规则和轮廓差异为主，不为每个人建立完整转面。锁定年龄层、服装年代、色彩范围和密度，避免背景人物抢主角辨识度。

## 六、不可变项与可变项

### 不可变项

- 年龄感、脸型、骨相、五官距离。
- 肤色、发型、发色和发际线。
- 身高、体型、头身比和肩宽。
- 基础服装款式、材质、颜色与配饰。
- 产品拟人角色与真实包装之间的结构来源。

### 可变项

- 视线、微表情、呼吸和身体重心。
- 合理的动作导致的衣物褶皱。
- 剧情明确要求的脱外套、卷袖、受雨、沾灰等状态。
- 机位和景别；改变机位不能改变身份。

## 七、活人感规则

- 肤质保留自然纹理与轻微真实瑕疵，不做塑料磨皮。
- 情绪拆成眉眼、嘴角、面部肌肉、视线和伴生动作。
- 表情默认克制；只有剧情明确要求时才扩大幅度。
- 手部动作必须有动因，避免无目的张手、摆臂或夸张姿态。
- 身份母图使用自然站姿或坐姿，不使用戏剧峰值动作。

## 八、拟人角色结构语义

对于毛孔、细胞、器官、产品包装、工具或成分角色，必须写清：

- 本体是什么。
- 拟人五官和肢体附着在哪里。
- 本体结构哪些部分不能被脸或衣服遮盖。
- 与容器空间、身体结构或产品包装的尺度关系。
- 动作发生时，本体是否允许变形、移动或脱离原位置。

不得只生成通用卡通人，再贴一个产品颜色或标志冒充拟人角色。

## 专业表达与检查

避免使用“帅哥”“美女”“老人”等宽泛词；每个正式人物至少有三项可复述的辨识特征。

## 相关表达与专业自查

- [ ] 去掉角色名后，仍能靠视觉辨认人物。

- [ ] 正面、侧面、全身和表情图是同一个人。

- [ ] 年龄、体型、头身比和服装未漂移。

- [ ] 人物与风格母版属于同一媒介和材质体系。

- [ ] 核心情绪可表演，但没有把人物母版做成剧情分镜。

- [ ] 拟人角色保留本体结构语义。
