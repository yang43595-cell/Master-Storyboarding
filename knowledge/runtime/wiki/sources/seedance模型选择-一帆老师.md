## 核心主张

1. **2.5 使用频率最高的三个功能**：更长生成时长、时间戳、更精准的多模态参考。单次最长从 15s 延长到 30s，很多原本要拆成两三段的动作表演现在能放进一个完整镜头。
2. **时间戳的作用是「拆段时间分别控制」而非「写更多剧情」**：把一条长视频拆成几个明确时间段，分别控制剧情、动作、机位和节奏；示例用「猫大侠追红点」（0-2.5s 建立发现 / 2.5-5s 跟拍追逐 / 5-7.5s 飞扑转场 / 7.5-10s 客厅揭晓再扑）。不会手戳可用他自建的 `timestamp-shot-prompt` 时间戳分镜改写 skill。
3. **复杂空间关系（多人走位/环绕运镜/正反打）上白模**：时间戳管时间但不稳空间，AI 仍会拍错人物、绕错机位甚至让人合体；白模（无脸白盒人物+未贴材质场景）搭出站位/轨迹/机位路径，配合人物和场景设定图，控制空间结构、姿态、运动路径和摄像机角度。
4. **多参考防串用 = 用提示词写明每份素材职责**：只给一堆参考图/视频但不写清「人物图管长相、场景图管环境、白模管动作轨迹」，模型会把材质衣服也一起学走（串用）。解法是加「多参考描述结构」提示词，并记住「素材统一、职责明确、够用就行」「告诉 AI 学什么 + 什么别学」。
5. **选模型看「一个可用镜头平均抽几次卡」，不是看单次价格**：普通镜头简单动作先 H3（MiniMax H3，成本低），复杂动作多人互动 H3 不稳时上 2.0（Seedance 2.0），长镜头/高调度/时间戳/多参考直接上 2.5（Seedance 2.5）。省钱的本质是简单镜头用便宜模型、高难度镜头按成功率往上切。

## 时间戳提示词写法（猫大侠追红点，正面案例）

> 30 秒长镜头示例，加入时间戳后按时间段拆开写，让模型精准锁住时间顺序、动作、镜头切换和反应节奏。

- **0-2.5秒 | 高处建立 + 发现目标**：深夜城市屋顶，猫大侠两足站立在高处俯瞰城市，斗笠压低，披风随风扬起，远处红点突然闪过，猫大侠瞳孔收紧，耳朵立起，迅速前倾，双前爪落地，从两足姿态切换成四足捕猎姿态，锁定红点。
- **2.5-5秒 | 低机位侧面跟拍追逐**：猫大侠四足高速沿屋顶追逐红点，镜头低机位侧面贴身跟拍，它跃过屋顶高低差，贴墙转向，第一次猛扑红点落空，落地后没有停顿，立刻重新加速继续追逐。
- **5-7.5秒 | 蓄力飞扑 + 动作匹配转场**：红点停在前方，猫大侠猛地刹住，身体压低，后腿蓄力，随后全力腾空扑向红点，双爪即将触碰目标时保持飞扑姿势、方向和构图，直接动作匹配切换到现实家庭客厅，斗笠、披风、佩剑瞬间消失，变成普通橘猫。
- **7.5-10秒 | 客厅揭晓 + 再次飞扑**：普通橘猫腾空中的动作落在木地板上，一爪按住红点，摄影机轻微后拉，露出沙发上的主人和手中的激光笔，主人再次移动红点，橘猫立即抬头锁定目标，再次猛扑出去，画面结束。

**反面案例**：不写时间戳、把整段剧情塞进一条长描述（含 Match Cut、禁止转场等），模型只生成一个凝固单镜头（猫僵立屋顶、节奏奇怪）。

## 白模（白膜）参考流程

1. **找有白膜预演台功能的工具**，选择创建场景；上传提前准备的场景参考图，点击生成后 Agent 自动建模，AI 通过白模还原场景空间关系。
2. **添加人偶**：点击左侧人物按钮，确定角色位置和姿势，完成基本空间还原。
3. **绘制运动轨迹**：选择人物 → 点击工具栏「绘制轨迹」→ 长按鼠标左键从运动起点滑到终点 → 松开 → 按空格看到运动路径 → 点击录制按钮得到白膜参考视频。
4. **生成**：把人物设定图 + 场景设定图拖入画布，再拖入白膜视频，输入提示词，选 2.5 模型点击生成。

> ⚠️ «白膜 / 白模»：一帆老师口播读作“白膜”，模型官方能力文档用词为「白模」（white-box / 白模控制）。二者指同一概念——用不带脸的 3D 白盒人物 + 未贴材质场景搭出空间结构与运动路径，作为参考约束生成。——待核验：视频中展示的白膜预演台工具具体产品名未在画面上标明，未能识别。
