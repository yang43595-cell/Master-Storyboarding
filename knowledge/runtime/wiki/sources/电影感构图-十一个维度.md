# 从十一个方面入手拍出电影感构图

> [!abstract] 来源结论
> 构图不是单一的三分法，而是围绕视觉注意、空间关系和情绪质感，从点、线、形状、空间、深度、角度、平衡、颜色、影调、样式和质地十一个维度组合选择。

## 核心内容

1. 点构图可结合三分法、黄金对角线；线构图通过竖线、横线、对角线、曲线和引导线改变力量、距离、倾斜感与视线方向。
2. 形状构图用框中框等方式锁定主体；空间构图通过主体占比、头顶空间和视线前方留白改变力量感与受困感。
3. 深度构图通过前景、远景、景深和焦点转移建立二维画面的层次并控制注意。
4. 角度、平衡、颜色和影调分别控制权力感、视觉重量、色彩突出与明暗情绪。
5. 样式和质地通过重复、有序或材质反差强化主体；不同维度可以组合，也可有目的地打破规则。

## 事实与风险

- 视频是实践型教程，不是标准化摄影教材；“样式构图”“质地构图”等分类名称应作为选择视角，不应冒充唯一行业分类。
- 规则不能机械叠加；构图选择仍需服从当前镜头的信息任务、主体关系和情绪目的。
