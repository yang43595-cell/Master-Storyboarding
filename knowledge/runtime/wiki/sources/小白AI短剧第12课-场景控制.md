## 核心主张

1. **单图控制的盲区**：AI 生成一张满意的场景图后，切到其他机位会飘移/穿帮——因为只有一张参考图，模型不知道场景「背面、上方、侧面」的空间关系。
2. **多角度参考图组（四图场景锁定）**，即梦 image 图生图：
   - 第 1 步：原图为参考 → **反向平视回望**图（补原图中没拍到的环境布置）。
   - 第 2 步：原图为参考 → **45°俯视斜角全景**图（补平视下缺少的物体远近关系，固化区域布置）。
   - 第 3 步：前三张图同时作参考 → **90°垂直正俯上帝视角**俯视平面图（空间总纲）。
   - 结果：4 张图构成场景的多角度参考组，任意机位都能保持一致。
3. **控制优先于提示词**：锁场景靠「参考图组」而不是堆复杂 prompt；若不想模型自由发挥，把要求写进提示词。
4. **操作要点**：模型统一选「image」（即梦图生图模式）；每步都基于原图（前两步），第三步才组合三图。
