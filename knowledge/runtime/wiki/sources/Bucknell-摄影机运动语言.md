# Bucknell 摄影机运动语言

## 基本信息

- 发布方：Bucknell University，ENFS-340 课程
- 页面日期：2018-10-02
- 原文：<https://practicumfall2018.blogs.bucknell.edu/lesson-6-1-the-language-of-movement/>

## 可核验结论

1. Pan、tilt 改变摄影机朝向，不改变摄影机空间位置。
2. Zoom 改变镜头焦距，产生视觉上的接近或远离感，但不属于摄影机真实位移。
3. Dolly、truck、pedestal/boom 分别描述前后、横向和垂直位移；其中垂直位移可由不同支撑方式实现。
4. 摄影机运动是否跟随画内事件，与运动是否有意图是两个问题；不跟随主体的运动也必须有明确设计目的。

## 边界

本页支持摄影机运动的物理分类和选择依据，不提供 Seedance 专属关键词权重，也不证明某个英文句式一定能被生成模型稳定执行。
