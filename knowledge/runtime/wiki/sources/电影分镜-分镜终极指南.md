# 像拍电影一样使用分镜

> [!abstract] 来源结论
> 分镜通过角度、景别、出入画、动作动势、眼神和空镜头组织信息，并通过镜头数量、画面占比和停留时间压缩或延宕叙事时间。

## 核心内容

1. 切镜可以由景别或角度变化、人物出入画、动势衔接、眼神对象和景别递进触发。
2. 主体在画面中占得越多、出现得越久，通常越重要；分镜组合既能压缩时间，也能延宕关键时刻、提高期待。
3. 景别可以逐渐缩小，也可以由特写开始再展开背景；跳跃或不连续的组合可用于时间流逝，但必须是有意选择。
4. 拍摄前应先用图或文字确定每镜的景别、角度和内容，再把想法变成可执行镜头。
5. 空镜头可舒缓节奏、提供余韵并为下一段定调。

## 事实与风险

- 视频是入门级工作流；实际项目仍需先完成戏剧节拍、调度、连续性、声音和切点设计，不能只列景别与角度。
- “不连贯也可以”只适用于明确的跳切、时间省略或风格目的，不是忽略连续性的许可。
