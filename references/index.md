# 执行参考索引

本目录保存知识策略与入口登记。各 Skill 的专业方法及参考通过本 Skill 的 `knowledge-profile.json` 从仓库 `knowledge/runtime/` 选读。普通阶段按自身入口准备本轮快照，资产 Web 和视频提示词按各自的直接读取合同执行。

- `workflow/`：仅含 `knowledge-policy.json` 与 `knowledge-entrypoints.json`，不保存中央阶段表或参考路由。
- 稳定工具合同、执行清单和模板归对应 `skills/<skill>/`，并由该 Skill 直接引用。
- 专业理论、导演方法、镜头知识、对白方法和生成经验由仓库内置包承载。新增或更新时由 `knowledge-maintainer` 进行来源核对、去重和入口审计。
