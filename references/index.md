# 执行参考索引

本目录只保存知识策略与入口登记。专业方法正文以 Obsidian Vault 为唯一真相，由各 Skill 的 `knowledge-profile.json` 选择并写入当前 `stage_startup.md`；Skill 不扫描整个 Vault，也不在仓库保存知识快照。

- `workflow/`：仅含 `knowledge-policy.json` 与 `knowledge-entrypoints.json`，不保存中央阶段表或参考路由。
- 稳定工具合同、执行清单和模板归对应 `skills/<skill>/`，并由该 Skill 直接引用。
- 专业理论、导演方法、镜头知识、对白方法和生成经验不得复制到本目录；新增或更新时由 `knowledge-maintainer` 完成来源、规则去重与确定性审计。
