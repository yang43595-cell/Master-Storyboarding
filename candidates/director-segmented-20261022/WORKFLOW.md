## 1. 完整理解后冻结全局约束

通读完整已确认编导稿及其 narrative.package：故事原文、对白、STP/DLG/AST、锁定事实、素材约束和未决项。以 manifest/state 的准确 artifact/revision 为依据，不能以旧导演稿替代上游；缺源或冲突按既有门禁停止相关内容。

在现有导演 JSON 的 director_rules 各语义字段写全局观看立场、风格、摄影与声音原则，在 editing_rhythm 写总时长约束及各段粗预算与理由；场景 dramatic_goal/change/audiovisual_flow 记录各段叙事目的、情绪关系和信息揭示路线，使用现有来源范围。将估算与用户给定或实测时长区分；timing_basis 保留原枚举和真实来源，未实测不标 authoritative。不同语义不得把同一大段文字塞入所有字段。

按完整动作、因果完成点、剧情转折或时空转换划分创作段落；不按字数硬切，不机械逐句配镜，不截断连续动作。创作段落可小于场景，但不新增上游场景或改号。同场景保留共用设定与连续镜号；计划未细写部分仍标待完成，不造空壳 shots 通过完整包校验。完整导演 JSON 的校验和交接时点沿用现行规则。

## 2. 用实际前态推进一段

每段先定位来源范围、全局目的、情绪/信息揭示目标和时长预算，再从上一段已写出的真实落幅继续。carry 状态写入现有 audiovisual_flow 的段落边界说明，内容覆盖：

- 人物和关键物体的准确结束位置、站坐与身体朝向；
- 动作完成度、手部和道具持有/放置/开合状态；
- 视线对象、关系与情绪余波；
- 对白承载进度、声音的起止/画外延续、环境声衔接；
- 下一段必须到达的目标状态及来源依据。

在场景边界复用 start_state/end_state；同场景段落边界不重造 scene，而由相邻 shots 的 take.end/take.start、cut.information_handoff 和 audiovisual_flow 记录。前段未知或存在相互冲突的结尾时，先解决具体依赖，不把期望状态冒充真实结束状态；时空省略须明确两端与声音时点。

在这些约束下先写本段连贯视听展开，选定画面/表演/声音，再标剪辑边界，落到现有 shots。逐段追加保留已确认内容和准确确认依据，不自动承认上一段 AI 候选。

## 3. 仅在实质岔路提出少量拍法

关键转折、复杂调度或表达不确定处，提出少量实质不同的可行观看路线，例如观众知情次序、观看对象或关系范围的差异；不是只换景别名称，也不每镜强造三案。没有实质分歧时直接完成本稿决定，不为凑方案新增剧情、物件或时长。

先排除硬冲突：台词/说话者/事实丢失或暗改、缺实际来源、不可执行调度、既定时长无法容纳、视线/动作/道具/声音连续性矛盾。硬冲突不能靠高分抵消；无可行方案时报告具体阻塞，不能为了交付强选一个。

对剩余方案按实际可见表达、人物情绪与关系、节奏、时间/素材需求和实现复杂度逐项比较。依据须指向具体画面、动作、切点、声音或停留，写清收益、代价和未验证处。分数仅辅助，不设万能加权总分，不只取局部最高分；必须放回全局目标、预算及前后段状态检查。有局部高分却破坏后续铺垫、时间或衔接时，选整体更成立的拍法或修订相邻未确认段。

选择结论紧凑记在现有 audiovisual_flow：所选路线、未选可行路线、决定性证据与代价。只保留本轮重要取舍，不新增必交评分表或第二份业务稿；把唯一选定拍法落实到 shots，不把互斥方案交给下游选择。

## 4. 有界修订相邻段

新段与真实前态或下一目标冲突时，定位最小受影响的前后镜/段：先修当前段，必要时回改受影响相邻段并复核其衔接，直到依赖稳定。不默认全篇重生成。若影响越过相邻段，明确列出依赖链和必要范围再处理，不能用局部修订掩盖远处变化。

已确认部分保持原文；确需改变时另建修订，保留旧版及未变部分的确认依据，只将受影响修订重新送审。局部确认不得升级为整稿确认，也不自动进入下一 Skill。

## 5. 合成完整 JSON 并做全稿复核

全部段落完成后，按顺序连读全稿画面与声音：核对信息重复/遗漏、远处铺垫回应、对白逐字拼接和说话者顺序、空间/动作/视线/道具/情绪/声音连续性、全局风格、各段及总节奏/时长。技术校验不能证明自然读演或艺术效果，估算不称实测。

最终仍是现有 v4 完整导演 JSON，不增加新字段。按 A 合同的候选 JSON → 自查校验 → 现有审核网页审查 → 用户确认准确版本；本分支不包含 A，对应遗留 profile 顺序冲突在集成前必须用独立 A 修正对齐。只有用户明确要求 Markdown 检查稿时才从同版 JSON 导出；不作为前置、不反向覆盖。网页实际入口、部署版本和发布回读来源未核实时，暂停对应网页操作，不造网址、不称已集成。
