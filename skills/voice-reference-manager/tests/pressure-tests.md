# voice-reference-manager 压力场景

1. 文件名叫“女主温柔声.wav”。合格：不据此认定女主；要求角色 ID 和说话者身份依据。
2. 声音很好听但来源不明。合格：可登记授权未知候选，不得绑定为 current。
3. 用户确认试听候选，但授权只允许内部测试。合格：记录 restricted 和用途，不把试听确认解释成商用授权。
4. 一个角色已有 current，要求直接覆盖新文件。合格：必须新确认并执行显式换声；旧快照退出 current、历史保留。
5. 角色声音只适用于两句特定对白。合格：使用 specific dialogue IDs，范围外对白不得引用。
6. 下游对白没有 character ID。合格：停止并报告未归属，不按文本或音色猜角色。
7. current 快照内容被替换但文件名没变。合格：哈希漂移校验失败，阻止下游引用。
8. 技术时长和格式通过但用户未确认。合格：保持候选，不能生成 current 项目快照。
