# Blender 预演 CLI 与配方契约

入口 `scripts/blender_previs_cli.py`（全局参数 `--blender <exe>` 放在子命令前）。项目主流程为无人物空间基座 `build` / `register-scene` → 按导演镜号 `prepare-shot` → `stage-shot` → 按需 `export-preview` 快速查看与调整 → `shoot` → `verify` → 登记、用户确认与交接，详见 [项目接入](项目接入.md)。`export-preview --project --stage-dir --output-dir` 只导出同源 GLB 与摄影机清单，查看用已有项目网页；正式检查、确认与交接不由网页预览代替。`doctor` 自检环境，`bootstrap-human [--keep-helpers]` 生成标准人物模块（MPFB，CC0）；`bootstrap-assets` 下载登记合规外部资产，`reconstruct-scene` / `image-environment` 由参考图起环境几何，均按实际需要使用。

配方遵循 `schemas/blender-previs-recipe.schema.json`。写配方前先跑一次 `doctor`；`build` 的 `--output-dir` 必须是**空目录**，输出不覆盖既有文件。

## 自动验收（`verify`，交付前必跑）

`verify` 打开待验收的 `previs.blend`，按有效人物配方和本轮镜头清单逐项核对并输出 JSON；任何一项不过就非零退出。`shoot` 产物须同时传 `--recipe <本镜有效配方>`、`--scene` 与 `--shots`，不能用无人物房间配方替代本镜配方：

- **接触**：持续坐姿的臀/大腿接触区与实际座面网格之间的有符号间隙（既防穿入，也防悬空）；脚不能代替臀腿。座面下方须有真实网格承托；大腿与扶手按椅子局部坐标判定。地面/台面间隙相对实际求交面，不固定世界 z=0；同一网格内的楼板、顶板或多层座板逐层求交，再选择最接近声明承托高度的向上表面，不要求拆开房间网格
- **比例**：每个人物实测身高 vs 声明的 `height_cm`
- **机位与景别**：相机与关键帧存在，在起止、关键时刻及规定采样重新求值后核对入画和主体占比；镜头时间不得超出有效配方范围
- **产物对应**：本轮配方指纹、指定文件与清单中的路径/大小/内容哈希一致；PNG 尺寸与参考图镜号/时刻准确；MP4 通过 `ffprobe` 核对实际帧数、时长、帧率与尺寸。缺图时放一张无关图补足数量仍会失败，旧清单缺少本轮证据时也不能验收。

自动检查只证明实际检查时刻与采样范围内的结果，不证明所有帧、全程遮挡、导演意图或精细表演。实际预演图/视频仍须查看。**不过就不交付**；修完再跑。

## 配方关键字段

| 字段 | 说明 |
|---|---|
| `project` | `fps`、`duration_seconds`、`resolution`（继承已确认导演时长与成片画幅；9:16 → `[540, 960]` 仅为竖屏项目示例） |
| `environment.preset` | 自建房间用 `natural_proxy`；它支持的类型以 runner 的 `NATURAL_PROXY_KINDS` 为唯一权威（`proxy_box`/`proxy_cylinder`/`proxy_cone`/`proxy_sphere`/`proxy_rock`/`chair`/`armchair`/`bench_seat`/`glass_balustrade`），其它家具类型要映射成这些；用了不支持的类型会直接报错并列出可用类型 |
| `actors[].height_cm` | **身高按厘米写**（如 178）；`height_m` 优先于 `height_cm`。粗体和导入人体均在完整可见几何求值后归一化，包含发型/冠饰，不宣称生理净身高。未声明身高时，旧粗体 `scale` 仍乘原角色比例，导入人体仍按 2.15 米基准乘 `scale` |
| `actors[].human_template` | `mpfb_neutral` 用标准人物模块；`rotation_degrees = 座位角度 - 90` 表示面向桌心 |
| `actors[].actions[]` | 坐姿**优先给 `chair_id`**（位置/朝向/座面高度全部由椅子决定）；没有椅子时才退回 `surface_height`（椅面高度，米，默认 0.45）。贴座面按独立臀/大腿接触网格求值，不用脚底、整人包围盒或写死下沉量 |
| `camera.shots[]` | 每镜 `start` / `end` / `keyframes[{time, position, look_at, lens_mm}]`；固定机位就写两个相同关键帧 |
| `outputs` | `build` 使用 `preview_video`、`preview_video_shots`（混合段只导确需时序参考的镜头）、`still_frames`、`reference_views`（每镜首/落幅）、`render_style: role_colors`；`topdown.video` 与 `topdown.show_paths` 默认 false，按需要显式开启 |

**机位换算示例**：9:16 竖屏采用 36mm 传感器高度并按**竖向**匹配时，等效焦距 f 的竖向视野 = 2·atan(18/f)，横向视野应按画幅比例另算；该数值不适用于其他画幅或传感器设置。双人并排能否同框由机位、焦距、实际头高与站位共同决定，不能为了塞进画面擅自改变导演站位。

**跟拍／走动镜示例**：约 1.8 米人物、9:16 竖屏和等效 30–35mm 下，全身取景可先试约 2.8 米的机位距离，再按实际人体高度、头尾留白与 `subject_fill` 核对；它不是通用距离下限。机位须符合已确认导演意图。

**粗状态能力边界**：已明确要求观看时，用 `look_at` 和已有场景对象名 `target` 给标准人体一次粗头部朝向；身体朝向先按来源摆好，不自动转脚或补精细眼神。当前不持续追踪移动目标。`idle` 保持已建立状态，`turn`保留局部姿态；需要重置站姿才明确用`stand`。未写actions仍只是未写，不等于继承上一镜。初始支撑高度由 `position.z` 声明，移动终点 `to.z` 也是支撑高度；站立、弯腰、走动不能把台面人物重置到世界地面。`sit` 持续到显式改变姿态，`idle`／`turn`／`look_at` 后仍验座面；`stand` 在起点退出，`stand_up` 从起点离座并在终点回到站姿支撑。`hold_prop`等当前后端未实现的动作明确报错；按既有空间参考/同源姿态布置补必要接触，细握持和表演由图片/视频提示词约束，不为填齐动作名扩建动画系统。

## 段形态与产物（三种）

先判断本次需要证明单态空间，还是相机/粗路径及遮挡过程，再在已授权范围内选最少充分产物；固定机位也可能需要时序参考：

| 段形态 | 判定 | `outputs` | 产物 |
|---|---|---|---|
| 静态参考 | 只需核对单态构图/空间 | `preview_video: false`；`topdown.video: false`；`topdown.show_paths: false` | 本轮所需首/落幅或关键帧**图**（显式选择），按需俯视图 |
| 时序参考 | 确需核对相机运动或粗路径/遮挡过程 | `preview_video: true` | **视频**（所选时段）＋本轮显式选择的参考图 |
| 混合段 | 只有部分镜头需要时序参考 | `preview_video: true` + `preview_video_shots: ["镜号"]` | 静态镜出图，**视频只含已选择时序参考的镜头** |

`preview_video_range: [起秒, 止秒]` 可按秒限定（两者取其一即可，缺省渲整段）。`preview_video_shots` 多镜选择必须连续相邻；不相邻的所选镜头使用 `shoot` 逐镜输出，避免把中间静态镜混进视频。视频不重复编码结束时刻那一帧；例如 10 fps 的一秒视频为 10 帧。静帧和俯视帧按秒保留两位小数命名，格式化后重名的时刻会在渲染前报错。

上表的 `outputs` 控制 `build`；逐镜 `shoot` 用镜头清单中的 `video: false/true` 控制，不读取配方的 `preview_video`。俯视默认只出图、无路径线；运动段要俯视视频也须显式 `topdown.video: true`。仅用户明确需要路径辅助图时设置 `topdown.show_paths: true`，辅助图不混入正常参考帧。

## 时长口径（继承导演稿，核对可行性）

本阶段继承已确认导演稿的镜时长、切点与段长，不重新决定节奏。对白、动作与运镜耗时估算只用于未定实现参数或可行性核对；所需时间超出已确认镜长时返回导演与用户，不自行加秒、删动作或拆镜。

- 对白：字数 ÷ 预估语速，未定语速可用中文约 4.5–5.5 字/秒作试验值；已有确认配音时参考实际时长。
- 动作：按本镜已确认的动作起止估算完成时间，精细动作仍交给文字与素材，不靠白模补写。
- 运镜：**摇时长 = 角度 ÷ 摇速**，如 45° ÷ 20°/秒 = 2.25 秒；再核对实际画面的可读性。
- 起落幅留白与 final hold 遵循导演稿；未定时可试起幅 0.2–0.3 秒、落幅 0.3–0.5 秒并标注试验参数。
- `project.duration_seconds` 与镜头清单的 `start/end` 保留已确认时长及一致的时间坐标，不由上述估算重定。

**图与视频的时长含义不同**：图不带时长；预演视频按所覆盖的已确认镜头时间范围输出。仅覆盖运镜镜的视频不代表整段，交接注明范围，不能把预演秒数自动当成后续生成时长或授权；后续阶段仍按导演稿与所选模型处理。

## 产物布局（CLI 实际写出）

```
05_分镜/预演/<场次>_<段号>/        ← --output-dir，必须为空；重建使用新目录
  previs.blend  manifest.json  resolved.recipe.json  blender-previs.log
  previs.mp4                      仅选择了时序参考的镜头/范围才有
  reference-frames/*.png          参考帧：本轮显式选择的首/落幅或关键时刻
  stills/*.png                    still_frames 指定的时刻
  topdown/topdown-<秒>.png        俯视站位图（开 outputs.topdown 时）

05_分镜/预演/<场次>_颜色对照.md    颜色→人物／物品 + 机位元数据（放输出目录外面，重建不会丢）
05_分镜/预演采用记录.md            跨段共用：版本、覆盖镜头、静态/运动/混合段、动作参考级别、审核结论、段号→文件
```

颜色对照**不要写进 `--output-dir`**：`build` 要求空目录，已构建目录再次写入会被拒绝。

## 空间基座复用与逐镜状态（重要）

**同一场景的无人物空间基座只建并登记一次**：固定房间、家具、道具占位与锚点沿用确认布局、尺度与同一 `scene_artifact`。新镜头按 [项目接入](项目接入.md) 的 `prepare-shot → stage-shot → shoot → verify` 执行；`stage-shot` 只在新副本增加本镜人物状态和摄影机，不能重建房间或保存回基座。逐镜有效配方必须列本镜人物、动作起止与关键状态。

```
python -B -m scripts.blender_previs_cli shoot --scene <逐镜布置副本>/previs.blend \
    --shots <本镜摄影机清单.json> --output-dir <本镜新渲染目录>
python -B -m scripts.blender_previs_cli verify --recipe <本镜有效配方.json> \
    --scene <逐镜布置副本>/previs.blend --shots <同一摄影机清单.json> \
    --output-dir <本镜渲染目录>
```

- `shoot` 只加相机、只按镜头临时挪动声明的道具（`props` 覆盖），**不重建、不保存**场景几何。
- 镜头清单里每个镜头写：`id / label / start / end / lens_mm / keyframes / must_include / subject_fill / props / still_times / video`。
- `keyframes[].time` 为相对本镜 `start` 的秒数；`shoot` 逐点执行 `position / look_at / lens_mm`（单点未写焦距时沿用镜头 `lens_mm`），不只取首尾。相同状态的相邻点表达停留，路径、目标与焦距逐段线性插值；`cut` 复用 build 的前一帧保持处理。`verify --shots` 复用同一动画实现；技术通过不代替视觉终审。
- 已有**完整整场人物时间线**的旧白模可直接 `shoot`，清单时刻必须对应其既有人物状态，`verify --recipe` 传覆盖本镜实际状态的有效人物配方；不能再 `stage-shot` 同 ID 人物。需要新增状态时回到无人物房间基座制作新逐镜副本，不删除已确认基座中的人物、不修改房间。
- 验收复现同一份 `props` 的位置、旋转与缩放覆盖，并按本镜有效配方检查人物；在实际采样时刻核对景别和承托，不把通过记录解释为全程无穿模或无遮挡。
- `shoot_manifest.json` 锁定本轮场景与镜头清单指纹、帧率/尺寸及逐文件内容。验收按准确文件名、静帧时刻与相机、PNG 尺寸核对；视频用本机 `ffprobe` 核对尺寸、帧率、帧数与时长。缺文件、参数变化、冒用其他镜头文件或旧清单没有对应证据时均不通过；技术通过仍不替代人工视觉审核。

## 两种用途：视频参考 与 分镜图约束

预演产物有两种用法，配方里用不同字段表达：

| 用途 | 约束什么 | 字段 | 验收 |
|---|---|---|---|
| 视频参考 | 运镜、路径级动作、站位朝向 | `camera.shots`、`actors[].actions` | 见「段形态与产物」 |
| **分镜图约束** | **景别（主体占画幅多少）与人物/物件关系** | `shots[].must_include`（必须入画的对象/人物）、`shots[].subject_fill`（主体占比区间） | `verify` 按相机投影逐项核对 |

分镜图常错的就是这两样（景别偏宽、机位跑到错误一侧）。给了白模参考帧 + 把该镜的 `must_include`／`subject_fill` 写进配方并 `verify` 通过，分镜生成才有硬约束可依，而不是靠文字描述各猜一遍。

- `must_include`：对象/人物 id 列表（道具写占位体 id，人物写 `chr.*`）。人物局部近景（如口袋、手）不要写人物整体——胸口这个代表点本来就在画外；写该处的占位体即可。
- `subject_fill`：`{target 或 targets, min, max}`，主体投影占画幅的比例（横竖取较大者，兼顾沿纵深躺着的主体）。近景一般 0.18–0.42，特写 0.35–0.7，中景 0.10–0.25。
- 分镜用的白模产物按镜头出目录（`05_分镜/预演/<镜号>_<简述>/`），与按段出的视频参考产物分开存放。

## 机位元数据（写进颜色对照）

画幅与成片一致（9:16 仅为竖屏项目示例）；焦距统一用**等效全画幅焦距**；机位高度用米，并按本镜实际人物尺度、姿态与头高核对；另记俯仰与起止位置。缺任一项景别不可复现。

## 颜色与动作级别

- 人物各一色且全片不变；**相似却不同的物品各自独立颜色**（白 A 剂与金 B 剂、礼盒与美容卡、茅台与电脑）。配方里用 `actors[].display_color`、`objects[].color`。
- 颜色只作认领标签：提示词按「把<颜色>模型映射为@素材N的<人物／物品>」写，并声明不保留白模颜色与材质。
- 动作级别默认 `路径级`（只参考走到哪、朝哪、何时切），提示词须写明不复刻白模姿态；只有用户明确指定「上传的是精细动作白模」才升级为 `精细动作级`，并记录依据。
- **预演视频承担相机运动与粗路径/遮挡参考，不承担精细动作表演**：像拾取、递物这类精细动作，出景别图即可（首/落幅），动作过程交给文字描述，避免成片复刻白模动作而僵硬。按本轮已授权目的选择时序媒体，不因固定机位排除粗路径核验，也不自动升级为精细动作参考。

## 坐姿与椅子（防劈腿、防穿模）

- **椅型与尺寸由本场景确认参考决定**：参考确实无扶手时选 `chair`；有扶手时可用 `armchair` 或已确认导入几何，按实际净坐宽、角色比例和臀腿/扶手接触核对。某个窄代理的碰撞结论不是所有餐椅的事实；不得为通过验收擅自删扶手、加宽确认家具、改变角色比例或导演站位，不可行时回报矛盾。
- **两种椅子的靠背都在自身 -Y**（`chair` 与 `armchair` 已统一）：给 `chair_id` 后自动面向椅子 +Y；标准人体自身朝 -Y，root 角加 180°，粗体自身朝 +Y，沿椅子原角。不要把一个后端的 root 角直接套到另一个。
- 坐姿给 `chair_id`：人物位置、朝向、座面高度全部由椅子决定，人会坐在座面中心略靠前、背对椅背。runner 会算净坐宽，窄于髋宽时在日志里报警（`[previs][warn] ...`）。
- **贴座面用独立臀腿网格，不用骨盆骨骼或采样圈内脚底**：粗体使用已标识的大腿部件，导入皮肤按主要骨盆/大腿权重选区；无法识别则拒绝接触验收。默认目标间隙 0.005 米，允许穿入最多 0.01 米、离座最多 0.02 米；至少半数底部接触采样须射中实际座面，座面包围盒跨孔不算承托。
- 双腿自动收拢：膝盖与脚按数值求解收到骨盆附近。实测：不处理时脚外撇 0.46 米；处理后脚落在身体正下方（0.00）、膝盖 ±0.23 米。
- 大腿若真的压进扶手，会沿坐向自动前挪（平移不改姿态），并且髋部不越过座面前缘。
- `ground_feet: true`（可选）：脚落到声明支撑高度优先，仍要求实际座面承托，且臀腿穿入不得超过 0.28 米；离座上限仍为 0.02 米，不豁免扶手检查。未开启时允许坐姿脚悬空。地面报告记录实际网格间隙；只有没有任何可用场景支撑网格的旧几何配方，才明确标注使用声明平面，不能把地面孔洞当声明平面放行。

## 白模人体规范（模板层）

需要标准骨架的动作，使用已登记标准人物模块 `previs.human.neutral`（`assets/blender-previs/asset-registry.json`，配方写 `human_template: mpfb_neutral` + `height_cm`）；模板缺失时明确报错。没有指定模板的粗体可做已实现的空间/支撑动作，不因本机缺 MPFB 而被强制升级为标准人体；不得把粗体或合成测试骨架冒充 MPFB 验收。

基础动作档（`actors[].actions[].preset`），够用即可：

| preset | 用途 | 备注 |
|---|---|---|
| `stand` | 站 | 默认站姿（手臂自然下垂） |
| `sit` | 坐 | 优先 `chair_id`；没有椅子才配 `surface_height`（承托面高度，米） |
| `crouch` | 蹲 | 自动按脚掌贴地对齐高度 |
| `bend_over` | 弯腰 | 自动按脚掌贴地对齐高度 |
| `walk` | 走位（带 `to` 终点） | 空间路径必需 |
| `idle` / `turn` / `stand_up` | 停住 / 转身 / 起立 | 衔接用 |

`look_at` 需要支持头部求值的标准骨架；躺卧预设需要导入骨架。粗体不支持这些动作时明确报错；`hold_prop` 两后端均未实现，不再以空操作冒充有效动作。

比"蹲/弯腰"更细的动作（拾取、递物、手指动作）不进白模：按上面的动作参考级别规则，那些镜只出景别图，动作交给文字。

`bootstrap-human` 生成的中性人体默认已做简化（`--keep-helpers` 可关闭）：删掉**头发、裙子、紧身衣、睫毛、牙齿舌头、MPFB 的 JointCubes（绑骨调试小方块）**等辅助几何（后几样在白模里会变成脸上、下巴上的小方块，或把角色误读成穿裙子），并删掉**手指与脚趾**、补平切口，只保留方位识别所需的轮廓。顶点数由 19158 降到 10516。

- **保留**：头、躯干、四肢、手掌与脚掌——否则站姿接地、坐姿落脚、遮挡与朝向都读不出来。
- **去掉手脚细节的目的**：降低生成端「照抄精细手部/脚部动作」的诱导；但**主要防线仍是提示词**（写明不复刻白模四肢动作）。
- 读白模图按**颜色 + 身高**认人；面部与眼球是基础网格自带结构，低面数下会有小凸起，属正常。

## 已知限制

- `build` 的 `outputs.topdown`（俯视站位图）可用：渲染时会临时清掉时间轴上的切镜相机、并隐藏天花板/屋顶/吊灯/壁灯。需要跨镜站位图时给 `topdown.still_times` 至少一个时刻；默认 `video: false`、`show_paths: false`。`stage-shot` 不渲染、`shoot` 不自动生成俯视图，不把配置项当成已有产物。
- 环境母版画的是它自己的家具数量；座位与椅数这类故事事实以已确认的关系图为准，母版只提供房间本身。
- `armchair` 净坐宽取决于实际尺寸；窄座告警用于提醒核对，不自动授权更换椅型或改确认尺度。实际碰撞仍由既有接触检查判定。

### shoot 静帧默认与准确命名

`build` 按 `outputs.reference_views` 选择首/落幅；`shoot` 按每镜 `still_times` 选择静帧，不保证默认包含首/落幅。省略时只渲染一张 `min(start + 0.5, (start + end) / 2)` 秒参考，不自动增加渲染。只有实际时刻等于 `start` 才命名 `START`，其他时刻命名 `T<秒数>`。需要 0–4 秒镜头首/落幅时，在授权范围内明确 `still_times: [0, 4]`；单态只选必要一帧。manifest 的 time/frame 是实际时刻依据，静帧不证明连续动作。
