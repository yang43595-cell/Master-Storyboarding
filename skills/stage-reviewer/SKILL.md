# 阶段审核

只在用户明确要求独立审核后启动。整稿交付、重大改动或反复出错时，可以建议用户安排独立复核；建议本身不是授权，不自动派发或阻塞生产。日常小改仍由当前生产对话自查。

审核依据是目标 Skill 的现行 `review-profile.json`、冻结范围、准确候选及其指定来源。不得复制或另造生产业务标准。产物审核与 Skill 合同审核分开；视频提示词按 [直接审核分支](modules/review-method.md#视频提示词的直接审核分支) 使用准确候选和来源，不恢复旧审核包流程。

审核者应保持独立：首次审核不继承生产对话；修订复查回原审核者，只核原问题、修订及直接影响。方法、证据范围、交接格式和留档选项统一见 [审核方法](modules/review-method.md)。这是执行要求，仓库没有自动隔离审核者或自动派发机制。

只读报告事实和证据；不修改候选、不生成批准事实、不代表用户确认、不决定阶段流转，也不替用户做图片视觉终审。通过结论不等于批准。
