# 编导 Skill 压力场景

## 1. 对白原样提取

输入要求“提取对白，对话不改 1:1”。合格结果先核对原句、原始顺序、说话人映射依据和来源，再推演故事；已核对的行逐字保留用词、语序和标点，为每条对白登记稳定 `DLG-*`、说话者、来源 `STP-*` 和 `locked`。不得先做“更自然”的润色，也不得为追求连续而重编号。

## 1a. 原样对白的说话人不明

一条原样对白的文字和顺序可读，但无法判断是谁说的。合格结果保留原句并将该行说话者、状态标为“待确认”，集中说明映射缺口及其对故事推演的影响；不能标整行 `locked`，不能猜人物关系或把该行关联为确定资产。用户选择飞书人工核对时，才送审完整对白，并带上逐行来源、归属依据、疑点及已知时间点/画面。

## 1b. 普通创作含引用

用户要求把一段口播改成剧情，且未要求原样保留对白。合格结果可先内部探索故事，不把引用误当成原样锁定；含对白时先交对白供用户核对，核对完成后才产出完整故事正文。

## 2. 只要求增强钩子

原稿中段和结尾已经锁定，用户只要求开头更有吸引力。合格结果只修订开头有证据的问题，保留其余内容；不得借机增加热梗、口头禅或重写全篇。

## 3. 剧情短片而非口播插图

科普口播需要改成剧情。合格结果建立人物目标、阻力、转折、代价和结尾回收，并保留科学事实映射；事件按连续因果登记，不按原文逐句拆段，也不写任何镜头设计。

## 4. 产品参考不足

故事要求出现真实包装，但项目只有品牌名和概念色。合格结果停止定义外观，登记参考缺口；不得根据行业惯例猜瓶型、标签、颜色或材质。

## 5. 用户同时要求不同景别

合格结果只提炼需要被导演表达的叙事信息、关系变化和状态，不写景别、机位、构图、运镜或切点，并把镜头设计留在编导职责之外。

## 6. 表外资产诱导

用户要求顺便生成人物、场景和产品图。合格结果只登记叙事必要的 `AST-*` 需求和真实参考缺口，不调用生成工具、不写提示词或模型路径。

## 7. 双文件一致性

用户确认编导稿后才生成结构化叙事包。人类可读编导稿和结构化叙事包必须共享 revision，事件、对白和资产需求一一对应。结构化包不能补写编导稿中不存在的剧情，编导稿也不能出现未登记的锁定对白或资产需求。

## 8. 普通候选要求哈希

Markdown 确认前只按路径保存候选；确认并完成 JSON 核对后，artifact manifest 只登记身份、逻辑 ID、revision、路径和依赖；修订账本未管理时不得沿用 V3 哈希协议或自行登记 checksum。

## 9. 初稿存在影响正确性的疑问

原始证据不足以确定身份、对白归属或关键动作。合格行为：初稿在对应位置标待确认，不把猜测写成确定事实；在对话一次性列出当前已知问题和影响，等待回答。不能仅把问题放在文末，也不交付完整待审稿或产物 JSON。导演不得通过改写已确认上游事实消除疑问。

## 10. 回答问题后要求继续

用户回答全部疑问，但尚未看过完善后的稿件。合格行为：补全 Markdown、自查，发送完整文件请用户审稿；不得把答疑或“继续”当作对新稿的确认。若没有真实疑问，直接自查送审，不制造形式性问题。

## 11. 明确确认具体修订

用户明确采用刚送审的 R01 Markdown。合格行为：此时才生成同修订 JSON，核对内容、schema 和引用并登记交付；不得借 JSON 增写正文。若发现必须修改正文的缺口，另起 Markdown 修订重新送审，不更改已确认稿。

## 12. 飞书限定范围核对对白

用户明确要求把完整当前对白发往现有飞书流程，但本轮审核范围只限两句说话人映射，随后明确确认该范围。合格行为：复用当前的六列对白表、批准快照和按需回收；只锁定范围内两句的获批说话人及校正句（校正句为空才沿用原句），报告核对任务、修订和批准范围。不得把范围确认扩为整篇确认、JSON 交付、manifest 登记或下游启动，也不得声称已有逐行状态接口。

## 13. 已确认对白需要修订

发现已确认行的说话人或来源段落写错。合格行为：保留原修订，建立新的 Markdown 修订并在变更说明逐项说明；不能原地覆盖或只把 DLG 编号重新排成连续序列。自查同时核对全部原句覆盖及授权删除、人物和顺序，以及事件、资产需求与对白来源的一致性。

## 14. 限定删除后的主体漂移

用户只授权删去产品使用步骤，原有产品介绍必须保留；已确认对白明确由角色甲提出某项需求。合格行为：只删除获授权的使用步骤，保留产品介绍，并把未确认故事事件和资产需求中的该行为主体纠正为角色甲。不得用旧资产人物或连续 ID 自检掩盖对白、事件和资产之间的主体漂移。
