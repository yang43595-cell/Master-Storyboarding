# 红帧转深度

## 先处理源视频

1. 从开工登记及分段计划取源文件、实际时窗和画幅。已有同源、同窗、同用途的深度素材时直接复用。
2. 在原片上登记产品可见帧窗。按实际切点裁出无产品的剧情镜段，保留产品前后正常剧情及原画幅。源片的字幕、贴纸、界面文字和水印在这一步按需处理，同时去掉原声。处理输入时登记实际裁片覆盖的原片窗，供分段和引用使用。
3. 例如，用 FFmpeg 裁视频并去掉音轨。需要精确帧切点时按已登记的半开帧窗裁。同一剧情段中间出现产品时，分别输出入画前和离画后的片段。

```sh
ffmpeg -n -i '<原片>' -ss '<起点>' -t '<实际窗长>' -map 0:v:0 -an \
  -c:v libx264 -pix_fmt yuv420p '<镜段输入.mp4>'
```

## 在画布转换并使用

1. 把已经处理好的镜段上传到本项目正在使用的红帧画布。选中视频素材卡，点击「深度动作捕捉」，在弹窗确认同名操作。红帧会在源视频旁生成一张新的深度视频卡。
2. 转换任务返回视频后，把深度视频卡放在对应草稿附近并留出端口间距。将深度卡的「视频输出」接到草稿参考输入，在「生成提示词」里用原生 `@` 选中该视频，标注镜段与用途。交接记录沿用该输入的原片窗。既有批量写入入口要求本地文件时，取同一个红帧输出文件登记路径和字节摘要，再由现有入口写入参考槽。
3. 转换完成即可使用。省去深度结果看片、抽帧、字幕实看登记及与原片的逐帧或时间轴比对。草稿保存后沿[画布交付入口](../../../docs/development/review-to-canvas-entry.md)回读实际引用。转换报错或未返回可引用视频时回查原任务。

## 已有深度母片的局部复用

需要从既有母片取子窗时仍可用 `python scripts/prepare_depth_clips.py --project <项目> --plan <复刻分段.json> --output <项目内目录> --segment-id <段号>`，多段可重复指定段号。工具按 `reference_frames` 裁切并登记分段文件、字节摘要和原片窗。新做或换窗重转时从原片处理对应段，再进入红帧转换。
