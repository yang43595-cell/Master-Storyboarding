# 深度图视频复刻

对标项目先由编导还原原片剧情、对白与动作。编导整稿采用且本轮选定复刻线后，进入此入口。1:1 指尽量对齐原镜头顺序、切点、构图、运镜、走位与动作节拍。人物和场景的保留程度按本轮选定资产及画面可辨识的特征判断，允许生成差异。

## 三层读取

1. 先读[项目规则](../../PROJECT_RULES.md)、[共用三层规范](../_shared/skill-layers.md)和本轮原片、替换范围、目标资产。按[开工确认单](../../docs/rules/project-layout.md#开工确认单)登记决定，本步直接读上述原件。
2. 按[知识配置](knowledge-profile.json)和[复刻执行方法](modules/recreation-method.md)处理镜头、外观参考和交接。需要新做深度时读[红帧转深度](references/depth-video.md)。
3. 本轮原片和截帧是逐镜依据。按处理好的源窗绑定红帧结果，输入变化时只重做受影响的镜段。

## 执行

1. 从已采用编导稿划连续剧情段。超过30秒时优先选换场、收句或动作结束处。平台生成或参考上限更短时在提交层切窗，沿用同一段的内容。
2. 先在原片登记产品出镜帧窗，裁出产品前后的正常剧情，处理源片上的字幕和原声，再把处理好的视频上传同一红帧画布转深度。转换完成直接把结果挂为对应段的视频参考，按[参考职责与排除项](modules/recreation-method.md#深度参考职责与排除项)写明时段和拍法。取消深度结果的看片、抽帧和原片比对。产品画面用本项目同款实物及实操参考。
3. 按[分段交接](modules/recreation-method.md#分段交接)登记输入。普通剧情及固定工序直接交视频 Skill，确实改变人物互动才派导演局部改戏。导演在对应段更新处理结果后重交。
4. 授权生成后按原片结构检查成片，局部偏差先返修受影响段。
