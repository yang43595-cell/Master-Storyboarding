# 深度图视频复刻

对标项目先由编导还原原片剧情、对白与动作。编导整稿采用且本轮选定复刻线后，进入此入口。1:1 指尽量对齐原镜头顺序、切点、构图、运镜、走位与动作节拍。人物和场景的保留程度按本轮选定资产及画面可辨识的特征判断，允许生成差异。

## 三层读取

1. 先读[项目规则](../../PROJECT_RULES.md)、[共用三层规范](../_shared/skill-layers.md)和本轮原片、替换范围、目标资产。按[开工确认单](../../docs/rules/project-layout.md#开工确认单)登记决定，本步直接读上述原件。
2. 按[知识配置](knowledge-profile.json)和[复刻执行方法](modules/recreation-method.md)处理镜头、外观参考和交接。需要抽深度时顺读[深度视频工具与核对](references/depth-video.md)。
3. 本轮登记的原片、截帧和实际深度片是逐镜依据。输入变化时重核对应窗和资产，用已核的案例证据判断适用范围。

## 执行

1. 连续看原片，核取材时窗、实际切点、起止构图、机位运动、动作落点与人景遮挡。对白、原声、字幕、叠加图层依本轮决定单独处理。
2. 先按剧情事件与产品工序划范围，再为需要复刻结构的剧情段准备同窗深度视频。切点优先落在新人物揭示、动作动机完成或进入下一行动地点的原片镜头边界。登记角色、场景和局部材质分别由哪张图约束，提示词写清深度参考可借和应排除的细节。人物和场景优先使用资产阶段已确认的合用图。发现缺图时，沿现有资产入口登记具体镜号和用途。缺源时登记受影响镜段，继续可独立完成的部分。
3. 把原片事实、镜号、参考片段及资产用途交回协调方。导演基于已采用的叙事包定逐镜方案，复刻适用镜头。真实产品使用及依赖该工序结果的收尾，走现有导演、资产、视频提示词和生成流程。生成前核实际平台的输入方式和本轮授权。
4. 本 Skill 完成到可核的原片与深度资料、逐镜替换及参考用途交接。取得已授权生成的结果后，按[样片核对](modules/recreation-method.md#样片核对)补核实际人景与时间结构。深度文件有效、素材接入成功和成片效果分别据实记录。
