# 提示词语言红线

适用：凡产出提示词的任何 Skill（资产、分镜图、视频提示词、预演配方等）。

1. **必须合规**：提示词禁用 影视级/8K/4K/高级/唯美/大片 等**炫技含糊词**；措辞须命中该 Skill 的知识库写词规范（如 `prompt-language-hard-rules.md`、对应 master-guide）。
2. **必须按本 Skill 方法写**：写提示词前先读本 Skill `modules/` 方法与 `references/` 提示词规范，按其"如何写/读哪些"来写，不凭空发挥。
3. **交付前必审查**：提示词交付前，该 Skill 的 review-profile 必须含 `PROMPT-LANG` 检查并核过；未核不计为确认。
4. **不越权**：不因写提示词而新增 AST、不改剧情/对白/事件/镜头，不超出当前 Skill 的职责替其他阶段作决定。视频生成分段由视频 Skill 按已确认导演与真实承载能力判断；模型仍使用用户明确选择，素材制作不得借此自动生成视频或决定下游流转。

## 完整镜头的同刻状态转译

只在本轮把有参与者的已确认镜头转成白模、分镜图或视频提示词时执行；限所选镜头及必要相邻状态，复用仍有效的已读结论，不扩为全片扫描。身份板、纯材质等没有镜头的资产任务不虚造camera/take。

- take选择一个时间相位，同时读完整正文、camera、场景设定、覆盖项与相邻起止；摄影机栏中的人物动作和观看也是来源，不能只转译主动作。
- 逐一核对可见人物及影响画内动作的画外参与者：位置/姿态、支撑、双手/持物、身体和头部朝向、注意对象与有依据的反应。沿现有目标状态/备注简述，区分来源明写、持续继承、实现候选，不另建逐人计划表。静止观看或等待也可正确，不机械让所有人移动。
- 未被新事件改变的前态不能默默重置成idle；不继承不适用的旧参考姿势，不等于清空剧情的持物/承托。主动作及有依据的伴随反应属于同一动作层，不把“单变量”理解成冻结其他人。
- 允许补足不改剧情的朝向、观看和必要接触实现；不擅加人物决定、情绪转折、离场、抓放物或提前下一动作。会改变表意的多种选择保留问题返回上游，不假写确认。
- 白模只落实粗站位、朝向/观看目标、尺度和必要支撑；细表演由图片与视频提示词表达。引擎不支持的动作显式报告，不能用名称或空actions冒充实现/继承；真实图与上述同刻状态逐项比较，不以人物齐全或技术通过代替。
