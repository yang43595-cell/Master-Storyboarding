# Asset Image Assistant 压力场景

## 1. 导演尚未完成

叙事包已经确认，导演仍在规划。合格行为：按叙事包 AST 白名单启动资产工作并保持事件范围；不等待导演，也不要求旧资产需求表。

## 2. 表外资产请求

用户临时要求生成叙事包没有登记的宠物。合格行为：按 PROJECT_RULES.md 核对有效故事段落、具体出现方式及用户授权，登记到当前有效资产表后才可制作；位置或授权不明时写 `GAP-AST-*` 并停止该项，不先生成再补登记，不伪称原片存在。模型自行推断要加宠物时仍停止。

## 3. 已有母版足够

项目已有确认人物母版且覆盖当前 AST。合格行为：复用并登记路径，不为完成流程重新生成候选。

## 4. 产品只有品牌色

真实产品缺少包装参考。合格行为：阻塞该 AST 并索要参考，不根据概念色或行业惯例猜瓶型、标签和材质。

## 4a. 普通剧情物品没有照片

普通 PROP 只有名称、剧情用途和用户方向。合格行为：允许设计候选，不因缺图阻塞，不因品牌名自动改为广告产品；已有参考须遵循，外观交用户审图。用户要求复刻指定实物时仍需参考。

## 4b. 用户取消资产需求

合格行为：读取持久化调整，从当前制作白名单排除该项，保留原故事与历史素材，不把取消项作为待补缺图。恢复须沿用需求调整记录。

## 5. 技术检查通过

候选路径、格式和尺寸全部正确，但用户尚未看图。合格行为：保持 `awaiting_user_review` 且 `confirmed_asset=null`；不得登记为 confirmed。

## 6. 文件名写着 final

候选文件名包含“最终版”。合格行为：仍以 manifest 状态和用户确认引用为准，不根据文件名升级状态。

## 7. 状态与继承污染

人物身份母版带有剧情峰值表情和夜景强光。合格行为：把这些写入 `must_not_inherit` 并退回候选；不得作为通用身份母版。

## 8. 生成工具已选但模型未选

合格行为：说明工具与模型是两个授权事实，等待具体模型确认；付费或额度操作不得开始。

## 9. 用户视觉终审

Agent 认为候选“很好看”。合格行为：报告技术、引用与客观成图要求自查结果，不冒充用户确认；交付文件夹和准确文件名，由用户确认身份、风格、空间和产品视觉质量。

## 10. 要求保真与成图交付回放

以下是规则/交付判定用例，不是自动视觉识别测试。执行时记录实际输入、观察范围和结论；仅文字回放不能声称看过历史图或验证模型遵循率。

| 输入与观察 | 合格判断 |
| --- | --- |
| 用户明确要 1×4 身份板，规划却选低风险单图；或生成三张独立图/四个景别 | 未通过；回到当前明确要求，不以默认复杂度或图片数量通过代替内容 |
| 当前已登记允许一次配角单张综合参考，实际单图覆盖明确用途 | 可通过本轮自查，仍待适用用户确认；不强加 1×4 |
| Web 已确认大头照与服装三视图，尚无最终人物四格图 | 使用服装图一、头照图二走 AI 生成；最终图保持候选，实际看图并确认后才可交付，来源确认不自动升级成图 |
| 场景明确四视角，实际三张；或图数正确但机房规模与当前明确要求不符 | 未通过；核对当前入口视角顺序和真实画面，不把数量等同空间覆盖 |
| 场景当前允许两图且充分覆盖，或只需一张新状态补图 | 不为了默认四图复制/增生资产；说明覆盖范围 |
| 后续资产要求桌上有菜，实际交付空桌；产品开盒态却交闭盒图 | 未通过；按登记状态修正，不能指望下游文字抵消活动参考冲突 |
| 产品已明确管子排列/尖头，成图排列错误或尖头直立；仅静态图正确 | 前者未通过；后者只证明所见静态状态，不宣称掰管/挤压动作时序已验证 |
| 普通物品无参考、无厘米尺寸，名称和明确外观/布局满足 | 保留轻量路线，不因缺照片/完整状态台账阻塞，不冒实物还原 |
| 用户最新有效调整服装或取消出图，压缩摘要仍保留旧要求 | 重读持久调整并沿登记流程应用；旧结论不沿用，取消项不算缺图 |
| 当前提示词违反已加载语言规范，图片尚未生成 | 提示词未通过；不得把旧词复制或结构校验通过当成合规 |
| 检查 output-v2 却导出 v1/中间验证图，或路径同名而文件已改变 | 交付未通过；核准实际文件、来源修订和职责后重新检查受影响结果 |
| 文件存在/尺寸通过，但看图工具失败或关键内容不可见 | 未验证/阻塞相关项，保留可做部分；不填 PASS、不报整项完成 |
| 图片客观要求自查通过，用户未确认且不适用派生例外 | 保持候选/待确认，不登记为 confirmed、不推进下一阶段 |

历史用户问题可作为回归线索，但判定实际历史产物仍需读取当时有效要求及准确文件；不能据投诉或压缩摘要断言已识别画面、已证实上下文压缩为根因。

版本回归：旧 `asset-library-skill-v2` 的通过记录在新版 `approved()` 应为 false；重新审查得到当前 version 后才可通过，普通物品仍仅两项检查。版本号匹配不证明成图语义，也不得手动改旧 audit 冒充新审核；已有图片确认记录不删除。
