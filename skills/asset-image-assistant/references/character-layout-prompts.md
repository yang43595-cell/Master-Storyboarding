# 项目人物资产图生成提示词

通用正文按以下顺序供生产入口加载。先绑定原参考，再绑定灰模。按本次造型补充具体信息，参考槽顺序或数量变化时调整对应编号。灰模只约束大致位置和大小。

## 大头照 · 有对标脸

```text
用参考图 1 生成人物正面大头照。参考图 1 是唯一面部身份来源，保留脸型、五官比例、肤色、发际线、发色、发型和实际头饰。按本次已指定的造型要求调整发型或配饰。

参考图 2 是大头照灰模，只参考头部位置和大小。

3:4 竖图。人物正面平视，表情自然放松。完整拍到头顶、发型和头饰，两侧自然裁肩。画面内无衣物、领口或肩带。背景干净，光线均匀。
```

## 服装三视图 · 有对标服装

```text
用参考图 1 制作同一套服装的正面、左侧、背面三视图，保留参考中可见的款式、版型、叠穿层次、颜色、材质、纹样、服装配饰和鞋履。指定的调整按本次要求执行，参考未展示的部分按可见结构延续。

参考图 2 是服装灰模，只参考三格的位置和大小。

4:3 横图，单行三格，从左到右为正面、左侧、背面。三视图同高对齐，主体之间留清楚的空隙。三格用无头隐形人台，从领口到鞋完整入画。领口上方为背景，无头脸、头发或颈部截面。鞋随视角转向，背面能看见鞋后跟。
```

## 大头照 · 无对标脸

在写提示词时把方括号填写成一组具体描述。已有的角色条件照用，其余按角色选择一组特征。

```text
生成一张虚构人物的正面大头照。人物设定：[年龄段与角色气质]。脸型：[具体脸型]。五官：[眉形、眼形与瞳色、鼻形、唇形]。发型：[发色、分线、长度与造型]。头部配饰：[具体头饰或耳饰，无则写无]。

参考图 1 是大头照灰模，只参考头部位置和大小。

3:4 竖图。人物正面平视，表情自然放松。完整拍到头顶、发型和头饰，两侧自然裁肩。画面内无衣物、领口或肩带。背景干净，光线均匀。
```

## 服装三视图 · 无对标服装

在写提示词时确定一套具体穿搭，填写已有要求外的款式、组合和配饰。

```text
为[角色身份与穿着场合]设计一套服装。穿搭设定：[逐件填写款式、颜色、材质和叠穿方式]。鞋履与服装配饰：[选定的鞋和随服装展示的配饰，无则写无]。

参考图 1 是服装灰模，只参考三格的位置和大小。

4:3 横图，单行三格，从左到右为同一套服装的正面、左侧、背面。三视图同高对齐，主体之间留清楚的空隙。款式、颜色、材质、层次和配饰一致。三格用无头隐形人台，从领口到鞋完整入画。领口上方为背景，无头脸、头发或颈部截面。鞋随视角转向，背面能看见鞋后跟。
```
