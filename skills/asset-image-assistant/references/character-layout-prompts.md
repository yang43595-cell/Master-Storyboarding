# 项目人物资产图生成提示词

通用正文按以下顺序供生产入口加载。先绑定原参考，再绑定灰模。按本次造型补充具体信息，参考槽顺序或数量变化时调整对应编号。灰模只约束大致位置和大小。

## 大头照

```text
用参考图 1 生成人物的正面大头照。保留原人物的脸型、五官、肤色、发际线、发型和发色。发夹、发簪等头饰按参考图 1 保留，包括数量、款式和佩戴位置。

参考图 2 是大头照灰模，只参考头部在画面中的位置和大小。输出保留参考图 1 的真人肤色、头发和头饰。

人物正面平视、自然放松。完整拍到头顶和头饰，下沿到锁骨，两侧自然裁肩。发顶和两侧留多少空间，以实际发型和头饰能完整入画为准。
```

## 服装三视图

```text
用参考图 1 制作同一套服装的三视图，从左到右依次是正面、左侧、背面。保留原服装的款式、层次、颜色、材质、纹样、配饰和鞋履。原图中的展示架可省去。

参考图 2 是服装灰模，只参考三格中服装的大致位置和大小。成图的衣服和鞋以参考图 1 为准。

服装像由不可见的人台支撑，领口上方自然是背景，画面里没有头、脸或断颈截面。各格完整展示衣摆和鞋，鞋的方向跟随该格视角，背面格能看到鞋后跟。三格比例协调，留白随服装轮廓调整。
```

## 人物 1×4

```text
在一张 16:9 横图里排成单行四区。从左到右依次是人物正面大头照、服装正面、服装左侧、服装背面。

参考图 1 提供服装、鞋履和服装配饰，保持原有款式、材质和颜色。参考图 2 提供人物身份、肤色、发型和头饰，保留原头饰的数量、款式和佩戴位置。参考图 3 是 1×4 灰模，只参考大头照和三处服装的大致位置与大小。

最左格是一张铺满整格的正面大头照。照片背景连续延伸到左格四边，肩部自然延伸至格底，格内不留白边、不加内边框，不把头照缩成一张嵌进去的小图。完整展示脸、发顶和头饰；头部可略微缩小，为头饰在照片内部留出空间，照片仍铺满左格。右三格像由不可见的人台展示服装，从领口到鞋完整入画，领口上方自然留空，不出现头、脸、头发或断颈截面。左格是整张图唯一出现人物头脸的位置。格宽和留白随实际造型调整。
```
