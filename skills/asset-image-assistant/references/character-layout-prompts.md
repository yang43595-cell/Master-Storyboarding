# 项目人物资产图生成提示词

通用正文按以下顺序供生产入口加载。先绑定原参考，再绑定灰模。按本次造型补充具体信息，参考槽顺序或数量变化时调整对应编号。灰模只约束大致位置和大小。

## 大头照

```text
用参考图 1 生成人物正面大头照，保留其脸型、五官、肤色、发际线、发型、发色和实际头饰。

参考图 2 是大头照灰模，只参考头部位置和大小。

人物平视、自然放松。发顶与头饰完整入画，下沿到锁骨，两侧裁肩。
```

## 服装三视图

```text
用参考图 1 制作同一套服装的正面、左侧、背面三视图，保留款式、层次、颜色、材质、纹样、配饰和鞋，省去展示架。

参考图 2 是服装灰模，只参考三格的位置和大小。

三格用无头隐形人台，从领口到鞋完整入画。领口上方是背景，无颈部截面；鞋随视角转向，背面能看见鞋后跟。
```

## 人物 1×4

```text
16:9 横图单行四格，从左到右为正面大头照、服装正面、左侧、背面。

参考图 1 定服装、鞋履和服装配饰，保留款式、材质和颜色。参考图 2 定脸、肤色、发型和实际头饰，头像无头饰时保持无头饰。参考图 3 是 1×4 灰模，只参考位置和大小。

左格照片铺满，无内框。发顶与头饰完整，下沿止于颈肩交界。右三格用无头隐形人台，服装从领口到鞋完整入画，领口上方是背景，无头脸、头发和颈部截面。
```
