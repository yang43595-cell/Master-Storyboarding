# 宠物与幻想伙伴三视图

`CHARACTER` 表示故事角色，不等于人物制作流程。HUMAN 和 HUMANOID 默认使用人物身份及服装流程；ANIMAL、NON_HUMANOID 和用户明确指定的 PET（宠物／幻想伙伴）使用宠物三视图流程。人形小精灵也可由用户明确归为 PET，不按名称自动修改类型。

每个稳定造型制作一张16:9横图，等宽并排三格：正面、左侧、背面。每格呈现完整头部和身体，四肢、尾巴、翅膀与固定服饰、配件均不能截断。三格的身份、体型、毛色或体表材质、结构、饰品和服装保持一致，角色比例、地面基线一致，背景简洁，采用中性外观姿态。

服饰和配件包含在完整角色中，不拆成人类大头照、无头人台服装或人物1×4。必要造型变化另列三视图，追逐、奔跑、施法、休息等是镜内动作，不机械生成独立外观资产。已有单张外观图可以用作参考，不能因为16:9尺寸合格就当作三视图完成；用户须核对三种视角及结构一致性。

库存统一归入“宠物”；兼容旧“角色外观”记录，但旧单图不自动升级为三视图。内部制作类型保留“角色外观”标识，避免破坏已有任务和历史引用。制作与复用结果都需要当前项目逐项确认；保留 CHR/AST 编号、对白归属与原剧情，分镜和视频沿当前资产清单读取类型与确认素材。
