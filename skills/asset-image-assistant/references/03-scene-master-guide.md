# 通用影视级场景母版构建指南

> 本文件保留类别字段、模板、执行顺序与交付检查。专业判断完整读取 knowledge-profile 绑定的 `ASSET-SCENE-METHOD`（Vault：`projects/Master-Storyboarding/应用知识/图片资产/场景资产方法.md`）；不得只读本文件代替方法。

> 用途：实现当前有效资产表已登记的 `LOCATION` 类 `AST-*`，建立空间关系明确、结构稳定、状态可追踪的场景资产。L0 单图锚定和多数 L1 项目不使用完整流程；没有场景 AST 时不得自行建档。

## 一、交付物

每个场景按等级交付：

| 等级 | 适用场景 | 最小交付原则 |
|---|---|---|
| S 主场景 | 大部分剧情发生、多人调度或动作复杂 | 1 张母图，加 AST 已登记的方向、状态或安全验证 |
| A 重要场景 | 承载关键对话或转折 | 1 张母图，加 AST 已登记的必要方向或状态 |
| B 过渡场景 | 短暂出现、无复杂调度 | 1 至 2 张定场资产，不强制母图和九机位 |
| C 单图空间 | 单一切面、固定微观舞台、无复杂拓扑 | 由 L0 / L1 综合参考图承担，不独立建立场景母版 |

所有独立图必须保留；拼图只用于审查，不代替正式场景母版。

若一张综合参考图已经同时锁定唯一空间、简单角色、色彩和材质，不得为了套用本模板额外生成多机位。

## 二、执行原则

- image2 每次只生成一张资产图；不同机位分别调用，不依赖一次任务输出九张独立图。
- 母图必须先经用户确认，派生机位才可以生成。
- 派生图必须引用同一张母图，并重复空间不可变项。

## 六、固定结构与剧情状态

永久固定项的专业判断见已绑定场景资产方法；状态表只登记本次允许变化项。

### 状态可变

剧情动作可能改变门锁、监控、桌椅、纸张、灯光、液体、泡沫或产品使用状态。为每个状态单独编号：

| 状态编号 | 剧情阶段 | 允许变化 | 仍不可变化 |
|---|---|---|---|
| STATE-A | 日常初始 | 门开、桌椅整齐 | 空间结构、家具款式、柜台位置 |
| STATE-B | 冲突后 | 桌椅移位、纸张落地 | 门窗、通道、核心设备外观 |
| STATE-C | 锁门后 | 门落锁、连接线拔下 | 场景尺寸、资产数量、光源方向 |

状态图只能改变表中允许项，不得重新设计场景。

## 九、已选机位的生成与登记合同

机位职责如何选择见已绑定场景资产方法；环境一致性优先，默认四图是可靠起点。已有视图能覆盖当前机位、遮挡、锚点及空间余量时可少补必要方向，不以临界最少为目标。以下只执行当前需求已选中的验证组；已明确选四图时不擅自减少。

### 9.1 多机位高风险场景的四图锁定

只有资产需求明确存在正反打、明显转机位、俯拍、全景转场或单张母图无法解释空间背面时，才启用四图锁定；简单固定空间不机械补图。

固定生成顺序：

1. 已确认场景母图：作为唯一空间原点。
2. 反向平视回望图：只补全母图未展示的背面环境，不改变入口、功能区、固定资产和光向。
3. 45°俯视斜角全景图：锁定固定资产的远近、区域边界与人物动线。
4. 90°垂直正俯上帝视角图：以前三张已确认图片为参考，形成空间总纲；不得借俯视图重新设计布局。

采用此四图默认配方时，前两张派生图引用场景母图；最后一张按实际需要组合已确认视图。其他充分覆盖方案在现有用途与理由字段说明各图覆盖和余量，依赖登记本次真实使用的参考，不自动上传全部血缘。四张图必须分别保存为独立资产，并在 `asset_manifest.md` 标明环境、背面、远近、总纲等已核验职责；同一图可承担兼容的多项职责。任何派生图出现镜像、资产增减、家具重排或光向变化时，回到母图重新生成，不用文字解释漂移。

### 9.2 侧机位场景图与固定场景锚点


空间中选择一个真实存在、跨镜不移动的固定场景锚点，例如火堆、柱子、柜台、泉眼或门。资产清单登记其位置、朝向、尺度及是否承担主光源职责；后续人物走位、镜头方向和光向都以该锚点校验。不得为了方便定位临时增加原场景不存在的锚点，也不得让锚点在不同机位改变位置或数量。

## 十、9:16 安全验证

仅当项目成片为 9:16 且本次空间用途需要验证时检查竖屏适配；已有图能证明适配时复用，不另加图。其他画幅按实际成片比例核对，不因 S 级要求额外 9:16。需要验证时检查：

- 人物主要站位区在竖屏内有足够宽度和纵深。
- 对峙双方、入口、柜台或核心机制区能够同时读懂。
- 上下留白支持近景、全身和字幕安全区。
- 关键资产不会长期位于竖屏裁切区外。
- 场景不是只在超宽横图中成立。

该图只验证空间适配，不提前承担正式分镜动作。

## 十一、image2 提示词

### 母图

```text
Use case: historical-scene / stylized-concept / scientific-educational
Asset type: AST-XXX 场景母图
Input images: 正式风格母版；如有，真实地点或产品空间参考
Primary request: 生成【场景名称】的【超宽主视觉 / 空间骨架 / 360°母图】，完整解释空间关系
Scene identity: 【一句话空间定义】
Topology: 【四向、入口、通道、功能区、人物动线】
Fixed assets: 【A01...及数量、位置、材质、颜色】
Style lock: 【正式风格前缀】
Lighting and material lock: 【光源、色彩、材质】
State: 【AST 中已登记的 STATE-A 等】
Constraints: 不增加、删除或镜像核心结构；本图用于后续机位唯一空间参考
Avoid: 结构变化、重复入口、资产数量变化、错误文字、风格漂移、鱼眼、过度广角、水印
```

### 派生机位

```text
Use case: identity-preserve / precise-object-edit
Asset type: AST-XXX 已登记方向
Input images: 已确认 AST-XXX 母图，作为唯一空间和视觉参考
Primary request: 基于同一空间重新生成普通透视的【机位职责】
Camera: 【位置、高度、方向、焦距语言】
Fixed invariants: 建筑结构、门窗、通道、家具款式、资产数量、材质、颜色、时间、天气、窗外环境和光源方向不变
State: 【状态编号及仅允许变化项】
Style lock: 【正式风格前缀】
Constraints: 不是母图裁切；本次只改变摄影机位置和构图
Avoid: 球面拉伸、鱼眼、左右镜像、家具重排、核心资产增减、文字乱码、风格变化
```

## 十三、审查板

- 独立机位图先统一尺寸，再由程序拼接。
- 九张时可采用 3×3、4096×4096 审查板，每格 1360×1360、4 像素边框与分隔线。
- 少于九张时按实际数量排列，不为凑九宫格重复机位。
- 审查板用于空间一致性检查，不作为正式母版或分镜输入。

## 十四、本地交付验收

- [ ] 派生机位均引用同一确认母图，且为独立原图。
- [ ] 启用四图锁定时，反向平视回望、45°俯视斜角全景与 90°垂直正俯图按所选顺序生成并登记各控制目标来源；兼容职责可由同图承担。
- [ ] 大幅运镜需要补充空间时，侧机位场景图和固定场景锚点保持位置、尺度与光向一致。
- [ ] 按实际成片画幅核对构图适配；仅 9:16 且当前需求确需时完成竖屏安全验证，已有证据充分可复用。
- [ ] 真实路径、版本和状态已写入资产清单。
