# 通用影视级风格母版构建指南

> 本文件保留类别字段、模板、执行顺序与交付检查。专业判断完整读取 knowledge-profile 绑定的 `ASSET-STYLE-METHOD`（Vault：`projects/Master-Storyboarding/应用知识/图片资产/风格资产方法.md`）；不得只读本文件代替方法。

> 用途：仅在当前有效资产表已登记 `STYLE_REFERENCE` 类 `AST-*` 时建立视觉世界。风格母版决定“如何呈现”，不决定具体角色长相、场景布局或分镜机位，也不自动成为所有项目的前置资产。

## 整片色彩统一（色卡工作流）

> 来源：`vault://wiki/concepts/03-AI生成与视频/色卡统一风格.md`（用户确认的权威方法）。本文只写针对本 Skill 的可执行规则，不复制正文。当叙事包登记 `STYLE_REFERENCE`、或需要整片跨镜头配色一致时，用一张**平面化色卡**锁住整片颜色/色调——这是与背景母版（锁背景）、多角度参考组（锁空间）并列的**第三种一致性路线**。

### 色卡输出合同

**生成色卡**：在截图基础上加"生成色卡"提示词，让模型输出一张扁平化色卡（含默认 10–15、**优先 13**个纯色块，每个色块给准确或近似 HEX）。

### 色卡本身必须满足（喂给生成模型）

- 纯 2D 扁平化数字图形设计；**非**照片/实物/印刷/桌面/3D 渲染/写实材质。
- 色块同水平线、均匀间距、垂直居中、尺寸一致、边缘锐利；每块为单一纯色。
- **禁止**渐变、阴影、描边、纹理、光泽、厚度、透视、立体效果、色块下方阴影、纸张或桌面质感、水彩/插画/手绘感、实物 mockup。
- 每块下方两行小字：第一行 HEX（等宽深灰）；第二行**功能标签**——写颜色在画面中的作用（如 `暖光照射`、`皮革阴影`、`金属暗面`、`布料高光`、`尘土中间调`），**不写颜色名**。
- 构图清晰、整齐、克制，像电影美术圣经/色彩系统说明书/视觉开发参考表，信息项自左到右成色彩逻辑（环境主色与光照色 → 中间调与阴影色 → 材质色 → 强调/特殊功能色）。

### 用途边界

- 色卡只约束"颜色/色调"这一维度；不替代背景母版（锁背景）或多角度参考组（锁场景空间）。三者按需并用。
- 从低分辨率视频帧提取的 HEX 为近似读值，**只作格式示例，不作精确色值引用**；需精确时以人工校样为准。
- 生成的色卡同样走候选→确认流程，登记为风格类 AST，不得直接当确认母版。

## 一、交付物

只交付当前 AST 要求的项目：

1. 一份风格身份卡。
2. 用户要求的候选数量；未指定且需要比较时才准备最少可区分候选。
3. 用户确认后登记的一张正式风格母版。
4. 仅在 AST 明确要求时制作独立验证图。
5. 一份 image2 可复用风格前缀。
6. 一份风格边界与完成条件；只有存在真实风险时才附模型专用负面字段。
7. 一张程序拼接的风格审查板；独立原图必须同时保留。

## 七、正式风格前缀

用户确认后，把风格压缩成可复用前缀。前缀必须覆盖：

```text
【风格名称】，统一【美术媒介】，【线条语言】，【人物比例】，【色彩体系】，【光影体系】，【材质语言】，【细节密度】，【表情尺度】，【时代与成像质感】。所有人物、场景、道具和产品必须延续该风格，不得转为其他媒介、比例或材质复杂度。
```

前缀不包含具体人物动作、场景布局、镜头景别或剧情事件。
