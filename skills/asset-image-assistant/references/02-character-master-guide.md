# 通用影视级人物母版构建指南

> 本文件保留类别字段、模板、执行顺序与交付检查。专业判断完整读取 knowledge-profile 绑定的 `ASSET-CHARACTER-METHOD`（仓库内置包相对路径 `projects/Master-Storyboarding/应用知识/图片资产/人物资产方法.md`）；不得只读本文件代替方法。

> 用途：实现当前有效资产表已登记的 `CHARACTER` 类 `AST-*`。人物母版用于后续身份引用，不承担剧情表演镜头；没有人物 AST 时不得按角色名自行建档。

## 一、输入

- 本项目已确认的风格决定；有适用风格母版和前缀时继承，不为人物制作新增独立风格 AST。
- 叙事包角色表、身份、年龄、关系、欲望和时代背景。
- 用户提供的人物参考图、服装参考或现实原型；存在时必须先查看并登记路径。
- 产品拟人角色还必须读取真实产品参考图和对应产品 brief。

## 三、先选择本次人物输出职责

普通一次配角或低风险人物可使用一张已核对用途的综合参考，不强制大头照、服装三视图与1×4。已确认资产表判断无需独立图时只在镜内描述，不创建图片资产。只有当前需求或所选路线确需身份与服装板时执行以下三步；单图按本次用途选择画幅，不套用1×4画布验收。

用户或有效上游明确要求1×4时，不能用单图例外降低最终规格；缺少来源视图应继续补齐该路线。最终规格登记与两处检查统一见 [`asset-method.md`](../modules/asset-method.md#本轮要求到实际成图的自查)，本指南不另建检查或审批流程。

## 四、身份板路线生成顺序（三步：先脸 → 再衣服 → 最后合成 1×4）

选择身份板路线时按以下来源依赖制作；项目 Web 与独立资产库的最终人物板均由 AI 生成，项目入口见 `../modules/project-web-mode.md`：

1. **先单独出"大脸身份母图"**：按身份卡与本轮已授权数量制作候选；**用户确认一张身份母图**。本轮新制的转面/全身/表情验证图沿用此身份，不凭文字重新设计；完成并确认 1×4 后，下游实际引用按 §五的共享规则选择，不要求重复上传独立头照。
2. **再制作对应服装三视图**：引用确认身份并遵循当前服装设定，使用无头无脸人台，在一张图内展示同一套服装的正面、左侧和背面，包含完整鞋履与配饰；用户确认该服装来源。额外全身、转面或表情验证仅在当前需求明确需要时制作，不替代这张无头服装来源。
3. **最后合成 1×4 身份资产板**：把已确认且清晰的独立大头照 + 对应已确认独立无头服装视图，按 16:9 1×4 合成统一身份资产板（构图规则见 §五）。首次、返修与换装均回到这两项来源，不使用先前的 1×4 或板内裁脸；头像或服装不合格时先按共享“返修参考与固定基准”回原始参考/获准文本设计重做，缺来源不从失败板补造。

- 每次派生只改变一个维度：角度、构图、表情或服装状态。
- 任何本轮不接受的瑕疵都按共享返修规则回该项原始来源重抽，不只身份漂移；失败结果不作下一轮输入，也不反向覆盖来源。

## 五、1×4 人物身份资产板

正式人物身份资产板以 **接近 `16:9` 的横向画布、单行大致四区 `1×4`** 为目标：最左格为高清头部特写（唯一可信面部来源），右侧正面/侧面/背面为从颈部以下开始的无头身体视图，只提供身体、比例与服装信息。**完整构图、画布比例与"唯一面部来源"规则以 [`image-continuity-hard-rules.md`](../../storyboard-director/references/image-continuity-hard-rules.md) 为准**，本指南不重复抄录，只补充角色专属三点：

1. **它是一张职责统一的身份资产**，不是把四张候选图随意拼接成审查拼图；四格必须来自同一已确认身份母图（大脸）及其派生的无头身体视图（见 §四 生成顺序）。
2. **生成后记录实际尺寸与宽高比，目标为接近 `16:9` 的横向画布**；允许少量像素取整差，不因分格宽度微差返工；`4:1` 超宽或明显比例失真仍不合格。单图不适用此限制。
3. **四格必须中性背景、均匀平光、无透视夸张**，且保持同一人物的身高、体型、肩宽、头身比例、服装、材质、配饰和鞋履一致——否则大特写与身体中远景会因景深、背景与透视差异显得不像同一人。

## 九、image2 提示词结构

先确定当前输出，只从下表取对应一行的画幅与构图。不要把其他输出的排版要求复制进本项；最终人物板使用独立确认的服装图和头照由 AI 生成，不用本地裁切拼版替代。

| 当前输出 | 画幅与构图 | 输入职责 |
|---|---|---|
| 综合单图 | 按本次用途选择画幅、景别与姿态，不套用网格 | 获准设计依据或现有适用参考，固定本次身份与服装 |
| 独立大头照 | 3:4 竖图，完整头顶至锁骨下缘，两侧裁肩；仅头颈锁骨区域，画面内无衣物 | 身份参考只锁脸与发型；无参考设计沿用明确许可 |
| 无头服装三视图 | 16:9 横图，正面、左侧、背面三格；无头无脸人台，完整展示同一套衣服、鞋履与配饰 | 确认头照只锁人物身份；服装遵循已确认设定或对应实物参考 |
| 人物1×4 | 接近16:9横图、单行四区；左格头顶至颈肩交界的唯一脸部特写，右三格为颈部以下的正、侧、背身体视图 | 图一为对应确认服装，图二为独立确认头照；不使用旧板或板内裁脸 |

```text
Asset type: 【本次输出类型】
Input images: 【本次实际输入与各自职责；无参考设计则写明确设计依据】
Primary request: 制作【人物名称】的【本次输出】
Identity and wardrobe: 【本项适用的已锁定身份、体型与服装；未锁定外观给出单一设计候选】
Style lock: 【当前正式风格；光线与材质写成可观察描述】
Canvas and composition: 【仅填写上表所选输出的画幅与构图】
Preserve and change: 【需要继承的内容与本次指定变化】
```

有本次真实风险时，按 `../../voiceover-to-video-script/references/prompt-language-hard-rules.md` 加少量专项排除约束并选择实际支持的通道；没有风险不附通用 Avoid 词包。实际尺寸、验收结论和内部 AST 编号留在制作记录，不写入提交正文。

## 十、本地交付验收

单图路线核对实际身份、服装、用途、状态与确认依据；下列排版项目仅适用于身份板路线。

- [ ] 人物身份资产板实际画布接近 16:9 横向比例，准确记录尺寸并允许少量像素取整差；1×4 仅表示画布内单行四格排布，不是 4:1 画布。
- [ ] 人物身份资产板为单行大致四区 1×4，不要求严格等宽或精确分隔坐标，最左格是唯一高清头部特写；下沿在颈肩交界，不出现胸口、上半身、手臂或半身构图。
- [ ] 右侧正面、侧面、背面身体视图均从颈部以下开始，没有头部、脸、头发或可辨识五官。
- [ ] 实际生成输入命中共享返修规则；1×4 的独立服装与大头照来源清晰、已确认，未输入旧板或板内裁脸。
- [ ] 独立原图存在，并在资产清单中标为 `有效`。
