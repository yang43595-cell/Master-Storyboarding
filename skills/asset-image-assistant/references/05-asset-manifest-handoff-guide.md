# 视觉资产清单合同

项目使用 `visual-asset-manifest.json`，结构遵循 `schemas/visual-asset-manifest.schema.json`。该清单是候选、确认状态和下游引用的唯一资产事实，不使用文件名或目录猜状态。

## 来源白名单

- `source_narrative` 保留兼容，指向同修订已确认叙事包。独立资产表来源 artifact、revision、路径和校验值写入用户确认记录的 `source_asset_table`；产物登记同时依赖 `narrative.assets`，表变化须重新核对交接。
- `source_asset_requirement_ids` 是本轮有效 AST 白名单，由已确认资产表结合按 PROJECT_RULES.md 授权分支核对并登记的用户调整生成；保留原始来源与调整依据，不把新增项伪称为原叙事包事实。
- `assets[].asset_id` 必须属于该白名单；未经授权或尚未核对登记的表外请求写入 `scope_gaps`，不得先创建资产条目；取消项按需求调整记录排除，不列作缺图。

## 每项资产

必须登记：

- `asset_id`、类别、名称和状态；
- 事件适用范围与可选镜头范围；
- 交互、展示面、朝向和所需状态；
- 必须继承与不可继承内容；
- 真实参考路径；普通剧情物品无参考时记录无参考及设计依据，不编造路径或实物核验结论；
- 独立候选、技术检查和可选生成授权记录；
- 用户确认后才存在的 `confirmed_asset`。

`must_not_inherit` 用于排除不应进入母版或其他镜头的剧情状态，例如特定表情、动作、污损、强剧情布光、临时构图、背景人物或文字。

## 状态规则

- `missing`：登记需求尚无可用候选。
- `candidate` / `awaiting_user_review`：未获用户确认。
- `confirmed`：必须同时存在确认候选、真实路径和 `user_confirmation_ref`。
- `stale` / `rejected` / `blocked`：不得作为当前下游输入。

生成成功、技术检查通过、审核通过、文件位于母版目录，均不能单独构成 `confirmed`。

## 技术检查与用户终审

Agent 检查路径存在、格式、实际尺寸、命名、来源可追溯和明显产品事实，并按 asset-method 的成图自查实看所选图片是否满足当前可观察要求；检查结论与用户终审分开。用户负责身份是否正确、画风是否接受、空间是否可信、产品是否视觉准确等视觉质量判断。

用户审核交付只包含文件夹绝对路径、准确文件名、对应 AST 和审核职责，不嵌入图片载荷。

## 下游读取

下游只能引用 confirmed 状态资产的 `confirmed_asset.path` 或 `confirmed_outputs[].path`，并遵守适用范围、必须继承和不可继承内容。不得从候选目录随机挑图，也不得绕过清单重建人物、场景、产品或道具事实。

1.1 清单保留 `confirmed_asset` 作为兼容主图入口，`confirmed_outputs` 为同一 AST 的必要独立图片组，每项含 output_id、purpose、state、view 及具体用户确认引用。下游需要某状态或视角时按这些字段匹配，不能把主图冒充未提供的视角。旧 1.0 清单没有此字段时只提供原有主图，不推测有其他图片。

用户明确新增、删除和恢复资产需求时，执行 PROJECT_RULES.md 的“用户调整资产图需求”。该授权分支允许按已核对出现位置加入需求表，不适用“表外一律停止”的自动推断限制；未授权的新物件仍须停止。下游读取 asset_requirement_decisions，取消项不是缺图，新增项须沿用其出现范围。

## 交付版本核对

导出前从当前登记记录定位实际选定的 AST、output_id、来源修订、用途/状态/视角及文件，实看交付文件与已检查结果一致；旧兼容主图只按其已登记范围使用。不能按“最新文件”或文件名猜选，也不能把中间验证图、少一张的组图、已替换版本冒充最终输出。文件或版本有变化时重新核对受影响结果，旧审核结论不自动沿用；保持原确认边界，Web 已确认来源本地拼装的派生例外按该入口执行，不伪造独立确认。

未完成、未验证和阻塞项写在现有记录及交付说明中，区分已就绪范围与缺口，不报整项完成。交给下游的是准确文件与职责，不是笼统“素材已齐”。本 Skill 不操作画布；实际上传后的原生引用、保存和刷新回读由承担上传的阶段核对，未执行时不得宣称已上传验证。
