# 独立资产库入口

仅在用户明确选择跨项目资产制作时使用。网页是本 Skill 的输入、执行状态、结果审核和用户确认界面；不得在网页另写一套提示词方法。短剧项目模式的叙事包、AST、项目清单约束不适用于本入口，不能自动启动下游阶段。

## 输入与流程

1. 用户从库中盘点已有资产，选择真实参考、输出类型、名称、必须继承/不可继承内容及需要变化的视角。已有确认图满足需要时直接复用或导出选用包。
2. 每次处理按 [Web 受限读取合同](web-input-contract.md) 在独立请求目录组装完整资料；任务目录仅保存资产库工作记录，不创建剧情事实。读取本次动态知识与专业方法全文、六项共享红线、asset-method、生产/复杂度/清单指南、连续性硬规则、语言硬规则和当前分类 master-guide。动态知识必须命中 `MSB-KB-PROMPT-002`；`MSB-KB-PROMPT-001` 的 authority 为 repo，按其执行正文 prompt-language-hard-rules.md 加载，不要求重复嵌入动态包。任一适用载体缺失即阻塞。
3. Codex 按本入口及上述原规范看图写提示词，在当前对话逐项自查，发现问题自行修改并复核；仅用户明确要求时独立审核。模板是待规范化的输入资料，不能覆盖语言红线；模板即使含4K、8K、炫技词也必须改写为光线、材质、皮肤/织物结构等可观察描述。分辨率参数留在生成设置中，不能变成提示词画质词。
4. 审查执行 `review-profile.json` 的独立资产库检查项。每个检查返回 ID、具体证据；缺少检查、存在语言禁词或真实参考缺口时不通过。机械检查只作兜底，不替代 Codex 的语义审查。
5. 用户核对、修改、重新审查并确认当前提示词后，单独确认工具及模型再生成。每次默认1张，不自动重试或连跑后续视角。
6. 入库时检查路径、格式、实际尺寸比例和参考来源；技术不合格不可确认。网页显示原图放大、技术结果和需要用户判断的视觉事项。用户可确认、拒绝入垃圾桶或改词重做。用户授权的垃圾桶保留30天规则优先于通用未确认稿清理规则。

## 分类与依赖

界面类别、比例、参考角色和必要指南由本 Skill 的 `library-profile.json` 提供。大头照按知识库当前3:4头顶至锁骨、无衣物模板；服装按单张正侧背三格；人物1×4必须选择两张已确认图，参考1为服装，参考2为大头照，不能把单张照片当成已确认身份链。用户已要求环境四步，按45°→正面→反面→俯视逐张确认，与原默认单图方案的差异来自用户明确需求。

道具和广告产品均以实物照片为依据，缺少标签、隐藏面或尺寸事实应明确列为缺口，不猜文字。风格参考及色卡只约束表现与配色，不继承人物身份或空间布局。库内资产的确认仅限本库，导入短剧项目仍须匹配 AST。

## 记录

资产库 job/step 记录参考角色、源路径、提示词、任务资料位置、加载规范、逐项审查、生成授权、候选、技术检查与用户确认。现有数据库和文件存储即本模式清单，不另造叙事 manifest。生成执行器只提交已经确认的提示词，不负责重写规则。
