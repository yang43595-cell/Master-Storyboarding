# Web 受限读取合同

只适用于本 Skill 的独立资产库与项目资产网页入口。它按 PROJECT_RULES 的受限读取约定替代本轮 stage_context_cli prepare / ensure-prepared，不与普通对话准备包并行使用。普通对话入口不变。

## 资料与职责

`library_runtime.prepare(folder, request)` 是网页唯一的模型资料入口。名称保留给现有调用方；它组装输入，不执行 stage CLI、不登记 agent 阅读声明。项目事实由原项目接收与确认代码核验；请求目录只保存当前制作项的工作记录，不能写项目执行上下文或修改上游事实。

输入必须包含当前制作项、相关 AST 与事实（项目模式）、已提供的真实参考及其角色、无参考设计许可、当前模式的本地合同、独立模板或分类模板、适用专业方法全文、动态知识全文。连续性从实际制作项类别选用对应指南和专业方法。共用的实看、参考冲突和返修检查始终保留，补图切点和平台原生首尾帧由各自操作入口读取。允许首张候选设计时，真实参考可为空；派生图和实物还原仍须相应参考。运行时按实际输出类型和 AST 类别计算方法范围，从仓库 `knowledge/runtime/` 解析 knowledge-profile 选中的方法和适用模板。真实参考文件按本次请求及资产登记核对，资产存储目录仅用于媒体。

本地合同、模板、必需动态规则或适用方法缺失、为空、不适用或存在阻断冲突时，在模型调用前失败；不得以旧路径、旧快照、跳过标记或空正文继续。已组装的 task-package 仅是该请求的只读输入记录，不是第二份可编辑方法。

Web 输入一并提供灯光本地合同，供执行者在身份、材质、空间或光向涉及风险时核对对应条目；不加载导演规划专业方法，不扩大资产职责。

## 单次执行

上下文压缩或恢复后，按输入包知识读取合同中的“压缩后的主动恢复核对”逐项处理；该通用恢复段不在单项裁剪范围。只核本次制作项及当前模式的适用内容，不以恢复为由重建普通 prepare、读取凭据或新增采用/生成授权。

单项写词输入按源文件二级标题排除项目目录表、历史双文件交付、导演后的视觉检查和资产后续交接；这些仍在原文件由相应操作使用，批量盘点保留本项适用内容。单项写词和项目盘点的知识读取合同只保留仓库知识根、读取证据复用与主动恢复核对，普通 prepare、图片批次命令、局部维护和计量按各自入口读取。图片连续性共用页在写词与盘点的模型输入中保留检查正文，跨阶段导航留在仓库供定位。等待与工具回传由宿主协调方在执行分工中读取。其余正文逐字保留，尤其产品参考、用户调整、身份与状态、连续性、语言、自查和批准边界；专业方法与动态知识全文不裁剪。旧模板保留原件路径与来源哈希，执行时按现行语言和模式合同统一规范化画质词及场景图号；草稿与 task-package 使用同一份规范化正文，不再同时输入两套图号。同一分类指南同时承担本地规则与模板时，仅在 rules 保留一次完整正文，production_item.template 用准确 content_ref、路径与哈希引用该正文，不重复装载也不省略阅读。缺失文件仍按原入口阻断，不用摘录替代检查。

准备提示词前，用户可为当前制作项填写可选的生成方向（如服装款式、场景外观）。随制作项保存并送入输入包；修改后须核对新的生成输入，重新准备。方向属于本次设计需求，与已确认身份、产品实物或故事事实冲突时集中报告，不修改已确认上游。

单项写词只加载当前制作项适用的制作合同、分类指南、模板、连续性与语言规则、专业方法和动态知识。盘点、复杂度拆分、导出交接和路径交付说明由对应操作读取，不重复进入每项写词输入。首张无参考场景使用场景分类指南；派生视角模板必须具备参考母图，调用模型前校验。

写词使用本次完整任务包、原稿和有序参考。按当前提示词和授权提交生成，保留任务输入与输出。技术检查和格式转换在展示候选前完成。用户通过的准确文件直接用于后续生产。

## 维护边界

制作方法正文和模板随仓库维护，绑定在 knowledge-profile 登记。library-profile 保留输出类型、模板与所需方法 ID，运行时负责解析。迁移或改版时验证两种网页模式的真实资料组装、缺失阻断和原确认门槛，不用模拟 CLI 成功代替读取验证。既有确认图片与记录不因方法改版而删除或重新确认；新写词与修改稿使用当前版本规则。

网页批量准备提示词及生成图片最多并行 3 项。前置参考须已确认。单项失败单独记录，生成失败不重复提交。
