# Web 受限读取合同

只适用于本 Skill 的独立资产库与项目资产网页入口。它按 PROJECT_RULES 的受限读取约定替代本轮 stage_context_cli prepare / ensure-prepared，不与普通对话准备包并行使用。普通对话入口不变。

## 资料与职责

`library_runtime.prepare(folder, request)` 是网页唯一的模型资料入口。名称保留给现有调用方；它组装输入，不执行 stage CLI、不登记 agent 阅读声明。项目事实由原项目接收与确认代码核验；请求目录只保存当前制作项的工作记录，不能写项目执行上下文或修改上游事实。

输入必须包含当前制作项、相关 AST 与事实（项目模式）、已提供的真实参考及其角色、无参考设计许可、当前模式的本地合同、独立模板或分类模板、适用专业方法全文、动态知识全文、对应自查项。允许首张候选设计时，真实参考可为空；派生图和实物还原仍须相应参考。运行时按实际输出类型和 AST 类别计算方法范围，从仓库 `knowledge/runtime/` 解析 knowledge-profile 选中的方法和适用模板。真实参考文件按本次请求及资产登记核对，资产存储目录仅用于媒体。

本地合同、模板、必需动态规则或适用方法缺失、为空、不适用或存在阻断冲突时，在模型调用前失败；不得以旧路径、旧快照、跳过标记或空正文继续。已组装的 task-package 仅是该请求的只读输入记录，不是第二份可编辑方法。

Web 输入一并提供灯光本地合同，供执行者在身份、材质、空间或光向涉及风险时核对对应条目；不加载导演规划专业方法，不扩大资产职责。

## 单次执行

上下文压缩或恢复后，按输入包知识读取合同中的“压缩后的主动恢复核对”逐项处理；该通用恢复段不在单项裁剪范围。只核本次制作项及当前模式的适用内容，不以恢复为由重建普通 prepare、读取凭据或新增采用/生成授权。

单项写词和审查只把当前制作约束交给模型。执行分工、三层治理、完整画布流程、普通准备与跨段视频操作由原入口执行，单项输入保留确切恢复章节、候选及确认边界、产品参考、用户调整、身份、状态、连续性和语言规则。节选保留原文，引用的本地文件仍须可读且非空，专业方法及动态知识全文照常提供。整表盘点沿用完整输入。

模板沿用原件路径及来源哈希。旧模板按当前语言和场景图号口径处理；当前稿与任务包内模板完全相同时直接引用该模板正文，实际改稿单独提供；每次调用仍保存准确的当前稿。项目 AST 直接取单项 requirement 或整表 rows，不在 narrative 重复。分类指南同时是模板时以 content_ref 引用同一份原文；人物灰模路线只把对应制作项的已选模板正文交给模型。

准备提示词前，用户可为当前制作项填写可选的生成方向（如服装款式、场景外观）。随制作项保存并送入输入包；修改后旧提示词审查和生成授权失效，重新准备。方向属于本次设计需求，与已确认身份、产品实物或故事事实冲突时集中报告，不修改已确认上游。

单项写词与审查只加载当前制作项适用的制作合同、分类指南、模板、连续性与语言规则、专业方法和动态知识。盘点、复杂度拆分、导出交接和路径交付说明由对应操作读取，不重复进入每项写词输入。首张无参考场景使用场景分类指南；派生视角模板必须具备参考母图，调用模型前校验。

执行者完整阅读本次 task-package 中的正文并查看全部参考图，撰写模式在同一次调用内写稿、自查和修正；审查模式只回判断、检查证据、问题和建议，由程序绑定本次输入原文，不要求模型复述正文。旧格式意外返回改写稿时仍只保存为待采用建议，未获重新审查不得批准。每次调用保留输入正文快照。KB-COMPLIANCE 写具体采用方法及适用结果；无法读取或无法解决的冲突必须报告并不通过。程序只核对输入完整性与检查结果，不证明模型理解或视觉质量。

skill-evidence 的 input_complete 只表示资料组装完成；attestation 明确为 input_assembled_not_agent_reading，不产生 method_reading_evidence.json。技术核对、提示词用户确认、工具/模型/上传及额度授权、图片视觉确认仍由原流程分别执行。

## 维护边界

制作方法正文和模板随仓库维护，绑定在 knowledge-profile 登记。library-profile 保留输出类型、模板与所需方法 ID，运行时负责解析。迁移或改版时验证两种网页模式的真实资料组装、缺失阻断和原确认门槛，不用模拟 CLI 成功代替读取验证。既有确认图片与记录不因方法改版而删除或重新确认；新写词与修改稿使用当前版本规则。

网页批量准备提示词及生成图片最多并行 3 项，只接收前置图片已确认的制作项；写词时允许Luna对可修正问题或缺失的自查结论自动补查一次；不编造检查证据，仍未解决就明确列缺项及处理方式。审查不得擅自替换用户原文；用户选择自动修复时保留旧提示词。建议栏可为空，不作为失败条件。单项失败不阻断其余项，生成失败不重复提交，全部结束后汇总结果。
