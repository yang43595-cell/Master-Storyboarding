# Web 受限读取合同

只适用于本 Skill 的独立资产库与项目资产网页入口。它按 PROJECT_RULES 的受限读取约定替代本轮 stage_context_cli prepare / ensure-prepared，不与普通对话准备包并行使用。普通对话入口不变。

## 资料与职责

`library_runtime.prepare(folder, request)` 是网页唯一的模型资料入口。名称保留给现有调用方；它组装输入，不执行 stage CLI、不登记 agent 阅读声明。项目事实由原项目接收与确认代码核验；请求目录只保存当前制作项的工作记录，不能写项目执行上下文或修改上游事实。

输入必须包含当前制作项、相关 AST 与事实（项目模式）、已提供的真实参考及其角色、无参考设计许可、当前模式的本地合同、独立模板或分类模板、适用专业方法全文、动态知识全文、对应自查项。允许首张候选设计时，真实参考可为空；派生图和实物还原仍须相应参考。运行时按实际输出类型和 AST 类别计算方法范围，按 knowledge-profile 的路径、状态、条件解析完整方法；不从旧提示词补回模板，不扫描经验补造事实。

本地合同、模板、必需动态规则或适用方法缺失、为空、不适用或存在阻断冲突时，在模型调用前失败；不得以旧路径、旧快照、跳过标记或空正文继续。已组装的 task-package 仅是该请求的只读输入记录，不是第二份可编辑方法。

Web 输入一并提供灯光本地合同，供执行者在身份、材质、空间或光向涉及风险时核对对应条目；不加载导演规划专业方法，不扩大资产职责。

## 单次执行

单项写词输入按源文件二级标题排除项目目录表、编导/导演双文件串行交付、导演后的生产顺序、资产后续交接，以及普通准备流程的局部维护和读取计量章节；这些仍在原文件由相应操作使用，批量盘点不裁剪。其余正文逐字保留，尤其产品参考、用户调整、身份与状态、连续性、语言、自查和批准边界；专业方法与动态知识全文不裁剪。旧模板保留原件路径与来源哈希，执行时按现行语言和模式合同统一规范化画质词及场景图号；草稿与 task-package 使用同一份规范化正文，不再同时输入两套图号。同一分类指南同时承担本地规则与模板时，仅在 rules 保留一次完整正文，production_item.template 用准确 content_ref、路径与哈希引用该正文，不重复装载也不省略阅读。缺失文件仍按原入口阻断，不用摘录替代检查。

准备提示词前，用户可为当前制作项填写可选的生成方向（如服装款式、场景外观）。随制作项保存并送入输入包；修改后旧提示词审查和生成授权失效，重新准备。方向属于本次设计需求，与已确认身份、产品实物或故事事实冲突时集中报告，不修改已确认上游。

单项写词与审查只加载当前制作项适用的制作合同、分类指南、模板、连续性与语言规则、专业方法和动态知识。盘点、复杂度拆分、导出交接和路径交付说明由对应操作读取，不重复进入每项写词输入。首张无参考场景使用场景分类指南；派生视角模板必须具备参考母图，调用模型前校验。

执行者完整阅读本次 task-package 中的正文并查看全部参考图，撰写模式在同一次调用内写稿、自查和修正；审查模式只检查当前原文，逐字保留正文，把问题与建议单独列出，不覆盖用户修改。模型意外返回改写稿时仅保存为待采用建议，不据此批准原稿；用户明确采用到编辑框并保存后重新审查。每次调用保留输入正文快照。KB-COMPLIANCE 写具体采用方法及适用结果；无法读取或无法解决的冲突必须报告并不通过。程序只核对输入完整性与检查结果，不证明模型理解或视觉质量。

skill-evidence 的 input_complete 只表示资料组装完成；attestation 明确为 input_assembled_not_agent_reading，不产生 method_reading_evidence.json。技术核对、提示词用户确认、工具/模型/上传及额度授权、图片视觉确认仍由原流程分别执行。

## 维护边界

方法正文只在 Vault 编辑，绑定只在 knowledge-profile 维护。library-profile 保留输出类型、模板与所需方法 ID，运行时负责解析。迁移或改版时验证两种网页模式的真实资料组装、缺失阻断和原确认门槛，不用模拟 CLI 成功代替读取验证。既有确认图片与记录不因方法改版而删除或重新确认；新写词与修改稿使用当前版本规则。

网页批量准备提示词及生成图片最多并行 3 项，只接收前置图片已确认的制作项；写词时允许Luna对可修正问题或缺失的自查结论自动补查一次；不编造检查证据，仍未解决就明确列缺项及处理方式。审查不得擅自替换用户原文；用户选择自动修复时保留旧提示词。建议栏可为空，不作为失败条件。单项失败不阻断其余项，生成失败不重复提交，全部结束后汇总结果。
