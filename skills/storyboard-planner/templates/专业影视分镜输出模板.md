# 通用排版方案

阅读顺序：全片总则 → 每场设定与连贯视听展开 → 逐镜卡片 → 核对记录。全片共用信息写一次，每场共用信息写一次，每镜只写具体决定和例外。不规定页数、镜头数或强制字数，复杂动作按信息需要展开。

采用两列表格卡片，避免六列长文字横向挤压。镜号作为三级标题，场景作为二级标题。来源编号紧凑一行，不再另做全量镜头速览、Beat 表、Panel 表、对白承载表或逐镜删除测试。按方法先检查表达遗漏，再比较拍法与精简重复；核对记录保留本轮关键判断和待解决问题。

## 可选阅读排版

保留 document_type、schema_version（4.0）、project_id、revision、status、source_narrative_artifact_id、source_narrative_revision 的文件头。

```markdown
# <项目>导演镜头方案

## 全片总则
输入版本、画幅、视角、摄影与声音原则、节奏和时间依据。没有权威逐句录音时间窗时统一注明未实测；有局部权威时间窗时标在相关对白。估算不用过细小数制造精度。

## 全片统筹与本轮范围
简述各创作段落的作用、情绪走向、来源范围与前后衔接；标明本轮细写范围、已完成与待完成部分。确认版本、范围及依据沿用现有记录，不以全片统筹代替未写段落。创作段落可小于场景，同场景保留共用设定和连续镜号。

## S01｜<场景名>
来源：STP-*；场景资产：AST-*。

**场景设定**：时间地点，人物与关键物体位置、视线轴与屏幕方向、空间锚点、灯光、环境声与音乐。跨时空省略明确前后状态。

**视听展开**：先写连贯的画面、表演、声音与情绪变化，决定剪辑和连续运镜，再标回镜号。表格细化这些决定；修改拍法时两处同步。此段不重复整份对白，只标必要切点词句。

### S01-010｜<镜头标题>
| 项目 | 导演决定 |
|---|---|
| 来源 | STP-*；DLG-* 或无；本镜涉及的 AST-*（含场景） |
| 表达目的 | 因为此刻发生什么变化，所以让观众看谁、获得什么信息或感受 |
| 摄影机与画面 | 景别、机位、构图、方向、焦点、静止或连续运镜；变化交代路径与终点 |
| 镜内过程 | **起**：开始状态。**过程**：人物与物体连续动作，复杂动作包含关键中间状态。**止**：结束画面及状态变化结果。 |
| 对白与声音 | DLG-*／说话人／画内或画外等方式：“本镜实际承载的原文片段”；按需注明已选定的声音表演（结构化为 delivery，不写入对白原文）；特殊动作声。光色、环境、音乐仅写相对场景的例外。 |
| 切点与节奏 | 从何处接入，在什么动作或词句切向哪一镜及原因；关键停留或粗估。声音提前进入或延续到下一镜需明确。 |

## 核对记录
先保留本轮关键表达判断：哪处变化由哪些实际画面、表演、声音和停留承载，重要取舍为何成立、仍有什么风险；指向已有镜头即可，不重述全稿或另建评分表。若只完成对白或连续性核对，表达审查如实记未完成。随后写紧凑 STP → 镜号对照（含无对白动作和外部接口）、对白文字／说话者／顺序核对结果、真实未决缺口及受影响镜头。
自查与用户确认分别写明范围；未确认写待审。本轮检查当前段落及跨段依赖，全部段落完成后复核全片覆盖、节奏与衔接。JSON 在全片确认与复核完成后生成，不重复方法读取日志、哈希或机器字段说明。
```

## 继承与信息底线

- 每镜继承所属场景的灯光、环境声、音乐。单镜例外不隐式延续到后镜；持续变化标清镜头范围，在对应各镜合同中落实。空音乐列表表示无音乐，省略表示继承。
- 起／过程／止始终可辨，固定镜头也明确起止相同或变化结果。人物位置、站坐、持物归属、开合、离场变化必须有明确结果；关键中间动作不另建 Panel 编号。
- 跨镜对白保留实际片段、说话人和呈现方式，按播放顺序拼接逐字还原上游对白，不用编号代替片段边界。
- 下游处理单镜时同时读取全片总则和所属场景，不自行补拍法。

## 结构化交付

创作直接维护 schemas/storyboard-package.schema.json v4 的完整 JSON，按项目逐场流程完成全片确认与复核；上述排版仅按需导出，不补造 Beat、Panel、删除测试或第二份连续性登记表。字段映射见本地执行合同。旧 v1/v2/v3 只读兼容，不自动回写已确认稿。
