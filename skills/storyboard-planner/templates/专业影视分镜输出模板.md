# 导演包 5.0 模板

JSON 是业务正本，阅读版由工具从 JSON 生成，不反向改稿。字段含义见[镜头规划的字段写法](../modules/shot-planning.md#导演包-50-字段写法)。一次 `put-scene` 写一个完整场次；下例是虚构写法示例，不是项目台词。

## 全片头部（`init --header`）

```json
{
  "director_rules": {
    "aspect_and_exhibition": "竖屏 9:16 手机观看：主体居中偏上，字幕区留下缘约五分之一，景别比横屏收紧一级。",

    "camera_principle": "情绪升级才动机位，平时稳定观察。",
    "editing_rhythm": "全片约 60 秒：S01 约 12 秒、S02 约 20 秒……",
    "light_color_intent": "傍晚暖窗光对冷室内，冲突时冷光占比加大。",
    "sound_principle": "对白优先，环境声只留钟表与窗外车声。",
    "technical_constraint_status": "unknown_director_intent_only"
  }
}
```

要点：
- 来源段落、对白说话人和原文、每镜对白编号由工具补齐；一句跨镜时每镜写本镜片段，按顺序拼回原句。
- 画幅规则只在 `director_rules` 写一次；焦点只在有要求时写。
- `audiovisual_flow` 只写整场走向，不复述镜头。
- 同场分多次修改仍是同一个 `scene_id`，用 `put-scene` 整场覆盖。
- 候选比较、知识应用和自查结论留在核对记录，不写进镜头字段；仅核对白或结构时，表达审查如实记未完成。
