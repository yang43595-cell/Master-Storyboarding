# 画面构思与拍法选择（实战精要）

用于实质创作与拍法返修：从整场人物目标、阻力和关系前后态出发，找可见载体并定观看路线，不逐句配镜。

## 1. 让观众怎样经历变化

先排日常观看顺序：“先看到什么 → 哪个刺激发生 → 注意力转给谁或什么 → 最后留下什么”。例如“她受伤”只是标签，“她原本等对方解释，听完后收回准备回应的手”才是可拍画面。

## 2. 从现场找可见载体

在已确认事实内找动作中断、距离、朝向、站坐、出入画、物件交接和画外声。既有事件内自然的表演动作与未锁定空间调度（如夹菜、收回手、落座、转向出口）属于导演正常设计，无需退回上游；只有改变剧情因果、人物关系、产品事实或已锁定设定时才报缺口。既有素材不够承载选定拍法时，记录具体补图缺口交下游处理，不自行改资产需求。

## 3. 重要岔路先选定，不把互斥选项留给下游

整场体验存在真正不同的拍法岔路时（如“紧跟离开的人”还是“留在桌上的旧物与空位”），比较各自得失与时长代价后明确选定一种，不把“可A可B”留给视频阶段重当导演；无实质分歧时不硬凑双方案。

## 对白中的反应镜与大特写

- **切给掌握新信息或决定权的人。** 原声继续，画面在关键重词或动作上转给听者、被冒犯者或关键旁观者（如在场决策者收住笑、放下杯子），给足看清反应变化的停留，为后续转折留铺垫。
- **必要时跨过常规景别直切局部。** 压迫感或攻击性强的现场台词，可在重词直接切说话者嘴部大特写；夸赞容貌或展示护肤前后变化时，可随台词直切面部大特写，写清入画范围、何时切出及下一镜如何接回关系。

## 4. 两层自查：先戏味，再执行

1. **表达检查**：连读整场，看关键转折和情绪是否真落在了具体画面、反应和停留上；平淡处回到观看路线重想，不靠堆砌镜头术语补救。
2. **执行检查**：核竖屏画幅容纳度、轴线、手物前后态、对白归属与总时长预算。
