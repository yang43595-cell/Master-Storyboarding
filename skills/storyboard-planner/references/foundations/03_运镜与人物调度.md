# 运镜与人物调度（实战速查）

按需参考：只保留运动取舍、手持分寸与连续路径检查，省略推拉摇移基础定义。

## 运动与调度准则

1. **先比三种方式：固定、切镜、移动。** 表演和站位本身能完成关系变化时，固定机位往往更有力；只有需要连续经历跟随、发现、接近或空间转换时才动机位，不为“让画面动起来”加装饰性运镜，也不在同一短镜叠加推近＋环绕＋升降＋拉焦。
2. **一镜内的物理路径与时间必须成立。** 摄影机有路可走（不穿墙、不撞障碍），人物有足够时间走完动作，落幅必须有值得看的新信息，不能把两个不连续状态硬写成“一镜到底”。
3. **手持质感分场景控稳。** 跟走、追赶或贴身观察时保留脚步起伏与转向补构图，停步自然收稳；拍挤料、开管、擦拭等关键产品细节时必须控稳，不让晃动盖过手物接触。
4. **人物调度先于机器运动。** 靠近、退开、转身、起身、递物和停顿须来自人物当下目的；涉及持物交接时定清人物自身左右手（反打不镜像换手）、承托与落点，不把人物当成给镜头摆造型的木偶。
