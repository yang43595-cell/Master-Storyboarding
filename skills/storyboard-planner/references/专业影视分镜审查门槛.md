# 导演镜头方案 v4 审查门槛

本文用于候选 storyboard-package v4 JSON 的自查校验及现有审核网页审查，再由用户确认准确 JSON 版本及范围。JSON 为业务权威；仅用户明确要求 Markdown 检查稿时，从同一 JSON 版本导出阅读副本，不作为前置、不反向覆盖 JSON。网页入口与版本缺口按项目根规则处理，离线校验不冒充已发布。历史带 human_readable_path 的包继续双文件一致性只读兼容，不删除字段绕过差异。

审查对象是 [导演 Skill](../SKILL.md#承上启下的职责) 定义的整段拍法。先按播放顺序检查画面、表演、声音、节奏与衔接能否组成清楚的视听安排，再核对字段和来源；不能把后者通过扩大为前者已经成立。

整段表现按本轮方法快照的“拍法选择与整段表现”核对：先指出重要变化由哪些实际画面承载，再检查尚未获得清楚表达的情绪、物件和关系，最后检查重复观看。对每个关键位置，依据实际景别、可见表演、原声覆盖和停留，判断观众能否读懂；保留同框和拆为近景都需给出具体表达依据。

重要态度与情绪按方法快照的“人物态度与表演承载”检查触发、声音、可见变化及跨镜延续；以情境需要确定表演强度和观看距离。

旁观者按“旁观者反应与叙事铺垫”检查：找出话语与行动对在场其他人的影响，将有意义的反应落实到观看顺序，并核对其后续承接。

按[逐场创作与确认](../../../PROJECT_RULES.md#逐场创作与确认)限定审查结论：逐段送审检查本轮完整范围及跨段依赖，不将明确待写的其他段落判为本轮漏写，也不将本轮通过扩大为全片通过。全片完成时再检查全部来源覆盖、对白顺序、铺垫回应、情绪、道具状态与整体节奏；同场景分段须继承共用设定，跨段对白和动作不漏播、不重复或断裂。修改已确认部分须有对应修订和重新确认。

## 不通过

- 叙事包未确认，或 artifact、revision、路径不一致；
- Scene、Shot 无法回指来源 `STP-*`；
- 新增、删减、换人或改写 `DLG-*`；
- 导演自行新增、修改或重新编号 `AST-*`，或把缺口写成新资产需求；用户已确认调整按项目规则读取并核对出现位置；
- 缺少空间、人物、产品或交互事实却自行脑补；
- 镜头按台词、段落、时长或图片数量机械切分；
- 起幅、镜内过程、落幅实际需要多个剪辑镜头才能成立，却合在一个 Shot 条目；剪辑目标没有对应的独立镜头记录；
- 镜头目的、观众信息、调度、摄影机、声音、切点或连续性缺失；
- 本稿声称的重要情绪或关系转折只有文字标签，实际观看对象、表演、构图或声音不足以承载，却以对白覆盖或人物在场判为表达完成；
- 影响拍法的选择仍互斥或含糊，需要视频 Skill 重新导演才能执行；
- Shot 与 Panel 混淆，或把 Panel 当成正式分镜图要求；
- 设备未知却伪造精确摄影参数；
- 包含 Blender、视频模型、生成分段、提示词、生成参数或正式出图决定；
- 把机器检查或审核结论冒充用户确认。

## 有条件通过

仅用于不改变导演合同、且已明确列出并需要用户接受的非阻塞问题。资产事实、对白、来源追溯、空间可执行性或连续性缺口不得降级为有条件通过。

## 通过

- 来源 revision 正确，STP/DLG/AST 覆盖可追溯；
- 每镜能回答“拍什么、观众得到什么、人物如何行动、摄影机为何如此、为什么在此结束或继续停留；有切镜时怎样承接”；
- 声画与空间连续性可执行；
- 整场与逐镜的视听安排明确，重要情绪和关系转折有可读的视听承载，可供用户审定拍法；时间依据与未验证限制如实说明，没有把结构通过写成实测节奏通过；
- 资产缺口只报告、不新增需求；
- JSON 中事件、对白、镜头与资产引用内部一致；网页来源绑定同一准确 JSON 版本，版本改变后重新自查并送审；若用户明确要求 Markdown 检查稿，其内容从同版 JSON 导出，历史双文件检查保留；
- 仍明确等待用户确认。

审查结论只允许“通过”“有条件通过”“不通过”。

## 紧凑合同检查

场景公共设定可被每镜明确继承；单镜例外不隐式传播。起／过程／止、状态交接、准确对白片段和声音切点仍完整。没有 Beat、Panel、删除测试独立表不构成缺项。不得在结构化或阅读视图中补造 JSON 没有的拍法。

候选 JSON 自查及网页审查时，逐场核对空间字段与 defaults，逐镜核对 camera、take 与切点：各字段按其语义提取，不把整段共用设定复制为轴线、方向、站位，也不把人物动作当摄影机运动或把整段摄影文字复制为 framing／movement／focus。正文未规定运镜或焦点转移时如实注明，不据此补造固定机位、移动或拉焦；重复文字先作语义检查，不机械去重。来源与对白脚本通过只证明对应技术范围，不能代替拍法对照。

同一镜若从面部近景转到手部特写，而落幅或切点仍要求读到眼神，须核对回到面部的观看过程是否已明确。连续运镜与内部切镜含糊时列出具体歧义交用户决定，不自动拆镜、改号或把决定留给下游。
