# 导演镜头方案本地执行合同

专业判断仍以绑定的 STORYBOARD-PLANNING-METHOD 为准。本合同规定紧凑交付结构：情绪推进和删除测试仍用于创作、自检，不要求复制成独立表格。

## 来源与层级

消费已确认叙事包的原文 STP、对白 DLG，以及原资产 AST 和项目规则指定的用户确认资产调整；导演不得新增或修改资产需求。取消资产图不删除原叙事事实，用户新增资产只在已核对出现位置引用。Scene、Shot 保留稳定来源引用，不新增 Beat 或 Panel 编号层。每个 JSON shots[] 对象对应一次逐镜设计（可按需导出阅读卡片），表示一次连续摄影；起／过程／止不能含未编号切镜，结构化时不得再补拆镜头。

场景保存时空、目标与状态变化、空间规则、公共灯光与声音，以及带镜号的连贯视听展开。删减重复栏目不等于删减情绪、观看对象、空间和状态信息。设备未知时不伪造精确焦距、曝光、轨道距离或帧数。光学选择影响观看时仍须设计广角／标准／中长焦倾向与可观察目的，区分作者设计和原片实证；不把“未知原片毫米数”扩大成不设计镜头。camera.framing 承载景别、机位和适用光学意图，focus 承载清晰主体、景深层次或转焦触发，不用 purpose 的复制句填满。

## JSON v4 内容与可选阅读排版

| 正文 | 合同字段 | 整理要求 |
|---|---|---|
| 全片总则 | director_rules、timing_basis | 未知时间窗统一记 not_evaluable；实测局部对白可覆盖时间依据 |
| 场景设定 | scene 的 source_paragraph_ids、dramatic_goal、start_state、change、end_state、space_rules、defaults | 明确位置、方向；defaults 保存光色、环境声、音乐 |
| 连贯视听展开 | audiovisual_flow | 保留带镜号原文；与逐镜拍法一致 |
| 镜号、来源、目的 | shot_id、source_*、purpose | 原文段落、对白、所有涉及资产的直接引用 |
| 摄影机与画面 | camera.framing、movement、focus | 景别、机位、构图、方向、运动、焦点，不交下游猜 |
| 起／过程／止 | take.start、process、end | 人物和物体状态变化结果明确，复杂动作包含关键中间状态 |
| 对白与声音 | audio.dialogue、sfx；可选 overrides | 每个片段有 dialogue_id、speaker_id、text、presentation；已选定的声音表演写入可选 delivery，跨镜片段保留相应语气和延续，text 只存原文；场景声音继承，例外显式填写 |
| 切点与节奏 | cut、rhythm | 入口、出口、触发、信息承接与停留；声音跨镜明确说明 |
| 未决缺口 | asset_gaps、open_questions | 缺口必须回指来源段落、受影响镜头和关联 AST，不创建替代资产 |

ON_SCREEN_TEXT 表示只显示原文，不发声、不配旁白、不做口型；speaker_id 仅保留上游归属，原 DLG、原文和顺序仍完整覆盖。该类型不写声音表演 delivery；显示时机与阅读停留写在 take/rhythm，不按自然语速估时。

每镜继承场景 defaults，overrides 出现的字段替换该字段，未出现则继承。空列表表示主动关闭环境声或音乐，不等于未知。单镜覆盖不影响下一镜；持续例外在正文标范围，并在对应各镜合同中写入。下游取单镜输入必须同时带上 director_rules、场景空间和 defaults。全片 timing_basis 可被具体对白的 timing_basis 覆盖，未知时间窗不视为零时长。

## 核对与兼容

先核对视听展开与逐镜的动作、情绪承载、对白、切点，再核对来源覆盖。程序检查不代替连续摄影与情绪可读性判断。跨镜对白按播放顺序拼接须与上游文字、说话人、顺序一致，保留已知缺号。

v4 为新生产合同，v1/v2/v3 仅历史只读。旧稿按旧 schema 读取，返工新稿采用 v4，不从历史摘要推导新拍法。新稿生成候选 JSON → 自查校验 → 现有审核网页审查 → 用户确认准确 JSON 版本及范围。只有用户明确要求 Markdown 检查稿时才从同一 JSON 版本导出；不作为前置、不新建业务权威、不反向覆盖 JSON。历史带 human_readable_path 的包继续双文件检查，只读兼容，不删除字段绕过差异；确认与正式交接授权不变。机器检查、自查、用户确认分开记录。

本阶段不承担 Blender、生成模型、分段、提示词或正式出图决定。无资产缺口写无，不为填表新增要求。
