## 从整场意图想出画面

**核心实战准则（直接执行，开工不预读下方参考文档）：**

- **反应优先于轮流说话**：别一句台词配一镜、别机械正反打。原声继续时，把画面提前切给“听话的人”或“掌握决定权的旁观者”看具体动作与神态变化；攻击性重话可在重词跳切说话者嘴部大特写，夸赞容貌可跳切被夸者面部大特写。
- **竖屏 9:16 防穿帮硬界**：横向窄，双人并排或“脸＋手＋低处物件”极易塞不下。同镜要兼看时先算上下界——例如“胸口到提袋手”不含头脸，绝不能同时要求读眼神（焦点补不回画外的脸），要么放宽景别，要么拆镜。
- **运动服务体验**：生活记录/手持跟拍跟走时保留脚步起伏、停步自然收稳，拍挤料和产品细节时控稳；普通剧情只有跟随、发现或关系变化才动机位，静止观察更有力时直接固定。

以下参考仅在遇到复杂调度、多线交叉或重大拍法岔路时**按需翻查对应小节**，常规开工不全文预读：[画面构思与拍法选择](../references/visual-conception.md)、[分镜与剪辑组织](../references/foundations/01_分镜与剪辑组织.md)、[景别与构图](../references/foundations/02_景别与构图.md)、[运镜与人物调度](../references/foundations/03_运镜与人物调度.md)。局部技术维护不重做整场构思。

## 从整场设计到逐镜记录

按[现行模板](../templates/专业影视分镜输出模板.md)组织结果；旧案例、旧构稿脚本不是当前模板，不从旧输出倒推本轮拍法。

1. **全片统筹。** 准备校验通过后，按[逐场创作与确认](../../../docs/rules/execution.md#逐场创作与全片复核)通读完整已确认故事，写出全片导演规则（`director_rules`，画幅规则在 `aspect_and_exhibition` 写一次）和各场作用、情绪走向、衔接。按用户硬上限、目标或暂估时长粗算各场预算，写在 `director_rules.editing_rhythm`；无依据的标未知，不算零。对既有稿换景或改编，先对照采用源版本的估时说明必要增减。
2. **按整场构思，再落镜头。** 每次处理完整的一场：先想清整场观众体验与关键变化（方法快照的“人物态度与表演承载”“旁观者反应与叙事铺垫”“拍法选择与整段表现”），在实际剪辑边界分出连续摄影，再逐镜写下决定。`audiovisual_flow` 只写整场走向、情绪与关键转折；画面、动作、对白、切点都在逐镜字段里写一次，不在场次正文复述。
3. **逐场更新预算。** 每场写完更新已用估时与剩余预算；硬上限装不下时先在授权内调整拍法，涉及事实或目标改变再提出具体问题。后续场次沿用全片理解，不丢远处铺垫与回应。
4. **两层自查。** 先核整场观众体验与关键变化是否有具体视听承载，表达不足回到构思而不是加镜头术语；再核可见范围、动作状态、轴线、声音与时长是否可执行。读工具生成的阅读版连读整场，指出具体遗漏或冲突，不以字段齐全代替判断。

逐场候选按[局部来源自查入口](../SKILL.md#逐段候选来源自查不等于整稿采用)显式列已有 STP 范围；全片校验仍为默认。存在实质拍法岔路时，按[分镜段创作与实质比较](../references/segment-sequence-method.md#重要岔路必须有实际短序列)先比较再展开；无岔路不凑双案。

## 导演包 5.0 字段写法

每件事只写在一个地方。工具（`scripts/director_package.py`）自动补齐的不用手写。

| 内容 | 字段 | 怎么写 |
| --- | --- | --- |
| 全片总则 | `director_rules`、`timing_basis` | 画幅、视点、摄影与剪辑原则、光色、声音原则各写一次；未知时间窗记 `not_evaluable` |
| 场次设定 | `scene_id`、`source_paragraph_ids`、`dramatic_goal`、`start_state`、`change`、`end_state`、`space_rules`、`defaults`、可选 `scene_states` | 位置、方向、轴线、关键物件、光源、声音基础写一次；`defaults` 保存光色、环境声、音乐 |
| 整场走向 | `audiovisual_flow` | 几句话写整场体验、情绪走向和关键转折；不逐镜复述 |
| 镜号与目的 | `shot_id`、`purpose` | 镜号连续；目的一句话 |
| 来源 | `source_paragraph_ids`、`source_dialogue_ids`、`source_asset_requirement_ids` | 段落默认取本场、对白编号从承载的对白自动生成（**工具补齐**）；资产编号由导演列出本镜实际出现的有效 AST |
| 画面 | `camera.framing` | 景别、机位、构图、主体在画面中的位置；不重复全片画幅规则 |
| 运镜 | `camera.movement` | 一句写清：从哪起、什么时候动、怎么动、停在哪；固定就写固定 |
| 焦点 | `camera.focus`（可选） | 只有转焦或特殊虚实要求时写 |
| 镜内行动 | `action` | “起态 → 过程 → 止态”，写人和物发生了什么；复杂动作写关键中间状态 |
| 切点与交代 | `cut.exit`、`cut.handoff` | 在哪个词句或动作相位切走、切到什么；这一镜交代了什么信息或情绪。进入方式即上一镜的切走 |
| 节奏 | `rhythm` | 估时和节奏，例如“约2.2秒｜极慢推近，末尾被问候打断” |
| 对白与声音 | `audio.dialogue`、`audio.sfx`、可选 `overrides` | 对白只写 `dialogue_id`（说话人、原文由**工具补齐**），一句跨镜时写本镜片段 `text`；可选 `presentation`（默认 SYNC）、`delivery` |
| 必保画面 | 可选 `required_visuals`、`packaging_requirements` | 只登记漏拍就改变结果的画面 |
| 未决缺口 | `asset_gaps`、`open_questions` | 缺口必须回指来源段落、受影响镜头和关联 AST，不创建替代资产 |

Scene、Shot 保留稳定来源引用，不新增 Beat 或 Panel 编号层；导演不得新增或修改资产需求，取消资产图不删除原叙事事实。每个 `shots[]` 对象是一次连续摄影；镜内行动不能含未编号切镜。设备未知时不伪造精确焦距、曝光或帧数，但光学选择影响观看时仍写广角／标准／中长焦倾向与目的。

ON_SCREEN_TEXT 只显示原文，不发声、不配旁白、不做口型，不写 `delivery`；显示时机与停留写在 `action`/`rhythm`。每镜继承场景 `defaults`，`overrides` 出现的字段替换该字段，空列表表示主动关闭；单镜覆盖不影响下一镜。下游取单镜时同时读取 `director_rules`、场景 `space_rules`/`defaults`。跨镜对白按播放顺序拼接须与上游原文、说话人、顺序一致。

可机械核验的边界：`scene_id` 包内唯一；`asset_gaps.affected_shot_ids` 必须存在且与缺口来源 STP 有交集；`related_asset_ids` 属于当前有效资产并与来源 STP 对应，确无关联资产时允许空数组。4.0 旧包（`take`、四项 `cut`）照常读取和沿用；v1/v2/v3 仅只读。

### 声音表演随片段绑定，不按角色批量填充

结构化只保留视听展开中已经选定的声音表演：以 `dialogue_id`、当前 `text` 片段及本镜动作/触发位置为对应依据，再写可选 `delivery`。同一人物在不同句子会询问、解释、受打断或转变态度，不能用 `speaker_id` 或“同期/画外”分支把整场情绪路线批量复制到每句；脚本可搬运已逐片段确定的映射，不能替代这一步判断。只在后句发生的打断、反问或回应不得提前挂在前句。跨镜同一句分别保留该片段的承接和切点，不把全句后半的变化提前到前半。

未选具体声音处理时可省略 `delivery`，不为填字段新增表演意图；但正文已有的关键声音决定不能靠全部删掉该字段丢失。同一准确语气确实贯穿相邻片段时可共用，重复本身不是错误。成稿后从实际 JSON 逐片段连读 `text`、`delivery`、`presentation` 和本镜 `action`，对照前后触发：提示是否属于这句话、这个人、这个时点，声画是否互相冲突。既有自查记录写具体发现和返修结果，不另建表或用“原词/说话人检查通过”代替语义复核。

情绪、关系、节奏与观看快感都是有效收益，长镜、同框和安静表演按实际效果判断。

## 把创作决定落实为可验证的状态与节拍

这是本项目两层自查的具体执行步骤，沿用同一导演JSON的逐镜 action、场景共用设定/overrides和既有核对备注，不另建状态表或业务真源。导演在创作时完成拍法决定；视频阶段按准确source_shots承接并检查实现，不在下游擅自补戏。程序字段完整不证明这些判断正确。

1. **先保住观众应看到的事实，再配镜。** 从每个来源段落分别核对白覆盖和视觉事件覆盖。对白提到不等于画面已经交代；转账到账、道具交付、物件变化等若原叙事要求可见，应有可见载体和阅读时间。选择背屏、遮挡或改成OS时回查是否把视觉信息无意删掉；字幕禁令不意味着实物信息不能出镜。需要改变既定叙事或已确认拍法则返回上游，不自行补屏幕内容或一概强制所有事实拍特写。
   有广告展示目标时，按[广告中的产品展示与使用](../../_shared/product-usage-contract.md#广告中的产品展示与使用)把实际展示、使用动作、参考覆盖和有效时长落实到本镜及相邻镜头。跨切点直接从「物件还在包内」到「已在手上」、从「人仍在路上」到「已站定」时，先连读前后镜的止态与起态或用简图草验，判断观众是否需要看到动作或情绪过渡；需要就把这一拍留在镜头里，再安排省略。
   对源要求中不可省略、漏拍就改变结果的画面，在对应 `shots[].required_visuals` 登记简短的 `prompt_clause`，用能直接进模型正文的单行视听指令。例如明确座位和道具的前后位置、接起动作的相位、表演触发与具体景别、实际站位上的面光或该时刻的背景活动。广告工序或读图有硬性最低时长时，同一镜最多给一个 `min_seconds`，须依据实际节拍判断。本镜确实依赖某张场景、产品或动作参考时，核现有已确认图能否承担对应状态。缺口登记在对应镜号和用途；可独立规划的镜头继续。返修改景别、声桥或切点后，对照同一镜的 `action`、`cut`、对白片段、`rhythm` 和必保指令，删改已失效的画内承载和估时。跨镜的原话或可见动作在实际承担它的镜头验收。普通镜头无需填此字段，历史导演包按原版读取。
2. **继承整个现场，不只修被指出的一件。** 从已核前态列出当前场景实际持续物件，逐件核身份、类别、尺度、结构、支撑、落点与内容物；后态集合减前态集合是新增，前态减后态是消失，交集再比属性变化。每处差异须有来源允许的可见动作、合理出画或明确时间转换；未知就留缺口，不补上菜、放物等新戏解释穿帮。画内可见集合与场景持续存在集合分开判断：出画只改变可见性，不授权物件消失、换身份或在下一镜重置。单镜overrides没有写的持续条件继续继承。换一件参考后同桌其他物件也要重看。
   持续可见的场景状态因剧情实质改变且后续沿用时，同时标清旧态 → 来源事件 → 新态、不变量／变化及生效镜号；在同一导演包对应 `scenes[].scene_states[]` 记录变化后态，字段见下述合同，保留与镜头前后态的一致性；没有持久变化时省略，不新增台账或在本阶段生图。下游按[剧情后的场景状态参考](../../storyboard-director/references/reference-asset-contract.md#剧情后的场景状态参考)先取得新态图，再使用；原基础环境不能永久覆盖已变化的现场。按[编导的对白与画面事实区分](../../creative-director/modules/story-method.md#完整故事正文从整场变化写到连续现场)核对可见依据；上游故事、资产需求与来源冲突时，退回准确 STP／DLG／AST 核实后再定镜。涉及持物交接时定同一实物外观组合、左右手、接稳与释放及新归属。

3. **按风险写清手物动作。** 普通动作写清人物、物件、关键先后和结果，不逐指推演。复杂交接、产品关键工序或易穿帮动作，才补足影响执行的左右手占用、接触、承托、分离、落点、释放与最终持有状态；不为每个动作机械填全这些项目。当前持物妨碍接触或受力时，选择来源允许的落物/换手或已有承托，不按物件数量推定手不够，也不靠“自然完成”省掉必要过程。具体产品工序按真实用法与[条件案例](../references/conditional-continuity-cases.md#产品工序与真实参考)核对，静态前后图不证明动态过程。
   交给视频之前，在普通镜头各自的 `action`、`camera`、`cut` 或 `rhythm` 写清影响观看结果的动作、反应、运镜和切点。视频阶段退回含糊拍法时，按原镜号补足决定并重新核对该镜及相邻接口。
4. **在实际画幅内验证可见范围。** 先以准确横竖比画取景框或做简单构图草验，核本镜需要呈现的脸、手、物和承托面是否能同时读清，选一个可实现范围；画幅剩余区域不能靠复制五官/拼条填满。用户已锁定的特殊景别及快切在其准确范围内保留；对应[构图案例](../references/conditional-continuity-cases.md#构图跨场与已锁定选择)仅在本轮确有该要求或问题时读取。
5. **试读/试演决定节拍，不由字数或慢放臆测。** 电话等长对白先正常语速读完整原话，沿信息、刺激和情绪变化定位停顿、反应和声桥；原话跨镜只说一次，不靠重复回远景凑节奏。复杂操作按必须顺序试演手和物的节拍，估计与实际计时分开，慢放参考的时长不是现实动作工时。时间不足返回拍法/分段职责处理，不能压掉必要接触、加速对白或改用户时长。
   对已有空间交代、关键反应或时间跳切的接口，把前镜最后一个有效画面、后镜第一个新增信息和切过来的声音按播放顺序连读一遍。在对应 `cut.handoff`、`action`、`rhythm` 中落实谁接住刺激、哪一拍可切、哪一拍要留。下一镜回全景须让观众读到新的站位、行动或关系。计划用同构图省略时间时，落实观众能读到的提示及其承载方式。使用已定后期文字时在原镜安排显示位置和停留。用动作、声音或空镜时写清实际线索。只在需要选择切点的镜头给可裁余量，预留拍摄素材和成片停留分别算。
6. **按真实依赖检查修改影响。** 首次导演创作尚无下游视频稿时，只核导演镜头、同场持续状态与前后接口，不查找或虚构生成段。已有当前有效下游时，修改镜头/状态/引用后由现有 source_shots 反查所有实际承载该镜的生成段，再按共同场景、持续实体和前驱/后继边界找直接受影响接口，读取相关完整段。摘要缺 source_shots 或邻段正文时先回查已知完整导演/视频源，以段ID及原字段逐字或哈希核验同版后恢复映射；未读取不等于缺资料。下游本应存在但真实来源仍不可得时，报告未核影响，只核已知导演镜头，不声称跨阶段回归通过。发现同类错误时核同场/同类动作或物件的其他出现位置；非目标字节未改只证明没误改，不证明连续性通过。撤图逐项检查原职责由有效来源、准确文字或合法不出镜承接；替代不能满足必要视觉身份时留缺口，不自行恢复已取消素材，不把“同一个”当视觉来源。记录具体范围与未核项，不扩大修改授权。


## 连续现场的重点反例

先问三个问题：动作开始需准备什么，结束后必须保留什么，观众必须看见什么才能接上。公共条件只放真正不变项；每段入态写已经完成后的状态，不重抄上一段动作让模型重演。左右手以人物自身为准，画面左右另行说明。

通用检查沿同一 `start_state/change/end_state`、`space_rules`、`action` 与核对备注落实：

- 用真实空间锚点定位；画内可见与画外持续存在分开，切镜不重置人物、道具或动作进度。
- 持物、交接与支撑按本镜实际风险细化，不设“一手只能一物”，也不凭空加手、支架或演员解释矛盾。
- 结构、材质和产品用法各核对应真实来源；参考缺失或版本不符时留缺口，不按名称、颜色或旧案例猜。
- 场景后态图与人物关系图各核其用途，不能以“仅取关系”等说明豁免仍可见的几何冲突；持续场景变化按既有后态图流程处理，普通走位不自动触发补图。

本轮场景真实感自查同时核事件对在场者的影响：谁原本做什么、能否看见/听见、何时察觉、怎样反应；既查附近已察觉却像背景贴图，也查提前反应或多人同刻同动作。允许没察觉、克制、僵住及有依据的齐声反应，不强制全员错峰。物件沿数量、位置、持有人与取得/交接路径核因果；环境声沿真实声源和事件前后变化核，不强制冲突时全场静音。相邻镜核动作相位、人物自身左右与持续衣饰，时间省略须有来源。具体检查与未验证边界见[场景真实感的候选检查](../../../docs/development/scene-realism-checks.md)；只改当前候选及直接影响，不因此改变已确认事实或新增生成任务。

具体盒袋、一次性管、护理、跨场与已锁定构图的反例，按[条件案例的读取条件](../references/conditional-continuity-cases.md#读取条件)选读相应章节；只承接本轮真实输入及用户决定，不把案例变成通用工序、镜头配额或出图任务。

按真实观看顺序核累计时间，逐场更新全片预算，全片完成再精核。覆盖对白、同步表演、独立动作、必要停留与转场：同期声画只算一段，声桥跨镜不重复计时，串行动作不假设同步，切镜不机械加停顿；未测标估计或 not_evaluable，未知不算零。
