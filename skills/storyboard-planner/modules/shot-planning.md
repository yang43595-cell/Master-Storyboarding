本 Skill 按“准备 → 阅读 → 登记 → 校验 → 产出”执行。先按 `skills/_shared/knowledge-access.md` 整理准确输入；广告任务在准备前按[广告中的产品展示与使用](../../_shared/product-usage-contract.md#广告中的产品展示与使用)确定当前商品及条件方法；需要按本轮条件选读时，在 prepare 命令追加 `--request-json <本轮请求文件>`。已有有效准备包和阅读证据按共享规则复用。

以下命令从仓库根目录执行；`<执行者ID>` 与 `<任务ID>` 由当前执行者确定，并在同一任务的三条命令中保持一致，不需要用户填写。


## 从整场意图想出画面

实质创作与拍法返修，先完整阅读下列三份本地基础参考，再选择具体拍法；同一任务、同一版本且原文仍在有效上下文时按共享规则复用，发生改变只补读受影响内容。它们是通用基础整理 v0.1，不是已从知识库核实的案例，也不替代绑定专业方法或输入确认：

- [分镜与剪辑组织](../references/foundations/01_分镜与剪辑组织.md)：把整场变化组织成观看次序，判断何时连续、切镜、反应、留空位及声画转场。
- [景别与构图](../references/foundations/02_景别与构图.md)：按可见载体选择范围、角度与画内关系，检查手物动作、遮挡和竖屏读性。
- [运镜与人物调度](../references/foundations/03_运镜与人物调度.md)：比较固定、移动与切镜，设计人物目的与站位变化，核对连续路径、落幅与时间成本。

这三份由上述显式路径进入 prepare 的本地规范及哈希清单，正文按原路径阅读，不作为新的 Vault 知识块。缺文件、空正文或版本变动须停止相关准备/产出并修复，不能用文件名或阅读登记代替全文。进入具体构思时把三类判断应用于下述观看路线与两层自查，不要求每场用空镜、运镜或固定镜头配额，不增加独立表格或生产阶段。

实质创作与拍法返修在逐镜表之前，读取 [画面构思与拍法选择](../references/visual-conception.md)；其推导与示例是已绑定方法的项目应用补充，不替代专业方法身份或全文阅读。先确定整场目标、阻力和关系前后态，再想观众怎样经历变化；从现有行动、空间、物件与声音寻找可见载体。重要岔路比较真正不同的观看路线，选择并组织后再决定景别、切镜、运镜和跨场转场。范围未变可复用既有阅读；局部技术维护不重做整场构思。

## 从视听稿整理为逐镜表

本阶段按入口与执行方法 → [现行填写模板](../templates/专业影视分镜输出模板.md) → 适用参考知识的层次执行。模板决定正文组织，参考提供取舍依据；旧案例、历史 R08 构稿脚本和临时字段拼接器不是当前模板实现，不从旧输出倒推本轮拍法。若需转换，逐项证明完整保留当前视听正文、共享设定与单镜例外，不能只拼 framing/movement 或按 purpose 自动填 focus。

准备校验通过后，按[逐场创作与确认](../../../docs/rules/execution.md#逐场创作与全片复核)先通读完整已确认故事，在现有导演稿内简述全片各创作段落的作用、情绪走向、来源范围与衔接。细写第一段前，按用户硬上限、目标或暂估时长，粗算各段预算及全片合计，预留关键动作、反应与转场；无依据的部分标未知，不算零。粗预算写在既有 director_rules.editing_rhythm 等统筹文字或核对备注，timing_basis 仍按原来源字段登记依据，不新增字段或台账。随后一次细写一个创作段落，逐段更新已用估时与剩余预算；硬上限明显装不下时先调整授权内拍法，涉及事实或目标改变再提出具体问题。后续轮次复用仍有效的全片理解，输入变化时补读实际影响范围；不因逐段写作丢失远处铺垫与回应。

逐段候选按 [局部来源自查入口](../SKILL.md#逐段候选来源自查不等于整稿采用) 显式列已有 STP 范围；全片校验仍为默认，不能用局部成功代替全片覆盖。已写部分与跨段接口先核对，未写部分保持未完成。

在当前创作段落所属场景的“视听展开”中先直接写连贯的行动、表情和声音，在准确词句或动作触发处嵌入景别与切镜，再整理底层逐镜记录；不先给整段设一个景别，不把目的、方案解释和审核声明混入阅读正文；同场景分批写作时沿用场景公共设定与连续镜号，以来源边界标明各创作段落，不另造场景。专业判断仍依据本轮方法快照；这里规定创作结果如何保留与展开，不新增专业知识来源。

1. 先写连贯的视听展开，作出画面、表演、声音及观看方式的具体选择，暂不按 Shot 表格字段或编号组织；专业判断应用方法快照中的“人物态度与表演承载”“旁观者反应与叙事铺垫”和“拍法选择与整段表现”，将整段注意力安排落实到实际画面顺序。
2. 在实际剪辑边界处分出连续摄影，把 Shot 编号标回各段摄影开始处；含糊的观看位置变化先确定是剪辑还是镜内变化，同一编号不跨越切镜。
3. 按边界展开逐镜表，保留原段落的拍法、声音、揭示顺序与切换目的。改变决定时同步修订段落和编号；对白只引用和承载，不改写事实。
4. 分两层自查：先核整场观众体验与关键变化是否有充分且具体的视听承载，表达不足回到构思而非添加镜头术语；再核可见范围、动作状态、轴线、声音与时长是否可执行。按方法先核对重要变化的实际视听承载与遗漏，再比较拍法、精简重复，往返对照段落与逐镜表的画面、动作、声音、切点和状态；按“拍法选择与整段表现”核对观看对象切换、景别与动作范围、反应和细节的可读时间，指出具体遗漏或冲突，不以条数相同或字段齐全替代判断。声音表演按下文绑定到实际对白片段，不混入 text。


### 声音表演随片段绑定，不按角色批量填充

结构化只保留视听展开中已经选定的声音表演：以 `dialogue_id`、当前 `text` 片段及本镜动作/触发位置为对应依据，再写可选 `delivery`。同一人物在不同句子会询问、解释、受打断或转变态度，不能用 `speaker_id` 或“同期/画外”分支把整场情绪路线批量复制到每句；脚本可搬运已逐片段确定的映射，不能替代这一步判断。只在后句发生的打断、反问或回应不得提前挂在前句。跨镜同一句分别保留该片段的承接和切点，不把全句后半的变化提前到前半。

未选具体声音处理时可省略 `delivery`，不为填字段新增表演意图；但正文已有的关键声音决定不能靠全部删掉该字段丢失。同一准确语气确实贯穿相邻片段时可共用，重复本身不是错误。成稿后从实际 JSON 逐片段连读 `text`、`delivery`、`presentation` 和本镜 `take`，对照正文及前后触发：提示是否属于这句话、这个人、这个时点，声画是否互相冲突。既有自查记录写具体发现和返修结果，不另建表或用“原词/说话人检查通过”代替语义复核。

最终视听段落与逐镜表在同一导演 JSON 内完成。存在实质拍法岔路或表达不足需要重选时，按[分镜段创作与实质比较](../references/segment-sequence-method.md#重要岔路必须有实际短序列)先比较再展开完整稿，成稿后回读落实；过程复用现有核对记录，不另建业务权威。无实质岔路不强凑双案；情绪、关系、节奏与观看快感都是有效收益，长镜、同框和安静表演按实际效果判断。

## 把创作决定落实为可验证的状态与节拍

这是本项目两层自查的具体执行步骤，沿用同一导演JSON的视听展开、take、场景共用设定/overrides和既有核对备注，不另建状态表或业务真源。导演在创作时完成拍法决定；视频阶段按准确source_shots承接并检查实现，不在下游擅自补戏。程序字段完整不证明这些判断正确。

1. **先保住观众应看到的事实，再配镜。** 从每个来源段落分别核对白覆盖和视觉事件覆盖。对白提到不等于画面已经交代；转账到账、道具交付、物件变化等若原叙事要求可见，应有可见载体和阅读时间。选择背屏、遮挡或改成OS时回查是否把视觉信息无意删掉；字幕禁令不意味着实物信息不能出镜。需要改变既定叙事或已确认拍法则返回上游，不自行补屏幕内容或一概强制所有事实拍特写。
   有广告展示目标时，按[广告中的产品展示与使用](../../_shared/product-usage-contract.md#广告中的产品展示与使用)把实际展示、使用动作、参考覆盖和有效时长落实到本镜及相邻镜头。跨切点直接从「物件还在包内」到「已在手上」、从「人仍在路上」到「已站定」时，先连读前后起落幅或用简图草验，判断观众是否需要看到动作或情绪过渡；需要就把这一拍留在镜头里，再安排省略。
   对源要求中不可省略、漏拍就改变结果的画面，在对应 `shots[].required_visuals` 登记简短的 `prompt_clause`，用能直接进模型正文的单行视听指令。例如明确座位和道具的前后位置、接起动作的相位、表演触发与具体景别、实际站位上的面光或该时刻的背景活动。广告工序或读图有硬性最低时长时，同一镜最多给一个 `min_seconds`，须依据实际节拍判断。先核场景图、产品和动作参考能承担对应状态，再定镜头；缺口走现有资产与导演返修。返修改景别、声桥或切点后，对照同一镜的 `take`、`cut`、对白片段、`rhythm` 和必保指令，删改已失效的画内承载和估时。跨镜的原话或可见动作在实际承担它的镜头验收。普通镜头无需填此字段，历史导演包按原版读取。
2. **继承整个现场，不只修被指出的一件。** 从已核前态列出当前场景实际持续物件，逐件核身份、类别、尺度、结构、支撑、落点与内容物；后态集合减前态集合是新增，前态减后态是消失，交集再比属性变化。每处差异须有来源允许的可见动作、合理出画或明确时间转换；未知就留缺口，不补上菜、放物等新戏解释穿帮。画内可见集合与场景持续存在集合分开判断：出画只改变可见性，不授权物件消失、换身份或在下一镜重置。单镜overrides没有写的持续条件继续继承。换一件参考后同桌其他物件也要重看。
   持续可见的场景状态因剧情实质改变且后续沿用时，同时标清旧态 → 来源事件 → 新态、不变量／变化及生效镜号；在同一导演包对应 `scenes[].scene_states[]` 记录变化后态，字段见下述合同，保留与镜头前后态的一致性；没有持久变化时省略，不新增台账或在本阶段生图。下游按[剧情后的场景状态参考](../../storyboard-director/references/image-continuity-hard-rules.md#剧情后的场景状态参考)先取得新态图，再使用；原基础环境不能永久覆盖已变化的现场。按[编导的对白与画面事实区分](../../creative-director/modules/story-method.md#完整故事正文从整场变化写到连续现场)核对可见依据；上游故事、资产需求与来源冲突时，退回准确 STP／DLG／AST 核实后再定镜。涉及持物交接时定同一实物外观组合、左右手、接稳与释放及新归属。

3. **按风险写清手物动作。** 普通动作写清人物、物件、关键先后和结果，不逐指推演。复杂交接、产品关键工序或易穿帮动作，才补足影响执行的左右手占用、接触、承托、分离、落点、释放与最终持有状态；不为每个动作机械填全这些项目。当前持物妨碍接触或受力时，选择来源允许的落物/换手或已有承托，不按物件数量推定手不够，也不靠“自然完成”省掉必要过程。具体产品工序按真实用法与[条件案例](../references/conditional-continuity-cases.md#产品工序与真实参考)核对，静态前后图不证明动态过程。
4. **在实际画幅内验证可见范围。** 先以准确横竖比画取景框或做简单构图草验，核本镜需要呈现的脸、手、物和承托面是否能同时读清，选一个可实现范围；画幅剩余区域不能靠复制五官/拼条填满。用户已锁定的特殊景别及快切在其准确范围内保留；对应[构图案例](../references/conditional-continuity-cases.md#构图跨场与已锁定选择)仅在本轮确有该要求或问题时读取。
5. **试读/试演决定节拍，不由字数或慢放臆测。** 电话等长对白先正常语速读完整原话，沿信息、刺激和情绪变化定位停顿、反应和声桥；原话跨镜只说一次，不靠重复回远景凑节奏。复杂操作按必须顺序试演手和物的节拍，估计与实际计时分开，慢放参考的时长不是现实动作工时。时间不足返回拍法/分段职责处理，不能压掉必要接触、加速对白或改用户时长。
   对已有空间交代、关键反应或时间跳切的接口，把前镜最后一个有效画面、后镜第一个新增信息和切过来的声音按播放顺序连读一遍。在对应 `cut.information_handoff`、`take`、`rhythm` 中落实谁接住刺激、哪一拍可切、哪一拍要留。下一镜回全景须让观众读到新的站位、行动或关系。计划用同构图省略时间时，落实观众能读到的提示及其承载方式。使用已定后期文字时在原镜安排显示位置和停留。用动作、声音或空镜时写清实际线索。只在需要选择切点的镜头给可裁余量，预留拍摄素材和成片停留分别算。
6. **按真实依赖检查修改影响。** 首次导演创作尚无下游视频稿时，只核导演镜头、同场持续状态与前后接口，不查找或虚构生成段。已有当前有效下游时，修改镜头/状态/引用后由现有 source_shots 反查所有实际承载该镜的生成段，再按共同场景、持续实体和前驱/后继边界找直接受影响接口，读取相关完整段。摘要缺 source_shots 或邻段正文时先回查已知完整导演/视频源，以段ID及原字段逐字或哈希核验同版后恢复映射；未读取不等于缺资料。下游本应存在但真实来源仍不可得时，报告未核影响，只核已知导演镜头，不声称跨阶段回归通过。发现同类错误时核同场/同类动作或物件的其他出现位置；非目标字节未改只证明没误改，不证明连续性通过。撤图逐项检查原职责由有效来源、准确文字或合法不出镜承接；替代不能满足必要视觉身份时留缺口，不自行恢复已取消素材，不把“同一个”当视觉来源。记录具体范围与未核项，不扩大修改授权。


## 连续现场的重点反例

先问三个问题：动作开始需准备什么，结束后必须保留什么，观众必须看见什么才能接上。公共条件只放真正不变项；每段入态写已经完成后的状态，不重抄上一段动作让模型重演。左右手以人物自身为准，画面左右另行说明。

通用检查沿同一 `start_state/change/end_state`、`space_rules`、`take` 与核对备注落实：

- 用真实空间锚点定位；画内可见与画外持续存在分开，切镜不重置人物、道具或动作进度。
- 持物、交接与支撑按本镜实际风险细化，不设“一手只能一物”，也不凭空加手、支架或演员解释矛盾。
- 结构、材质和产品用法各核对应真实来源；参考缺失或版本不符时留缺口，不按名称、颜色或旧案例猜。
- 场景后态图与人物关系图各核其用途，不能以“仅取关系”等说明豁免仍可见的几何冲突；持续场景变化按既有后态图流程处理，普通走位不自动触发补图。

具体盒袋、一次性管、护理、跨场与已锁定构图的反例，按[条件案例的读取条件](../references/conditional-continuity-cases.md#读取条件)选读相应章节；只承接本轮真实输入及用户决定，不把案例变成通用工序、镜头配额或出图任务。
