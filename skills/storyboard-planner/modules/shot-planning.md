## 从整场意图想出画面

实质创作与拍法返修，先完整阅读下列三份本地基础参考，再选择具体拍法；同一任务、同一版本且原文仍在有效上下文时按共享规则复用，发生改变只补读受影响内容。它们是通用基础整理 v0.1，不是已从知识库核实的案例，也不替代绑定专业方法或输入确认：

- [分镜与剪辑组织](../references/foundations/01_分镜与剪辑组织.md)：把整场变化组织成观看次序，判断何时连续、切镜、反应、留空位及声画转场。
- [景别与构图](../references/foundations/02_景别与构图.md)：按可见载体选择范围、角度与画内关系，检查手物动作、遮挡和竖屏读性。
- [运镜与人物调度](../references/foundations/03_运镜与人物调度.md)：比较固定、移动与切镜，设计人物目的与站位变化，核对连续路径、落幅与时间成本。

这三份由上述显式路径进入 prepare 的本地规范及哈希清单，正文按原路径阅读，不作为新的 Vault 知识块。缺文件、空正文或版本变动须停止相关准备/产出并修复，不能用文件名或阅读登记代替全文。进入具体构思时把三类判断应用于下述观看路线与两层自查，不要求每场用空镜、运镜或固定镜头配额，不增加独立表格或生产阶段。

实质创作与拍法返修在逐镜表之前，读取 [画面构思与拍法选择](../references/visual-conception.md)；其推导与示例是已绑定方法的项目应用补充，不替代专业方法身份或全文阅读。先确定整场目标、阻力和关系前后态，再想观众怎样经历变化；从现有行动、空间、物件与声音寻找可见载体。重要岔路比较真正不同的观看路线，选择并组织后再决定景别、切镜、运镜和跨场转场。范围未变可复用既有阅读；局部技术维护不重做整场构思。

## 从视听稿整理为逐镜表

本阶段按入口与执行方法 → [现行填写模板](../templates/专业影视分镜输出模板.md) → 适用参考知识的层次执行。模板决定正文组织，参考提供取舍依据；旧案例、历史 R08 构稿脚本和临时字段拼接器不是当前模板实现，不从旧输出倒推本轮拍法。若需转换，逐项证明完整保留当前视听正文、共享设定与单镜例外，不能只拼 framing/movement 或按 purpose 自动填 focus。

准备校验通过后，按[逐场创作与确认](../../../PROJECT_RULES.md#逐场创作与确认)先通读完整已确认故事，在现有导演稿内简述全片各创作段落的作用、情绪走向、来源范围与衔接，再一次细写一个创作段落。后续轮次复用仍有效的全片理解，输入变化时补读实际影响范围；不因逐段写作丢失远处铺垫与回应。

在当前创作段落所属场景的“视听展开”中先直接写连贯的行动、表情和声音，在准确词句或动作触发处嵌入景别与切镜，再整理底层逐镜记录；不先给整段设一个景别，不把目的、方案解释和审核声明混入阅读正文；同场景分批写作时沿用场景公共设定与连续镜号，以来源边界标明各创作段落，不另造场景。专业判断仍依据本轮方法快照；这里规定创作结果如何保留与展开，不新增专业知识来源。

1. 先写连贯的视听展开，作出画面、表演、声音及观看方式的具体选择，暂不按 Shot 表格字段或编号组织；专业判断应用方法快照中的“人物态度与表演承载”“旁观者反应与叙事铺垫”和“拍法选择与整段表现”，将整段注意力安排落实到实际画面顺序。
2. 在实际剪辑边界处分出连续摄影，把 Shot 编号标回各段摄影开始处；含糊的观看位置变化先确定是剪辑还是镜内变化，同一编号不跨越切镜。
3. 按边界展开逐镜表，保留原段落的拍法、声音、揭示顺序与切换目的。改变决定时同步修订段落和编号；对白只引用和承载，不改写事实。
4. 分两层自查：先核整场观众体验与关键变化是否有充分且具体的视听承载，表达不足回到构思而非添加镜头术语；再核可见范围、动作状态、轴线、声音与时长是否可执行。按方法先核对重要变化的实际视听承载与遗漏，再比较拍法、精简重复，往返对照段落与逐镜表的画面、动作、声音、切点和状态；按“拍法选择与整段表现”核对观看对象切换、景别与动作范围、反应和细节的可读时间，指出具体遗漏或冲突，不以条数相同或字段齐全替代判断。声音表演在结构化时保留至对应对白片段的可选 delivery，不混入 text。

这一过程在同一导演 JSON 内完成，具体按 [分镜段创作与实质比较](../references/segment-sequence-method.md)。不固定每镜候选数或模型调用次数；重要表达岔路须实际比较短镜头序列，不能只写一句选A。候选比较复用现有核对记录，不新增业务权威；自查与独立审核按项目授权区分。保留带边界编号的视听段落供用户阅读，分镜表展开其具体拍法。只在影响整段表现的关键取舍处，在现有核对记录保留同事实、对白和时间预算的两套实际短序列，先比较正文及邻段接口，再写选定理由；两者都成立时明确本稿选择，未选方案不进入生产正文。没有实质岔路不强凑双案，不要求每镜比较或另表。情绪、关系、节奏及符合本片目标的观看快感都是有效收益，不因没有新增剧情信息否定镜头；长镜、同框与安静表演同样按实际效果判断。该记录留下具体决定供检查，不以出现比较词句证明创作质量。

## 把创作决定落实为可验证的状态与节拍

这是本项目两层自查的具体执行步骤，沿用同一导演JSON的视听展开、take、场景共用设定/overrides和既有核对备注，不另建状态表或业务真源。导演在创作时完成拍法决定；视频阶段按准确source_shots承接并检查实现，不在下游擅自补戏。程序字段完整不证明这些判断正确。

1. **先保住观众应看到的事实，再配镜。** 从每个来源段落分别核对白覆盖和视觉事件覆盖。对白提到不等于画面已经交代；转账到账、道具交付、物件变化等若原叙事要求可见，应有可见载体和阅读时间。选择背屏、遮挡或改成OS时回查是否把视觉信息无意删掉；字幕禁令不意味着实物信息不能出镜。需要改变既定叙事或已确认拍法则返回上游，不自行补屏幕内容或一概强制所有事实拍特写。
2. **继承整个现场，不只修被指出的一件。** 从已核前态列出当前场景实际持续物件，逐件核身份、类别、尺度、结构、支撑、落点与内容物；后态集合减前态集合是新增，前态减后态是消失，交集再比属性变化。每处差异须有来源允许的可见动作、合理出画或明确时间转换；未知就留缺口，不补上菜、放物等新戏解释穿帮。画内可见集合与场景持续存在集合分开判断：出画只改变可见性，不授权物件消失、换身份或在下一镜重置。单镜overrides没有写的持续条件继续继承。换一件参考后同桌其他物件也要重看。
   持续可见的场景状态因剧情实质改变且后续沿用时，同时标清旧态 → 来源事件 → 新态、不变量／变化及生效镜号；在同一导演包对应 `scenes[].scene_states[]` 记录变化后态，字段见下述合同，保留与镜头前后态的一致性；没有持久变化时省略，不新增台账或在本阶段生图。下游按[剧情后的场景状态参考](../../storyboard-director/references/image-continuity-hard-rules.md#剧情后的场景状态参考)先取得新态图，再使用；原基础环境不能永久覆盖已变化的现场。

3. **手和物按可执行顺序交接。** 对实际发生的动作，从前态逐步说清左右手各占什么、物体靠什么承托、哪只手先接触、如何分离、落在哪里、何时放下释放、最后谁持有；当前持物妨碍所需接触或受力时，先定位来源允许的落物/换手或已有承托，不按物件数量推定手不够，不靠“自然完成”省掉接触。全脸涂擦按所需区域核覆盖。清洗可以省去重复擦拭，但导演要留出末处主膜被巾带走、巾离脸并放下、所需脸区无大片连续主膜后才用清水的可见衔接；静态前后图不证明动态过程。
4. **在实际画幅内验证可见范围。** 先以准确横竖比画取景框或做简单构图草验，核双眼/单眼、脸/手/物/承托面是否能同时呈现，选一个可实现范围。画幅剩余区域不能靠复制五官/拼条填满。保留用户选择的嘴部ECU及锋利快切，检查其刺激、台词落点和接收者反应，不一律退回含眼口中近景。
5. **试读/试演决定节拍，不由字数或慢放臆测。** 电话等长对白先正常语速读完整原话，沿信息、刺激和情绪变化定位停顿、反应和声桥；原话跨镜只说一次，不靠重复回远景凑节奏。复杂操作按必须顺序试演手和物的节拍，估计与实际计时分开，慢放参考的时长不是现实动作工时。时间不足返回拍法/分段职责处理，不能压掉必要接触、加速对白或改用户时长。
6. **按真实依赖回归，而非按手填目标名单收尾。** 修改镜头/状态/引用后，先由现有source_shots反向查出所有实际承载该镜的生成段，再按共同场景、持续实体和前驱/后继边界找直接受影响接口，读取相关完整段。摘要缺source_shots或邻段正文时先回查已知完整导演/视频源，以段ID及原字段逐字或哈希核验同版后恢复映射；未读取不等于缺资料。真实来源仍不可得时只核已知导演镜头，不虚造生成段。发现同类错误时核同场/同类动作或物件的其他出现位置；非目标字节未改只证明没误改，不证明连续性通过。撤图逐项检查其原职责：由仍有效的真实来源承接、由准确文字保留可观察属性、或由合法不出镜解决；替代不能满足必要视觉身份时留缺口，不恢复用户取消的假手持图，不把“同一个”当视觉来源。记录具体检查范围与未核项即可，不扩大修改授权。


## 连续现场的重点反例

先问三个问题：动作开始需准备什么，结束后必须保留什么，观众必须看见什么才能接上。公共条件只放真正不变项；每段入态写“已经完成后的状态”（如盒已在女主手里、丈夫空手），不重抄上一段“丈夫把盒递给她”让模型重演。手别按人物自身左右，不混同画面左右。

以下是上述状态自查的适用细化，不新增人物模拟器、逐动作台账或每镜出图任务。事实仍在同一 `start_state/change/end_state`、`space_rules`、`take` 与核对备注中：

- **世界锚点与在场关系**：以门窗、水槽、柜、桌边、椅位和地面通道定位，不以画面左右/前后代替。逐切检查实际在场者与画外者、坐站朝向/支撑、交流对象、双手占用；画外继承状态，切镜和生成段均不能重置。袋的身份、相对身体尺度、外形装量、收口与持手连续；外箱、产品旧盒、新盒、红盒分别追踪，交产品盒不授权外箱搬家。改变须由已有合法动作或明确时间省略支持；程序不能从自然语言证明路径可达。
- **动作的承托和进度**：同一操作者当前持有碗/盒且占用了开封/取镯所需接触或手时，先落稳并释放以空出所需手；本次产品操作仍以先放碗最清楚。通用判断看可见接触、稳定承托与受力，不设“一手只能一物”：允许原剧情已有另一人承托、真实支架，或有可见稳定受力的合理同手兼持（如钥匙与盒）；不凭空增加第三只手、不存在的支架或新演员来过关。每支一次性管独立核 `sealed→opened→dispensing→empty` 的动作进度；安全横放或托架是各阶段暂放/结束时的支撑要求，不必等空管才能放下，也不重置开封进度。挤压可多次，开封只一次，切镜不重新掰头。已出料不等于全量空管。封头由手接触取下、落碟、释放后才出料；尖端不可作为无支撑直立支点，横放需干净承托面、管口避污，真实专用托架另核。
- **结构、材质各有来源**：盒内采用盖托/底托和实际槽位，不写随镜头翻转的“画面上/下排”代替结构；取后空槽保留。造物者实拍白A在盖内托，金B在盒底托；不是从金排抽出白管。管色不决定料色。A/B分别对真实动作片看料条连续性、粗细、落碗累积与慢铺展；半透明且黏性可见是合法B外观，不能把透明本身判水、强写金黄或不透明。未知属性留未知。
- **护理的前提和结果**：已获准的夹发准备拍到完成态；护理期间临时发型持续，身份参考不将刘海压回额头。等待保真实15–20分钟或准确源时长，以生活动作和时间省略表达，不延长已定成片。擦膜ECU明确脸颊皮肤、湿巾接触边、带走胶体、擦净路径与离肤；其前后仍交代全脸未擦区及末处主膜被带走，不一抹全净。净脸结果留自然纹理、同曝光白平衡、洁净水润与舒展神情，不靠漂白磨皮。
- **构图与跨场**：双眼局部镜在真实画幅只取一组眼睛，不用上下拼脸填空；通道人物的脚即使画外也继承落地支撑，不能靠透视猜踩台。离厨去餐厅等先交代收回动作、看向/转向出口与带一步，再按同一方向入场；无需拍满走廊或机械补图。戴镯若无法可靠表现，可比较“盒已落桌释放→取镯起势→接收者反应→腕上完成态”的因果省略，不强求高风险穿掌全过程；产品关键操作不可借此跳掉。

场景持久物后态与人物调度关系是两种用途：无人环境后态图不能证明人物坐哪、谁持盒。人物关系图若椅位/桌侧与源空间不兼容，必须修正或替换并待审，不能只写“仅取关系/不取眼神”豁免几何冲突。持续场景变化仍先制新态图再用于后续，普通走位不每动一拍就生图；取消的手部过程图不恢复。表演关系的高风险状态只按需补，用已有正确参考优先。
