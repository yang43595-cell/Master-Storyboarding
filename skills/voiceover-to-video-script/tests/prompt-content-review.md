# 提示词内容审查压力样例

维护该规则时用以下小样例复核实际决策；不运行模型，不修改项目。它们不是按词匹配的生产校验器，不能将特定道具或人物名写成全局禁词。

| 输入事实 | 应有决定与最小处理 |
| --- | --- |
| 公共条件“近侧椅留给从卧室走来的女主；她左手持碗、右手持筷”，正文才“在近侧坐下，端起饭碗，拿筷子” | 内容不通过，暂停该段写入；去掉提前持物结果，保留正文动作顺序，再复核。即使保存回读一致也不放行。 |
| 顶部完整素材职责，末尾同义职责加真实 @ 重写一遍 | 合并成一套职责并保留对应真实引用及其身份/顺序；不删引用来去重。 |
| “按参考准确换屏或后期合成”且执行方案未定 | 不通过，依现有确定方案分清职责；若需新决定则报告缺口，不能擅自把全部屏内内容转后期。 |
| 三层标题、必要风险约束、屏面稳定与阅读停留；模型按已定方案呈现剧情内 UI | 这些本身合法，不因长、含否定词或提及屏幕而删除；仍核具体来源与执行责任。 |
| 真实原生 @ 标签含版本号或“待验收”，普通正文没有内部路径 | 不按手写 ID 泄漏误判；另核真实引用身份与当前状态，不用标签证明已确认。 |
| “不叠加画外字幕，同时添加字幕” | 后半仍是不允许的叠字指令；前半否定不能豁免整段。对应有限机器回归见 test_video_output_policy.py。 |
| 同稿写前内容审查有真实依据并通过，随后原生回读缺一项素材 | 内容结论不替代绑定；报告回读失败，修复授权范围内的绑定并重新回读，不宣称完成。 |

实际复核分别记录内容判断、机械检查覆盖和未验证事项。上述样例通过不是对任意文本语义的自动证明，也不批准候选、缺图或视频生成。


## 本轮要求与多模态参考边界

下列为合成规则回放，不是自动语义/视觉识别或生成效果测试。

| 输入事实 | 应有决定与最小处理 |
| --- | --- |
| 用户和导演已明确嘴部大特写，只有制作备注写“保留”，实际正文仍全程中景 | 要求未落实，不通过该项；修正候选实际正文，不把来源正确当保真。 |
| 用户本轮只改某段语气，其他已确认段未变 | 回读相关依据，核语气及直接声画影响；保留未变化范围，不重做全片或因重读自动新修订。 |
| 已核深度视频只提供动作，实际入口仅有普通视频参考 | 按真实普通视频引用写清动作/空间职责，人物外观仍用相应确认素材；不要求Depth槽，不承诺1:1。 |
| 动作视频原音含对标对白，本段只需要动作 | 排除原音及无关身份/环境，核准确文件和实际片段；不能把原音误当本段对白。 |
| 已明确选用音频语气参考，但未听验，只有文字摘要 | 保留未核，不能声称已听或声音适用；相关提交不得凭摘要放行。 |
| 小云雀历史参数存在，现改用红帧且当前控件能力未知 | 不搬用历史参数当能力事实；核当前入口，未知依赖留缺口，不擅改用户选择求通过。 |
| 仅交提示词候选，平台未写入且尚未生成 | 可报告实际文字审查范围；上传、原生绑定及成片效果未执行，不要求伪造回读或视频结果。 |
| 合法无参考正文、无需摄影光学的二维内容，且所选入口允许 | 省略无关素材及光学项，记录适用判断；不为表项完整补图、音频或参数。 |
| 正文职责正确，但实际上传的是同名旧视频或换了片段 | 素材身份/用途未通过；核准确输出与绑定后再交付，不沿用旧看听结论。 |


## 画布交付入口与完成范围

以下仍为合成人工规则回放；不访问业务画布，不证明平台适配或生成质量。

| 输入事实 | 应有决定与最小处理 |
| --- | --- |
| 红帧额度无限，用户只要求写稿上画布 | 可在写入授权范围保存，不触发生成；额度不能代替每次生成同意。 |
| 用户明确批准红帧一个列明片段的批次 | 仅执行该批次范围，不要求逐按钮重复确认；失败重提或新增片段须另获同意。 |
| 红帧提交超时，是否生成未知 | 只读查原任务，不能认定未提交而重复生成；查明确失败也不自动重提。 |
| 小云雀旧原生实体/参数有记录，红帧当前映射未核 | 不套旧映射、不凭模型同名确认能力；受影响字段保留未核。 |
| 比较器对手填期望值返回一致，但未实际刷新和采集 | 不构成真实回读，报告未验证；不能用 after_refresh 声明或离线通过补证。 |
| 红帧正文引用已读回，但未核布局保存或截图仍遮挡 | 仅报告字段范围已核，画布交付未完整；按实际能力修布局，不重生成内容。 |
| 已有草稿无结果，用户本次只验收画布 | 以参考与草稿完成范围验收，不要求生成视频来填结果区；不冒成片通过。 |
