# 视频提示词交付结构

内容结构参考：完整业务内容保存为同一 JSON，下面的标题与段落只作为按需阅读排版参考，不再要求同义 Markdown。无关项省略，不保留空表；全片共用来源、模型和确认事实写一次。

声音参考仅在用户明确选用时列入素材，未选用时省略，不写“未提供／待确认”占位；对白和必要配音安排仍按原稿交付。

# 本次视频提示词

来源与范围：导演包、叙事包准确路径/版本及镜头范围。
模型与平台：本轮明确选择。小云雀新写入草稿显式选择 480p，保存后读回确认；不沿用旧稿 720p，不自动改用户时长、模型或画幅。
状态：本轮创作段落范围、已完成与待完成部分；确认的版本、范围及依据沿用现有记录，另列生成授权范围。单段确认不代表全片确认。
创作段落：按场景或剧情阶段标明名称及来源镜头范围，其下列出本轮实际生成片段；同场景可有多个创作段落，生成片段编号在全稿中连续且唯一。

剧情涉及放大/缩小时，仅在此处补全片共用的“尺寸状态与比例依据”：已确认变身/恢复节点、各状态生效范围、适用比例图及其允许继承/禁止继承的职责。没有确定尺寸数值就不填厘米；未确认的全片比例图或新增用途列为缺口。

各有关段在素材行实际列出比例图及正常尺度参照，不以正常人物板或“微缩”文字替代。变身段分别核对变化前和变化后状态，未到恢复节点不能提前使用正常尺寸作为空间依据。

## 第 1 段：事件名称

来源镜头：按原顺序列出。
生成时长 / 目标剪辑时长：分别说明；独立单镜或限制拆段给出真实理由。
素材：本段实际上传顺序、准确路径、引用标记、主要职责与相容的允许继承范围。
声音与衔接：仅列操作者所需配音安排、跨段衔接或复杂估时依据，不重复正文。

### 提示词

写完整可提交正文，不用“同上”、内部 ID 或路径代替内容；对白直接使用原文及说话者。


下面方括号是填写提示，不是提交文字。仅保留本段有来源且适用的内容；没有参考素材时，删除素材区。

### 素材职责

[平台原生素材引用]用于[角色身份／场景空间与光向／产品外观／已有动作范围]，继承[具体内容]；[确有串用风险时，注明不借用的身份、背景、声音或状态]。按实际使用项续写。

### 公共条件

[时间、地点及开场状态]。[人物位置与关键物件关系]。[本段共用的光源或方向、照到谁或什么、形成的可见结果；保持或已有变化]。[已确定且有可见含义的整体风格、环境声与音乐安排，适用才写]。

这里只放持续条件与真实开场；装袋、换手、坐下、擦净等稍后才发生的结果留在正文对应位置。不得把场景末态摘进公共条件后，又让正文从未完成状态开始。只有确需概述变化时才明确写“开始……，随后……”而不是并列两个同时状态。

### 连续视听正文

[开场景别、机位关系和构图]，[有依据且适用的焦段倾向及其光学目的]，[焦点落在哪里；导演有拉焦安排时写起止对象及触发]。[人物从什么状态开始，做什么，动作如何发展；摄影机按原定方式固定或运动，交代必要的起幅、路径与落幅]。

[说话者]以[原定语气、重音、停顿或声音质感]说：“[原文片段]”。在[导演明确的动作阶段／信息变化／词句触发点]，[按原定切法切到什么画面，或不切而继续当前镜头]；[此刻画面中的动作与反应]。[如果声音跨镜，明确原说话者继续在画外说出的后续原文，不重播前半句；同步关系按原稿]。

[按真实先后继续写其余镜头与动作，不要求每段固定三镜，也不重复公共设定]。到[可观察的结束状态]，[原定停留、收声、段末切法或下一画面衔接]。

最后一项须区分执行归属：同一生成段内的切镜写入正文；下一场已分配给另一生成段时，本段止于自己的末画面，不再要求模型生成下一段开场。原导演的硬切、叠化或声音桥保留在现有“声音与衔接”备注供两段连接，不能因此删掉导演决定、额外生成一遍下一场或改用户选择的时长。

生成画面不添加字幕、片头或片尾文字、说明字卡、时间描述、时间码或其他叠加文字。正文中的秒数与切镜时间只控制动作和剪辑，不在画面显示。

[其余仅在本段确有必要时补充少量专项约束；没有则删除]。

## 填写时保留的边界

- 开场状态、身份、空间、动作、镜头、声音、必要约束和完成状态，是完整性核对的八项，不是必须分成八个标题。完成状态写成模型看得见、听得见的收尾，不写内部验收口号。
- 公共条件与单镜要求一起读取：全片 director_rules、场景 space_rules/defaults，以及 camera、take、cut/rhythm。overrides 只覆盖出现字段，省略则继承、空列表则关闭，单镜例外不自动延续；持物、站坐和动作前态仍须连续。
- 从导演稿继承决定，不重新设计。精确到某字或某动作相位的切点，只有导演已给出时才照写；来源只有“说到某句时”，不能擅自精确成某字。缺失且影响实现的拍法返回导演明确。
- 焦段、焦点与景深不是同一项。适用时保留“焦段倾向＋可见光学目的”，以及导演要求的清晰对象和焦点转移；设备名、精确焦距和光圈只在已有依据且确有用途时写，不凭景别推算，不为专业感填参数。
- 一句对白跨多个镜头仍只播放一次，按顺序写各镜承载的片段。画内、画外、旁白及无声画面文字区分；字幕、片尾文字、说明字卡、时间描述等可叠加文字只在正文外的后期文字安排中保留原文、显示时机与顺序，不提交给视频模型生成；它不是对白、旁白、配音或口型任务，阅读停留另行估时，不计入有声语速。后期配音时不要又要求模型生成同一句人声。
- 共同光线与风格在同一生成段只交代一次；变光写触发、变化过程和结束状态。每个独立生成段仍须自包含，不能依赖另一段的“同上”。
- 有真实素材才引用。平台要求原生 @ 实体时，须在平台选中实际上传素材；键入“@图片1”文字不等于绑定。动作参考不自动提供角色身份、环境和声音，状态图不自动成为首帧或尾帧。
- 普通切镜不自动拆成独立生成段。确因能力限制拆开连续事件时，另核对动作相位、持物、光线及实际衔接参考；缺桥图或缺确认就如实留缺口，不能写成已经具备。

以下继续为制作信息与交付检查，不复制进模型正文。

后期文字安排：在同一 JSON 的既有制作备注中保存原文、顺序、显示时机及阅读停留；原文只保留在这里，不复制进提交正文。按[对白与时长方法](../modules/video-method.md#对白与时长)核对覆盖，不删除上游文字，不改用户选择的时长。包装、商标、道具或场景实物固有文字仍按真实参考保真，不因本条擅自抹除、改字或改品牌；不得把后期字卡伪装成实物文字。

按同样方式完成当前创作段落内其余实际生成段；后续创作段落确认推进后追加到同一稿件。外部广告等非生成段明确标记占位，未知时长不编造。

## 连续事件的跨段参考（确因时长拆分时才写）

前段 → 后段及拆分原因：{准确段号，不能仅按切镜机械拆分}
共同切点状态：{前段结束=后段开始；人物/道具位置、朝向、持物接触、动作相位、相机与明确变化}
实际桥图：{已确认artifact ID、修订、路径、登记hash与获准用途；同图复用或同状态不同机位的依据}
两侧输入：{前段@图片n的尾态职责；后段@图片m的动作前态职责；采用的实际平台控制能力}
返工影响：{何种变化使后段旧引用无效；本轮已复核或真实未决事项}

以上保存为同一业务 JSON 的制作信息，不新增平行请求或机器计划；正文仍不带内部ID、hash或文件路径。

## 自查与未决事项

注明自查范围，简记镜头覆盖、对白、时长、素材与连续性结论和真实缺口；每轮检查当前段落与跨段依赖，全部完成后补充全片覆盖、衔接及节奏复核结果。没有问题时不另建问题表。实际生成后才追加任务 ID、输出和状态，不预填成功。

返修的影响范围由本稿source_shots反向派生并核直接接口，不以手填目标段清单代替；实际方法见[状态与节拍步骤](../../storyboard-planner/modules/shot-planning.md#把创作决定落实为可验证的状态与节拍)。新修订不继承旧native_binding已回读状态，准确核验方法见[交付快照](../../../docs/development/delivery-snapshot-checks.md)。
