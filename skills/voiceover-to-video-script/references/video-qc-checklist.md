# 视频质检清单

仅在用户明确要求生成结果内容质检时使用；普通下载先完成所用入口要求的文件技术检查，不自动开展本清单的完整视觉审查。按已确认拍法、声音策略与实际生成结果检查，勾选不代表用户采用。

开始前绑定本轮准确任务、媒体文件及版本，核对来源提示词与已确认拍法。沿现有交付记录写实际观看/听核范围、问题时窗、观察与未核部分；不适用项注明理由，未执行不勾通过。发现问题先区分提示词、素材、任务实际输入或生成结果，给出受影响范围；返修与重生成仍按授权，修后重新检查实际新媒体，文字改好不能关闭旧成片问题。

## 一、技术质检

- [ ] 本地 mp4 文件存在。
- [ ] 稳定文件名已设定。
- [ ] ffprobe 已检查：
  - [ ] 时长
  - [ ] 文件大小
  - [ ] 视频编码
  - [ ] 分辨率
  - [ ] 帧率
  - [ ] 音频流
- [ ] 已用适合本次问题的观看方式核对；需要时定向抽帧或制作联系表，不强制每段九宫格，抽帧不能代替动态动作与声画检查。
- [ ] 任务标识与平台实际报告的用量已记录；未提供的消耗保持未知，不编造。

---

## 二、视觉质检

- [ ] 风格正确，无意外 2D/3D 断裂。
- [ ] 背景连续性可接受或为有动机的切点。
- [ ] 角色形象稳定。
- [ ] 产品形象稳定。
- [ ] 要求的动作拍按顺序出现。
- [ ] 事件前后连放逐人看：旁人的原活动、视听条件、察觉与反应成立；查能察觉却无依据地毫无反应、提前反应、复制动作。未察觉、克制、僵住或有依据的同步反应可成立，不强制错峰；需要读脸时在实际观看大小可辨。
- [ ] 沿完整取得/交接过程追踪关键物件数量、位置和持有人，核接触、承托、释放与落点；遮挡/出画后不凭空复制或消失，不能只比首尾两帧。
- [ ] 跨镜核人物自身左右、固定饰件、天气及动作相位；反打不重置实体状态，已接稳不再接一次。有意时间省略与新场建立按来源判断。
- [ ] 无当前剧情或产品参考以外的无依据增生物件与结构；不把某一历史案例的毛孔/洞口等约束套到全部内容。
- [ ] 有产品机制或宣称时，实际表现符合已确认来源；无此内容写不适用。
- [ ] 产品广告存在结果/英雄镜头时，核其是否符合本轮已定表达目标；普通剧情不套用广告结果镜头标准。
- [ ] 对直接接续的两段，将实际选中的前段落幅和后段起幅连放，核动作相位、持物、空间与光线；要比较原版、超清或历史结果时，先核是否来自同一条演绎。无源任务证据的配对保持未绑定，不用时长或当前编辑稿推定来源。
- [ ] 广告必保过程按实际画面计可读时间并核变化路径：例如两剂在同碗从可辨的起态过渡到终态、擦拭中已擦和未擦区域是否逐步改变。仅出现开始与结果的两帧不能算展示过程；关键包装在挤压、抓取与收尾等实际出镜状态分别对照真实参考。
- [ ] 生成底片没有字幕、片头/片尾文字、说明字卡、时间描述、时间码等可叠加画面文字；指令中的秒数和切镜时间没有被渲染。上游无声文字只在后期安排中逐字、按序核对，不作为模型生成内容。
- [ ] 真实包装、商标与场景实物固有字样按参考保真，不因禁止叠字而擅自抹除或改造。后期字卡不得冒充实物字样；不新增无依据水印或 UI。

## 三、音频质检

- [ ] 按本轮确认的声音策略判断模型音频是拟采用声音还是临时参考，不默认一律替换。
- [ ] 实际听核生成片段是否出现背景音乐（BGM），有则记录段号和出现时段。
- [ ] 环境声有可理解的声源、距离/遮挡及事件前后变化，与人物靠看见或听见作反应的条件一致；冲突不自动要求全场静音或尖叫，有意静音核拍法依据，字幕/转写不替代耳听。
- [ ] 实际听核对白原文、说话者、顺序、漏播/重复与声画衔接；音效按来源要求核对。未听验不得标为声音通过。
- [ ] 仅在既定后期配音安排或实际缺陷确需处理时列后期替换建议；不自行改变已确认音频策略。

## 关键接缝试剪

在已明确授权生成且包含接缝验证时，批量前从实际风险挑少量相邻段先试。优先选多人站坐或道具交接、关键情绪承接、需要观众读出时间变化的接缝，按本片实际风险取舍。草稿交付可把优先试的段号和理由留在现有交付备注，待可用媒体与授权齐备后再试。

取实际拟用的两段，按预计裁切和音轨连放。空间已经读清时，检查后段是否又耗时建立同一关系。刺激与回应分开时，检查尾音、动作和听者反应是否接得住。时间跳切先查审看片段里是否已有原定的声音、画面或后期时标，再判断观众会不会误读为立即发生。对后期尚未加入的提示，记为待合成并留待粗剪复核。只抽帧时可核画面证据，动态和声画结论须实际播放及听核。

在现有交付记录留两侧段号、选用版本、试剪起止点、所用声轨和待后期项。优先试裁冗余、延续已确认原声或复用现有可用镜头，保住关键表演、必要动作和原对白。确实缺画面时，说明补镜对应的剪入／剪出位置、应保留的声音和所需画面。实际补做按本轮授权，只复验该段及相邻接口。试剪通过只覆盖所试组合。


## 短动作证据与结论强度

概览1fps只能定位，不足以断言亚秒动作“没有开封/没有重复”。脱头、手物接触、落物/离手、切镜跳变等先在疑点前后以0.1秒或逐帧密查，注明实际覆盖时窗与源节点/hash；密帧仍不能证明未取样的帧无问题。电话离耳不自动等于真实挂断；ASR重复文本不等于真实重读，需可靠听核与声画对齐。源对白本来两次告别不能被内容去重。

不把用户reported升级为已复现，也不因本轮未复现而撤销。已写正确要求、编辑器回读、实际job输入、生成结果分别报告。无视频的规则/提示词回放只证明规则在这些输入上的应用与候选文字变化，不宣称像素修好、真实生成通过或原结果已修改。

场景复审使用[候选检查的实片复审边界](../../../docs/development/scene-realism-checks.md#实片复审和进入知识库的条件)：结论只写通过、需修、未验证、不适用及具体依据，未检项不随总体通过被隐藏。
