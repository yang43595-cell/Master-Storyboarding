# 视频质检清单

视频生成后、标记为就绪前使用。

---

## 一、技术质检

- [ ] 本地 mp4 文件存在。
- [ ] 稳定文件名已设定。
- [ ] ffprobe 已检查：
  - [ ] 时长
  - [ ] 文件大小
  - [ ] 视频编码
  - [ ] 分辨率
  - [ ] 帧率
  - [ ] 音频流
- [ ] 代表性抽帧已提取。
- [ ] QC 九宫格/联系表已创建。
- [ ] submit_id 和额度消耗已记录。

---

## 二、视觉质检

- [ ] 风格正确，无意外 2D/3D 断裂。
- [ ] 背景连续性可接受或为有动机的切点。
- [ ] 角色形象稳定。
- [ ] 产品形象稳定。
- [ ] 要求的动作拍按顺序出现。
- [ ] 无多余的毛孔/洞口/地标。
- [ ] 产品机制符合宣称。
- [ ] 结果/英雄镜头不过度强调原始问题。
- [ ] 无多余字幕、文字、水印、UI。

---

## 三、音频质检

- [ ] 如果存在模型音频，视为临时参考。
- [ ] 检查是否出现不想要的背景音乐。
- [ ] 检查要求的对白/音效是否大致出现。
- [ ] 规划后期替换：精准对白、字幕、音效和混音。

---

## 四、决策

- 保留。
- 保留（含裁剪/后期音频备注）。
- 局部重跑特定段。
- 先重生成源图。
- 废弃。
