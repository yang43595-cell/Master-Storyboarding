# 生成异常处理

只查当前实际问题，不自动重跑或启动上游 Skill。

- 超时或结果未知：用已有任务 ID 查询；不能确认是否提交时暂停，避免重复扣费。
- 素材错误：核对实际文件、上传顺序、段内引用和职责，只修相关段。
- 动作没有忠实生成：对照导演决定、实际输入与结果定位缺口，提出修改候选；不得擅自删剧情、改机位或付费重跑。
- 状态参考被当作首尾帧：核对实际模型能力和素材职责，不假定平台支持严格首尾帧控制。
- 台词漏播/重复或声音冲突：对照原文和实际播放安排，区分后期配音与模型生成声音；反应镜头不自动重播对白。
- 下载失败：先查询原任务并检查输出路径，不能以成功状态代替文件验证，不覆盖确认产物。

- 空间/接触/尺度或画面连续性错误：先沿原导演→白模/真实参考→成图→本段实际输入定位；按分镜参考契约判断改白模、复用有效白模重新生图或无需白模，不只调负面词
- 连续事件跨段接不上：核对共同切点图和两段实际上传项；前段返工改变了参考时，后段旧绑定停止复用。回分镜步骤补/重选具体状态图，确认后再更新两段，不自动重交视频

- 角色忽大忽小：先查剧情尺寸状态、实际上传文件和职责，而不是数正文“微缩”次数。确认正常人物板有没有被当作世界尺寸、比例图是否包含正常锚点且覆盖本段、跨段是否用了不同或过期状态。按已有参考契约返回相应补图/白模层；新增全局比例依据仍需确认，不固化试验厘米值

持续无法解决、来源冲突或需新增授权时报告具体缺口。缺少机器计划或阅读凭据不是新流程的阻塞原因。
