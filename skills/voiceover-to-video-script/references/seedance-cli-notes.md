# 授权后的 CLI 执行

仅在用户要求生成、查询或下载时读取。历史已核 Windows 工具路径为 C:/Users/LIUYANG/bin/dreamina.exe；使用前确认本轮执行环境实际可用，不将该路径当作云端或 Mac 入口。调用前读 multimodal2video -h 并对照平台合同；必要时 user_credit 查看额度。不以历史文档参数或 CLI 默认值代替当前能力和用户选择。

## 提交前

直接使用本轮确认的提示词、真实素材和参数，不恢复退役的机器计划、视频准备包或打包器。现行的来源版本、确认范围、资产引用与交付检查仍按 [素材与提交交付](seedance-delivery-package.md) 执行，不能用本节绕过；候选登记不等于用户确认。当前执行者核对：
- 来源、提示词和素材已确认；用户授权覆盖本次上传及生成。
- 文件存在且非空，素材引用与实际上传顺序一致，声音策略无矛盾。
- 所选模型支持当前时长、参考数量、比例及分辨率。
- 输出位置明确，不覆盖已有确认文件。

已有明确模型和授权在范围不变时复用，缺实质参数才询问。不把“写提示词”视为付费授权。

素材清单与实际命令分别核对：模型正文的每个图片/视频/音频引用须对应本次真实传入的文件、顺序及职责；需参考的任务不能把素材只留在文档里，却改用纯文字生成。素材缺失先停相关提交，不自动补图；确无参考的纯文字任务须符合本轮明确选择。只上传提交正文，制作备注和检查报告不进入prompt。

按实际帮助传入 --model_version、--duration、--ratio、--video_resolution 及所用 --image/--video/--audio。--prompt 传实际正文，不传路径；PowerShell 用 Get-Content -Raw -Encoding utf8 读取 TXT，以独立参数传入，不拼接执行字符串。未获授权只交付，不调用生成。

## 查询、下载和结果

提交后立即在现有交付记录记下返回的 submit_id 和实际参数。用 query_result --submit_id=<id> --download_dir <目录> 查询与下载，参数以当前帮助为准。超时、断线或结果未知先查原任务，不自动重提交；无法确认是否提交则暂停，避免重复扣费。

下载到用户指定位置；未指定时使用项目 06_视频/片段 中不覆盖旧文件的新名称。成功状态不等于落盘，用 ffprobe 检查实际文件可读、时长、分辨率及音轨，交用户审片，不自动抽帧或宣布视觉质量通过。

在同一文档记录实际提示词路径、素材、参数、任务 ID、平台报告用量（没有则未知）、结果与输出路径。明确失败后的重跑仍须在原授权范围内，新增费用/范围需用户决定。不另建运行时、重试框架或重复状态文件。

用户已确认最终剪辑时，在现有记录开头追加当前采用事实及准确范围，保留历史提交结果；不把最终剪辑采用扩成每条原始生成片段或全部上游稿重新确认，也不继续要求审片或自动重跑。项目状态需同步时使用 `scripts/core/project_state.py` 的同一状态渲染/保存入口，保持JSON与说明页一致，不手工维护第二份状态。
