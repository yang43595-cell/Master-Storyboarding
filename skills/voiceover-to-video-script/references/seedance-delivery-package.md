# 素材与提交交付

交付一份完整分段提示词文档，不依赖 production_plan、打包器或请求 schema。每段列实际上传文件顺序、引用标记及唯一职责；素材 ID 或文件夹不能代替实际文件。核对文件真实存在、非空且属于本次确认参考，涉及真实外观时实际看图。

给用户文档的可点击路径，以及图片文件夹、准确文件名和段内顺序；遵守项目图片交付约定，不嵌入大图或 Base64。共用素材可列统一清单，但每段实际上传序号须明确，生成模型不能依赖其他段正文。

实际提交需要时才保存对应 UTF-8 TXT，内容与确认稿一致。参数及图片/视频/音频输入以所选模型当前能力为准。声音母版仅在用户明确采用声音参考时核对，不把试听候选当作确认声音；未选用时按[项目可选边界](../../../PROJECT_RULES.md#导演稿之后的生产顺序)省略该项。

交付不等于授权上传或付费，素材和参数检查不证明生成效果。来源、授权或文件缺口直接报告；不创建重复请求快照、预检 JSON 或机器计划模拟授权。
