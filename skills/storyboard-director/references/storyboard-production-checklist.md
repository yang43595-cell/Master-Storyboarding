# 视觉补充检查表

按[导演到视频的视觉交接](../../../docs/rules/visual-production.md#导演到视频的视觉交接)核本轮全部待写词镜号，按[补图范围与计数](../../../docs/rules/visual-production.md#补图范围与计数)确定新增目标。普通镜头可成组记录，检查结论须覆盖实际镜号。仅交接已完成检查且所需素材就绪的范围。

## CHECK-REQUEST

- [ ] `CHECK-REQUEST-01` 来源为本轮已采用的 `storyboard.package` v4 revision，旧 v1/v2/v3 只读。`source_shot_ids` 合计覆盖本轮实际需要写词的镜号。检查记录的 `visual_review.storyboard_sha256` 与采用版一致，`visual_review.observation` 记录同版的实际检查。漏查范围先补齐。
- [ ] `CHECK-REQUEST-02` 每组的决策和证据相符。
  - `no_supplement`（`not_needed`，`max_images: 0`）在 `visual_review.observation` 写本组的具体可见事实，以及现有素材如何覆盖或导演安排为何无需额外静态控制。必须选定的关系图单列复用，仍缺素材、还没检查或应退回的范围保持实际状态。
  - `reuse_existing` 列实际采用的参考及其覆盖。必用既有关系图在 `relationship_reference` 用 `ref_id` 与 `sha256` 指向 `existing_references` 中的一张准确图片，身份使用 `AST@输出` 或已采用分镜图的 ART-ID，并核对这张图的 `layout` 或 `state_reference` 用途。
  - `request_supplement` 写明当前参考缺哪项、可观察证据、为什么需要图及缺图会影响哪些镜号和事项。
  - `return_upstream` 写明具体矛盾或缺项、受影响镜号及处理方，相关范围待修订后复核。
- [ ] `CHECK-REQUEST-03` 补图请求要有唯一静态目标、必须出现、禁止出现、保留项和候选上限。相同状态与用途合并覆盖镜号。各独立目标优先选既有合用图，缺图时先做一张。
- [ ] `CHECK-REQUEST-04` 确认资产、动作参考和产品实拍已完成盘点；足够时选择复用并停止生成。
- [ ] `CHECK-REQUEST-05` 问题不是剧情、导演镜头、连续性合同或表外资产错误；若是，已返回对应上游。
- [ ] `CHECK-REQUEST-06` 已先检查跨段共用的位置关系，再核单镜动作。已查人物与门、桌边、座位等固定物的位置和可达范围，以及人物对面／相邻、遮挡、视线和持物。身份图、空景、单品图按实看内容分配职责。用户决定、执行判断和采用依据分别核对，已确认选择可沿其原范围复用。
- [ ] `CHECK-REQUEST-07` 涉及连续动作时，已按导演来源核对上一状态、本图职责和后续状态；不明的站位、持物或动作进度没有被猜成既定事实，衔接矛盾已返回上游。

- [ ] `CHECK-REQUEST-08` 返工已定位到导演、资产或成图，并写明需调整的具体内容。
- [ ] `CHECK-REQUEST-09` 按导演相邻镜核会跨段继承的人物关系、持物和可见状态。视频阶段实际拆开连续事件时，回查确切切点、前段最后可读与后段最先可读的镜号和相位，再判两侧能否共用同一图。现有参考只覆盖一侧时，记录另一侧的具体缺口。切换场景、事件结束或省略时间后仍有关键条件继承时，也核对两侧。

- [ ] `CHECK-REQUEST-10` 当前请求、选择记录与本轮用户依据一致；目标/范围有变已先修订请求并复核受影响来源，不只依赖压缩摘要。

## CHECK-PREGEN

- [ ] `CHECK-PREGEN-01` 请求决策为 `request_supplement`。`max_images` 的 1 至 4 张是同一目标的候选上限。单批最多 8 个独立补图目标。项目张数按去重后的状态与用途计，实际批次和候选用量按各自授权范围执行。
- [ ] `CHECK-PREGEN-02` 实际参考集合覆盖目标且有充分余量，每份参考注明负责的身份、服装、场景、产品或动作状态。环境资产的多角度参考按实际覆盖选用，产品镜头按对应状态使用产品实拍或指定的真实参考。
- [ ] `CHECK-PREGEN-03` 提示词只转译来源镜头的唯一静态状态，没有重写镜头设计或夹带视频指令。
- [ ] `CHECK-PREGEN-04` 生成工具、具体模型及成本范围均可从本轮有效授权核对。
- [ ] `CHECK-PREGEN-05` 画幅默认竖屏 9:16，有明确指定按指定。按参考资产契约核景别、截幅、前态位置及视线、产品尺度证据。实际输入按共享“返修参考与固定基准”核对，只使用本轮有效参考并保留合格基准。
- [ ] `CHECK-PREGEN-06` 已读镜头完整正文、场景设定及相邻状态。本图相关人物的位置、支撑、双手与持物、朝向、注意对象和反应均有依据，属于同一时刻。动作前图停在首个新增事件之前，前后衔接留在制作备注。
- [ ] `CHECK-PREGEN-07` 按[提示词模板](../templates/storyboard-image-template.md#提交给模型的图像正文)核实际提交正文。模型收到单一目标瞬间，镜号、来源、前后相位和内部核对留在制作备注。确有专项排除时已确认当前工具与模型的真实投放位置，按实际通道填写一次。

- [ ] `CHECK-HANDOFF-02` 每个候选可追溯到请求、来源镜头和实际参考集合。

- [ ] `CHECK-HANDOFF-08` 实际交付的准确图片、请求/来源修订、用途和获准镜号与本次观察一致；提示词计划、中间图、旧版或待审候选没有冒充已确认合格结果。未完成和未验证部分明确保留。
