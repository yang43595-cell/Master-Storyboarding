# 道具与产品资产方法

本页由现有仓库专业段落等义分流，不新增理论。第一层输入、字段、模板、生成数量、用户确认与工具授权仍以本 Skill 当前执行合同为准；Web 的明确类别比例、依赖和视图顺序按其模式合同执行。方法不能新增 AST、扩展本次需求或覆盖已确认事实。

## 一、资产分类

### 剧情道具

- 证据物：书、文件、照片、手机、信件、名录。
- 行动道具：钥匙、拖把杆、工具、餐具、门锁。
- 身份道具：制服、校徽、工牌、配饰。
- 环境固定物：监控主机、菜单牌、设备。

### 产品资产

- 产品包装、瓶、管、袋、礼盒。
- A/B 双剂和配套工具。
- 产品质地、泡沫、乳霜、凝胶和使用容器。
- 产品拟人角色或世界观道具。

## 五、剧情道具生成组

只从下列项目中选择 AST 明确要求的最小集合：

1. 三分之二角度身份母图。
2. 正面或可读面验证图。
3. 尺寸比例验证图，必要时与手、桌面或人物轮廓同框。
4. 剧情需要的状态图。

普通背景道具可并入场景母版，不需要重复建立独立资产。

## 十、产品与拟人结构

- 产品拟人角色必须保持包装轮廓、盖子、标签区、材质或工具结构的可识别性。
- 五官、肢体和服装是附着层，不得覆盖产品核心结构。
- 包装角色不能在不同资产中从软管变成瓶、从二维变成三维实物。
- 产品质地的颜色、透明度、黏度和气泡来源必须与 brief 一致。

## 六、产品资产生成组

真实产品只生成或整理 AST 已登记的展示面、比例、质地或使用状态：

1. 包装身份母版。
2. 正面、侧面和背面参考；缺少实物角度时不得凭空编造复杂结构。
3. 与手、碗、刷子等工具的尺寸关系图。
4. 产品质地母版。
5. 使用步骤状态图；每张只表现一个步骤。

## 相关表达与专业自查

- 产品名、品牌名和关键包装文字属于一级文字；应优先引用真实产品图，而不是要求模型重新书写。

- 模型生成文字无法稳定准确时，保留干净标签区，后期覆盖真实文字。

- [ ] 正面、侧面、比例图和状态图是同一个资产。

- [ ] 资产延续正式风格母版，并能自然进入所属场景。
