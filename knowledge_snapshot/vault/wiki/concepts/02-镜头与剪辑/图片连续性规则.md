# 图片连续性规则

> 图片连续性的两条路线：**背景母版工作流**（锁定背景，单层变动）锁「动作层变化时的背景」；**多角度参考图组**（四图场景锁定）锁「机位变化时的场景空间」。

## 定义

面向 AI 图像连续生成的背景一致性方法论。核心思路是"锁定背景，单层变动"——与传统动画的"背景层+角色层"工作流一脉相承，但适配 AI 图像生成的特性。

## 跨段共用帧：真实开场状态

当下一段需要表现某个道具、人物或效果“入场”时，该段最高优先级开场图必须处于**动作发生前**：入场主体尚未出现，但固定场景、角色位置、机位、光线和材质已经成立。已经展示贴合、覆盖、击中、爆炸、冲洗或其他动作完成状态的图片，只能作为动作参考或结果参考，不能兼任该动作的开场图。

跨段复用图片时，优先建立一张**双职责静止帧**：它既是上一段全部动作结束后的尾帧，也是下一段新动作发生前的首帧。只有两个时点在画面状态上完全相同，才允许共用同一张图；不得为了形式上的首尾衔接，直接把上一段仍在进行的动作图或下一段已经发生的动作图放到边界上。

执行检查：

1. 逐段写出“第一帧已经存在什么”和“本段第一个新增事件”。
2. 若第一张参考图已经包含本段第一个新增事件，则图片与提示词冲突，必须补动作前状态图或更换首图。
3. 动作状态图可以继续上传，但必须降为动作职责，并在图片职责中明确“只参考贴合／变形／撕起等状态，不作为开场状态”。
4. 没有合格的动作前状态图时，停止视频提交；不能只靠“不要从已完成状态开始”等文字限制修复源图冲突。

## 背景母版工作流

### 五步工作流

1. **生成背景母版**：一张干净的、无主体的场景图
2. **锁定固定层**：机位角度、地平线、远景物体、身体锚点、主要道具、光源方向和尺度
3. **逐帧迭代**：每帧引用母版，只改变一个动作层
4. **相邻帧检查**：逐对检查地平线、地标、锚点、位置、光源、风格是否匹配
5. **发现漂移时修复**：不要指望提示词修复源图不一致——从母版重生成漂移帧，或用动机切点过渡

### 提示词模板

```text
Use the same background master: same camera angle, same horizon, same sky,
same distant landmarks, same body anchors, same major props, same lighting and scale.
Fixed layers must not change: {list}.
Only change this action layer: {specific action}.
```

真实示例（[[sources/HELL-GRIND长片工作流拆解#画面内提示词（屏幕上未口播的文字）]]，Higgsfield《HELL GRIND》背景母版 prompt，中文）：

> 仅需对图像进行**两处最小的局部更改**即可编辑此图像。保留其他一切，保持原样——构图、树干、树根、前景的岩石、草丛和灌木、天空、云朵、温暖的地平线光晕、朦胧的大气、雪的质感、氛围、色彩等级和整体照明均保持不变。更改 1…更改 2…**整体变化幅度最大为 10%。输出一张统一的照片。与现有宽高比保持一致。**

> 要点：除了「固定层不可变」，还用「**整体变化幅度 ≤ 10%**」量化约束改动幅度，比只写"保持不变"更可执行。

### 常见失败模式

| 模式 | 症状 | 修复 |
|------|------|------|
| 母版被覆盖 | 前景变化时背景也跟着变 | 提示词明确"固定层不可变" |
| 光源跳变 | 主光源方向变了 | 母版标注光源方向，后续显式声明 |
| 比例漂移 | 同一主体尺寸不一致 | 标明占画面比例范围 |
| 道具消失 | 背景道具突然消失 | 母版列出固定道具清单 |
| 风格断裂 | 改图区域笔触不一致 | 降低改图占比，或整帧重生成 |

## 多角度参考图组（四图场景锁定）

> 解决「单张场景图满意，切其他机位就飘移/穿帮」的问题。方法源自 [[sources/小白AI短剧第12课-场景控制]]（YIQI玩AI《小白AI短剧》第12课）。
> 思路：不靠复杂提示词，而是生成一组**不同角度的场景参考图**，让模型从多个角度"记住"同一个场景。
> **阈值（执行层，以 repo `storyboard-director/references/image-continuity-hard-rules.md` 为准）**：默认每个场景只生成 **1 张 45°俯视**；仅当**时间跨度大**（该场景生成的视频时长 **>30s**）才需建完整多角度参考图组（原图+反向平视回望+45°俯视+90°正俯）。短剧能在 30s 内演完本段剧情的场景，一张 45°俯视即可看清大部分布局。

### 适用场景

- 短剧/影视分镜需要同一个场景多机位拍摄（正反打、俯拍、全景转场等）。
- 单图控不住：只给一张参考图，模型不知道场景背面、上方、侧面的空间关系 → 一切机位就漂移。

### 三步工作流（即梦 image 图生图）

| 步骤 | 参考输入 | 生成目标 | 作用 |
|------|---------|---------|------|
| 1 | 原图 | **反向平视回望**图 | 补全原图中没拍到的环境布置（场景"背面"） |
| 2 | 原图 | **45°俯视斜角全景**图 | 补全平视下缺少的物体远近关系，固化区域布置 |
| 3 | 前三张图（同时作参考） | **90°垂直正俯上帝视角**俯视平面图 | 空间总纲，把整个场景布局"钉死" |

**结果**：4 张图（原图 + 回望图 + 45°全景 + 90°俯视）构成场景的**多角度参考组**；后续任意机位生成都以这组图为参考，场景保持一致。

### 操作要点

- 模型统一选「image」（图生图模式）；若不想模型自由发挥，把要求写进提示词。
- 前两步都**以原图为参考**，第三步才组合三张图——保持「原图锚点」不被稀释。
- 与背景母版互补：背景母版锁「动作层变化时背景不变」；参考图组锁「机位变化时场景空间不变」。

### 失败模式与对策

| 模式 | 症状 | 对策 |
|------|------|------|
| 只给单图就切机位 | 背面/俯视画面编造空间，穿帮 | 补反向回望 + 俯视参考图 |
| 多参考图互相干扰 | 模型不知听哪张 | 明确每张参考图的职责（环境/远近/总纲） |
| 45°图丢了远近关系 | 物体空间位置错乱 | 提示词强调"补全平视下缺少的物体远近关系" |
| 只有局部没有整体 | 单角度对得上，全景对不上 | 生成 90°上帝视角平面图作总纲 |

### 1. 角色脸部分离（防变脸/防脸迁移明星）

| 要素 | 做法 | 原理 |
|------|------|------|
| 面部近景 | 为角色准备一张足够清晰的高清脸部图 | 给模型一个唯一可信的"脸来源" |
| 正/背全身图 | 准备正面与背面全身视图 | 锁定体型、服装、姿态 |
| **正面全身图去头** | 把正面全身图上的头裁掉/抹掉 | 逼模型只能从高清面部近景读脸 |

**为什么**：若全身图保留头，到全景镜头时模型可能从全身图上那张小模糊的脸提取特征 → 角色脸被迁移成某个明星。去掉头 = 断了模型从低清脸取样的路。

> ✅ **实测印证**（[[sources/300万ai电影开源-higgsfield-4招]]，阿絮）：两种设定图（常规 vs 无头）同场景同提示词对比——**近景无差异，镜头一拉远常规版角色脸部油彩丢失、无头版油彩保持准确**；把常规版全身照头发染红，远景素材直接调用红发 → 证明确从全身图小脸取样。（画面帧：`raw/随笔/2026-08-23/300万ai电影开源-higgsfield-4招-画面帧/t233.2-三视图测试-常规vs无头设定图远景对比.jpg`）

### 2. 多状态角色资产 + PS 蒙版局部修复

- 一个角色按状态制作**多个版本资产**：正常 / 临时 / 受伤 / 带血 / 换装，各版本独立成卡。
- 局部修改（如加一道伤疤）：**不要重生成整张角色图**。先用 AI 工具把伤疤做好，再在 PS 里做蒙版，只把伤疤小块贴回原图 → 最大程度保留初始皮肤质感。
- 原因：AI 生成次数越多图片质量越差；局部有问题就只改局部。
- ➕ **状态化资产（角色/场景/道具，[[sources/300万ai电影开源-higgsfield-4招]] 阿絮实测）**：单靠提示词难固定细节，镜头一切就穿帮。应把**同一角色的不同状态**单独做成可调用资产（换装/破衣/伤口/发型提前锁定），镜头怎么切都一致；出问题能定位改哪个资产而非重写整条提示词。**场景、关键道具同理**可拆状态（白天/黑夜、晴天/雨天、关键道具独立资产）。
- ➕ **角色卡背景要「中性」**：角色卡本身保持**中性调背景 + 平光**（少过度风格化 / 少写摄影棚），AI 才读得到更丰富细节；过度风格化反而干扰（与「角色卡像身份证」一致）。

### 3. 空间地图（在提示词里写"地图"）

不用依赖参考图，在提示词里用几行文字写清：场景里有哪些东西、相对位置、摄影机站在哪。
示例："平台在画面中央，巨石在平台右边三米，仪式中心在画面左边，摄影机始终站在门口这一侧，背后的红光从平台后方照过来。"

### 4. 多人戏开头放 1 秒全景

每场多人戏开头先放约 **1 秒全景**（不做复杂动作），让模型看清"谁站在哪里"，再切近景 → 人物不会突然换位置。每次浪费 1 秒，但大幅提升不同镜头间角色空间位置一致性。多人对话/穿帮频繁时最值得用。

### 5. 参照物证明大小比例

写"30 米高的巨人"会被缩成 2-3 米——因为数字在画面里没有证据。要用熟悉参照物植入尺度："一个人只到他的脚踝，他的手掌和一辆汽车一样宽，他的头伸进屋顶的黑暗里。"

### 6. 角色卡像身份证 + 压力测试（《卡利山男孩》升级）

源自 [[sources/1300万ai电影长片工作流拆解]]（Higgsfield 第二部长片《卡利山男孩》，官方三 Skill：LIRA/CINEDANCE/ACTING）。在前八类一致性手段上的增量：

- **角色卡像身份证（中性灰背景）**：角色设定图用**中性灰背景**、柔和均匀光、尽量无硬阴影/轮廓光、提示词里少写「摄影棚」——因为灯光/环境越复杂，越会被模型当成角色的一部分带回别场（"你本来只想固定一个人，结果连摄影棚的灯、背景色、阴影方向也一起固定了"）。与「去头」同理：让角色卡只承载"这个人"，不夹带特定场景的光影信息。
- **压力测试（正式制作前必须做）**：每个角色至少**连续生成十次**（跑/说唱/打电话/哭/大笑/换景），看不同状态下脸/身体/服装/动作是否崩；常变脸则该资产不可用。**角色与地点一起测**——单人设定的角色常在双人镜头里崩。镜头出问题不一定是提示词，也可能是资产。
  - ⚠️ **适用边界**（[[sources/300万ai电影开源-higgsfield-4招]] 阿絮实测）：完整压力测试约需**大几千块钱**（每个角色连续生成十次 + 固定声音音域/语速/口音/说话方式），更适合**预算拉满的长片/AI 电影**前期规避不稳定素材。**短视频/单一广告**可降级为只测：远景、多人同框、复杂光影下角色的稳定性。
- **主镜头 1 秒 + 空间地图（补强「多人戏全景」）**：每场戏以约 1 秒固定调度广角主镜头开头（无对白无动作），让模型先锁定谁在哪/光从哪来；主镜头后紧跟每场只写一次的**空间地图**，防角色瞬移/换位/摄像机跳侧。
- **镜头描述用视场角而非焦段**：用视场角度数（**81° 为相对稳定区**、超出风险上升）+ 画面结果（人物比例/空间关系）描述镜头，生成模型不一定真懂传统镜头参数。
- **表演档案 + 写行为不写感受**：提前规定角色紧张时眼睛怎么动、手部小动作、说话身体节奏；写行为/目标/摩擦，不写形容词情绪——人物才不是"一张会说话的照片"。

### 7. 侧机位场景图 + 场景锚点（保场景空间，实测复评）

> 源自 [[sources/300万ai电影开源-higgsfield-4招]]（阿絮实测复评）。单张场景参考图在切机位/大幅运镜时失控的**第三个解法**（与「多角度参考图组」「空间地图」互补）。

- **侧机位场景图**：正面场景图一旦远景/转机位，模型会脑补场景外空间、像换场景。更推荐**侧机位场景图**（多露一面侧墙、一段台阶、更明确空间关系）。测试：正视角机位一动出现原图没有的场景，侧视角更稳、空间关系更准。
- **补场景背景图**：视频片段涉及大幅运镜（露出更多空间）时，除正面机位图外，再额外生成**一张场景背景图**——给模型更多场景信息，避开其不稳定的自我发挥。
- **场景锚点（固定参照物）**：仅空间角度不够，再给一个**固定参照物**；如把画面中间的火堆作参照，人物怎么走、镜头怎么切都用它定位置方向；若该参照物正好是主光源，还顺带帮模型记住光从哪来。切机位后人物不易跑错位置、光线方向更一致。
- **组合**：侧机位场景图负责交代**空间关系**，固定参照物约束**人物走位 + 光线方向**——两者结合，镜头切换后模型不容易把环境、人物位置、光影关系重新生成一遍。
