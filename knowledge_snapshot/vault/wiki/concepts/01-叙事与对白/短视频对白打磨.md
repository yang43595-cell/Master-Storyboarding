# 短视频对白打磨方法论

> 短视频对白的核心不是"写得好"，而是"在边界内写得有效"——语气合约定义边界，钩子句式承载冲突，字幕节奏控制流量。

## 语气合约（9 字段）

在任何对白修改前，必须先建立语气合约。它定义了创作的边界：

| 字段 | 说明 | 典型可选值 |
|------|------|-----------|
| 平台 | 发布平台 | 抖音 / 小红书 / 视频号 / 快手 |
| 受众 | 对谁说话 | 25-35 岁护肤焦虑女性 / 成分党 / 学生党 |
| 角色身份 | 说话人是谁 | 黑头老大 / 产品成分 / 毛孔 |
| 品牌安全 | 绝对不能讲 | 不吐槽用户、不暗示产品无效 |
| 攻击性上限 | 多"欠揍" | 无 / 轻度调侃 / 角色互怼 / 反派挑衅 |
| 热梗密度 | 网感比例 | 无 / 轻度 / 中度 / 高 |
| 科普严肃度 | 严谨程度 | 轻松 / 平衡 / 专业 / 专家 |
| 吐槽用户 | 能否怼观众 | 护肤品默认不允许 |
| 句长规则 | 字数/节奏 | 默认≤15字 / 短句连击 / 长短交替 |

## 四类钩子句式

1. **三连否定+反转**：A 提方案 1/2/3→B 否定→张力积累→B 亮出奇招→反转
2. **角色自夸+打脸**：角色立 flag→外部威胁出现→恐慌
3. **荒诞自信+被揭穿**：角色立 flag→对手亮证据→认怂/嘴硬
4. **视觉矛盾开头**：画面与台词错位，利用好奇心

## 字幕节奏规则

- 单句≤15 字，超过则拆成两句
- 一行≤10 字，两行≤20 字
- 连续 3 句短句后必给停顿
- 长句（10-15 字）后留 0.3-0.5 秒停顿

## 口癖设计三要素

1. **标志词**：每个角色 1-2 个专属词汇或句式
2. **语速特征**：快/慢/拖/抢
3. **反应模式**：遇冲突时先说哪句话

**去标签测试**：去掉角色名只读对白——能分辨谁在说话吗？
