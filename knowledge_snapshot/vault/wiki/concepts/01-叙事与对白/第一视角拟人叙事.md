# 第一视角拟人叙事

> 让观众感觉被放置在微观世界中——用毛孔、黑头、产品成分的第一视角来讲述故事。

## 定义

一种将微观世界（毛孔、油脂、产品成分等）拟人化并以第一人称视角呈现的叙事技巧。通过"被清理者"的视角来展示产品功效，比客观展示更有代入感和戏剧性。

## 可选叙事弧

先判断拟人是否符合受众、用户感受和本片气质；不要把任何毛孔或成分题材都默认写成儿童化阵营大战。需要拟人时，可以参考但不必填满以下功能：

```
身份 → 冲突 → 转折 → 机理 → 结果 → 产品提示
```

1. **身份**：建立叙述者是谁、处于什么处境
2. **冲突**：堵塞、油脂过剩、压力、暗沉、入侵
3. **转折**：产品/机制到达
4. **机理**：泡沫、气泡、微粒、清洁动作
5. **结果**：世界变得更干净、更轻盈、更平静
6. **产品提示**：仅在用户要求时收束到产品展示

角色名称、口吻和冲突强度服从受众与叙事气质；不得默认“黑头老大”“泡泡军团”、夸张武器或固定善恶阵营。

## 视角规则

- 选择一个叙述者并保持一致性
- 镜头保持主观：拟人眼位、过肩视角、微距对比
- 拟人化方式不限于面部/四肢——可通过姿势、表情、运动、光线和画框实现

## 适用边界

**适合**：护肤品清洁/清洁类产品、成分机理展示、不同产品间的对比

**不适合**：产品结果展示（洗后效果应该用客观视角）、医疗/严肃场景、需要精确比例展示的步骤说明
