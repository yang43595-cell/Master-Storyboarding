# 资料摘要：告别AI画面翻车！3招写对提示词

> 一帆老师：AI 视频/图像生成总是把简单画面做崩（iPad 屏幕反了、学生背后出现学校）的根源是**提示词污染**——AI 把提示词拆成 token 逐个当作独立视觉任务去「摆到画面最显眼处」，而不是理解场景的现实逻辑。三招规避：**少写抽象词、少写否定词、少写自带模板的大词**，多写能被看见的具体画面。

## 核心主张

1. **提示词污染的机制**：AI 将提示词按 token 拆分，把每个词当作一个独立的视觉任务；它优先做的是「把每个词都摆到画面最显眼的位置」，而不是判断场景是否符合现实逻辑。例：「一个人在医院用 iPad 看剧」→ AI 会强行把 iPad 屏幕翻转过来让剧集内容朝向镜头。
2. **否定词天然弱**：AI 对「不要 X」这类否定信息理解很弱，拆分后最先抓到的是「学生 + 学校」等名词，所以「不要出现学校」反而更容易出现学校。对策是**说肯定词**（"一个学生在公园"），而不是说否定词。
3. **第 1 招：少写抽象词，多写视觉证据**。抽象感受词（高级感/松弛感/电影感）对 AI 太空洞，它会去套训练集中最常见的母版（高级感→西装/落地窗/好车；松弛感→咖啡/沙发/阳光）。要写成「一组能被看见的画面」。
4. **第 2 招：少写否定词，多写肯定结果**。AI 不擅长排除、更擅长执行；「不要下雨」改成「晴天后阳光照在地面，空气清透」，「不要夸张表情」改成「表情平静，嘴唇自然闭合，眼神放松」，「不要动漫风」改成「真实摄影质感，自然皮肤纹理，真实镜头光影」。
5. **第 3 招：少写自带模板的大词，多写具体的动作/空间/物体**。创业/约会/直播/庆祝这类词一出现，AI 就自动脑补一套固定场景（创业→西装/办公室/落地窗；约会→玫瑰/蜡烛/餐厅；直播→补光灯/麦克风/夸张表情）。要给更具体的场景切片。
6. **底层心法**：AI 生成画面「不是在执行你的想法，而是在生成它能看见的提示词」。你写得越抽象它越容易乱猜，写得越具体它越听话。**普通人写提示词是许愿抽卡，高手写提示词是在规划画面。**
