# 资料摘要：统一Ai视频画面风格只需要一张图（色卡）

> 小云雀AI 教学：用**一张色卡（color card）**锁定 AI 视频的视觉元素统一。核心主张——「视觉元素不统一」的本质是**颜色不统一**；色卡既能锁定所有资产的颜色，也能把整段画面的主色调约束住，从根源上解决视频前后色差。配套操作：借著名影视作品（《银翼杀手2049》）截参考图 → 用提示词生成色卡 → 用 Seedance 2.0 mini 生成视频。

### ① 色卡示例（约 0:07，S1）
- 色卡标题：`SMOGGED MEGASTRUCTURE - SODIUM HAZE PALETTE`，副标题 `Industrial dusk haze · 13 color system`。
- 13 色 HEX（示例）：`#0B0D0B #171812 #2A251A #2F3221 #58452A #6D5431 #6A6B3F #A88755 #899A65 #D0B47C #F0C26F #2A5B5C #5EA7A5`。
- 字幕：「所有资产的颜色」。
- 画面：顶部 4 张《银翼杀手》风格参考图拼贴为一组，连到色卡——示意「参考图 → 提取色卡」。

### ② 色卡示例 2 + 生成提示词（约 0:20-0:23，S3 / 0:37-0:41，S6）
- 色卡标题：`2049 - SCRAPYARD MEMORY FARM - ASHEN INDUSTRIAL PALETTE`，副标题 `Cold fog wasteland · scorched metal · muted warning accents · 13 color system`。
- 生成色卡提示词（元素 1 / 2 / 3）：
  - **元素 1（主标题与副标题）**：用干净的无衬线字体，主标题为黑色或近黑色；标题内容按参考图主题自动命名，格式具电影美术设定/世界观设定/视觉开发文档感，如 `[项目名称]·[场景 / 集数 / 主题]·[色彩系统名称]`。主标题下方一行更小的浅灰副标题，概括整体色彩气质，如 `[环境氛围描述]·[颜色数量] color system`。
  - **元素 2（画面中部一排横向矩形色块）**：从参考图提取核心颜色，按复杂度默认 10–15 个、**优先 13 个**；所有色块同一水平线、均匀间距、垂直居中；每块为干净纯色矩形、尺寸一致、边缘锐利；不能有渐变/阴影/描边/纹理/光泽/厚度/透视/立体效果；顺序从左到右形成色彩逻辑（环境主色与光照色 → 中间调与阴影色 → 材质色 → 强调色或特殊功能色）；每块给准确或近似准确的 HEX（无则按视觉估算生成可信 HEX）；每色必须单一纯色填充。
  - **元素 3（每个色块下方的两行小字）**：第一行对应 HEX 色值（干净等宽字体，深灰）；第二行是该颜色的**功能标签**（更小无衬线字体，中性灰；按颜色气质分析命名，不写颜色名而写其在画面中的作用，如 `暖光照射` `天空雾色` `皮革阴影` `金属暗面` `布料高光` `血色强调` `霓虹信号` `尘土中间调` `冷色反光`）。整体视觉要求：纯 2D 扁平化数字图形设计，非照片/实物色卡/纸张印刷/桌面摆放；风格精确、冷静、信息化、极简、专业，像电影美术圣经/色彩系统说明书/视觉开发参考表/设计系统文档；构图清晰、整齐、克制，强调色彩信息本身。

### ③ 生成色卡的提示词需求（约 0:24，S4）
- **必须避免**：摄影渲染、纸张纹理、桌面、阴影、景深、镜头虚化、胶片颗粒、写实材质、3D 渲染、色块上的光照效果、色块下方阴影、光泽表面、手绘感、水彩感、插画感、草图感、实物 mockup、真实世界物体模拟。
- **请最终输出一段完整、可直接用于图像生成的中文提示词。**
- **提示词中必须包含**：1. 画面比例与风格说明；2. 背景色；3. 标题与副标题；4. 色块数量；5. 每个色块的 HEX；6. 每个色块的功能标签；7. 扁平化、无虚影、无纹理、无阴影等限制条件。
- **不要解释你的分析过程，只输出最终生成用提示词。**
- 生成骨架示例：`一张干净的数字化色卡参考设计图，16:9 横向构图，纯 2D 扁平化平面设计美学，没有任何摄影元素，不是照片，不是实物拍摄，不是纸张印刷品，不是桌面摆放。背景为纯色中性冷灰白填充：#F1F0E8。背景完全平面化，无纹理、无阴影、无纸张质感、无桌面、无表面材质。画面只包含以下三个部分：…`（旁注「已思考 3m 57s」）。

## 核心主张

1. **视觉元素统一的本质是颜色统一**：AI 视频「前后色差」的根源在于各镜头资产颜色不一致；色卡既能锁定所有资产颜色，又能约束整段画面主色调，是根源层面的解法。
2. **色卡生成三步法**：
   - 第 0 步：先定**基本风格参考**——建议直接借用著名影视作品（如《银翼杀手2049》），在电影原片中截 2-3 张图。
   - 第 1 步：从截图中**提取色卡**——在参考图基础上「加上生成色卡的提示词」，输出一张含 13 色 HEX + 功能标签的扁平化色卡（元素1/2/3 提示词模板）。
   - 第 2 步：把参考图 + 色卡作为资产传入小云雀的 **Seedance 2.0 mini** 生成视频，锁定整片风格。
3. **Seedance 2.0 mini 定位**：2.0 对很多人性能过剩、费用较高；**mini 费用只有一半**，生成素材也足够可用，**适合做短剧和漫剧**。
4. **色卡是关键资产**：色卡成为「颜色规则」的载体，与角色卡、场景卡并列，作为整片色彩规则的具象（呼应「整片色彩规则」）。
