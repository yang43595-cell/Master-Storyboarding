# Kodak Essential Reference Guide—Lighting

> [!abstract] 来源结论
> 灯光反差是高、低照度之间的关系；主光与补光的比例影响形体塑造，也应在相邻镜头间维持可解释的连续性。

## 对提示词标准的支持

- 除“光从哪里来”外，还要说明暗部保留程度和明暗反差。
- 加光与减光都可控制反差；生成提示词可用“保留暗部细节”“压低环境杂散光”等可见结果表达。
- 连续视频或同场景多镜头必须区分应保持的灯光基线与由剧情触发的变化。

## 边界

资料讨论胶片与摄影实践；项目只吸收不依赖具体胶片参数的光比、塑形和连续性原则。
