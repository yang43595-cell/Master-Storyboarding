## 用途

视频生成时锁定真实产品使用步骤：

- 每段聚焦一个动作，近景/特写呈现"手 + 产品 + 容器"；
- 视频模型优势在**连续动作 + 状态渐变**（如：挤白管 → 挤金管 → 搅拌到绵密奶泡），比逐张静态分镜图更能传达过程感；
- 参考视频只负责**产品外观 + 动作流程**；**场景背景由生成提示词定**，不被视频原背景带偏。

## 使用逻辑（与产品资料一致）

开盒 → 掰白管 → 挤白管 → 掰金管 → 挤金管 → 搅拌发泡（至绵密奶泡）。

本批参考覆盖到「搅拌发泡」，未含涂抹/等待/擦除。创作不得改变双剂关系与真实使用顺序；**禁止单支产品直接对皮肤/毛孔出料**。
