# LLM 叙事规划能力研究

论文以因果成立、角色意图和戏剧冲突评估 LLM 的叙事规划。作者报告强模型能在小规模任务中生成因果基本成立的故事，但角色意图和复杂戏剧冲突仍是困难点。

本项目只采用有限结论：编导需要显式检查角色想要什么、阻力如何迫使行动以及选择产生什么后果；这不证明固定结构或自动评分能保证好故事。最终效果必须由项目案例验证。
