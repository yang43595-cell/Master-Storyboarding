# 短剧电影叙事规则

> 将原始口播文案视为隐含含义的素材库，构建微型电影叙事弧：建立 → 冲突 → 升级 → 揭示 → 解决 → 情绪收尾。

## 基本信息

- **来源**: 原始执行文件已转为薄指针后删除，知识本体见 [[concepts/01-叙事与对白/短剧电影叙事法则]]
- **定位**: 编导（creative-director）专用规则，解决"从口播到电影"的模式转换
- **适用范围**: 剧情短片、产品广告短片、AI 视频生成前的叙事设计

## 核心主张

1. **核心转换原则**：口播文案不是最终结构，而是素材库；每个场景必须有明确的戏剧功能
2. **叙事角色模型**：主角、障碍、假帮手、真帮手、见证者、叙述者六类角色驱动冲突
3. **对白三原则**：听起来像角色在说话、每场至少一句台词/反应、优先使用潜台词
4. **反应镜头优先**：人说什么不一定最重要，重要的是听者的反应；允许"抢反应"
5. **景别组合模板**：空间入场、对峙、揭秘、暧昧、群体压力、余韵收束六种高效模板
6. **护肤品行业边界**：避免医疗表述、使用干净隐喻、确保产品视觉稳定

## 关键数据

- 镜头时长参考：远景/全景 1.5-3.0s，中景/全身 1.0-2.0s，近景/半身 0.8-1.8s，特写/极特写 0.2-1.2s
- 六种景别组合模板，覆盖绝大多数叙事场景
