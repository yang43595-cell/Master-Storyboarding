# LLM 长故事一致性研究

该研究系统分析长故事生成中的一致性缺陷，说明人物、事实、时间和世界状态会在长文本中发生可检测的偏移。

本项目采用的执行结论是：交付下游前保留角色动机、场景起止状态、选择后果、空间事实和产品事实等稳定信息；审查应定位具体冲突，不以笼统的“可能不一致”制造返工。
