# 1x4三视图模板提示词

> 项目资产图生成步骤模板｜人物资产。本文用于在资产图助理阶段依次建立脸部资产、服装资产与人物 1×4 三视图；后续分镜只引用经用户确认并登记为有效的独立原图。

## 用途与边界

本页供 AI 或 Agent 在建立可复用的人物视觉资产时检索与引用。适用于先建立脸部资产、服装资产，再生成角色 1×4 三视图的工作流。

本页只定义提示词模板与资产关系，不替代具体项目的剧情、角色设定、产品参考图或生图工具选择。实际 PNG 原图必须保存在具体视频项目内；候选图与已确认资产的状态、路径和版本由项目 `asset_manifest.md` 维护。

## 资产链路

```text
脸部候选 → 用户确认脸部资产
服装候选 → 用户确认服装资产
已确认脸部资产 + 已确认服装资产 → 1×4 三视图候选
→ 用户确认 → 项目资产母版登记 → 下游分镜引用
```

人脸负责身份识别；服装负责款式、材质和配饰一致性；三视图只负责验证两者组合后的体型比例与服装结构。未经用户确认的图片只能是候选，不得作为正式母版或分镜输入。

## 模板一：人脸资产

```text
生成一张用于后续人物三视图识别的人脸身份参考图。

人物设定：【角色风格】，【性别与年龄感】，【族裔/地域观感（如需要）】，【脸型与骨相】，【发型、发色与发际线】。
五官特征：【眉眼特点】，【鼻部特点】，【嘴唇与嘴角特点】，【标志性辨识点】。
肤质：【肤色】，自然真实皮肤纹理，保留轻微正常瑕疵与毛孔细节，不油腻、不过度磨皮、不塑料感。
表情：自然放松、克制，中性微笑或平静直视镜头；眉眼、嘴角和面部肌肉自然，不夸张。
构图：3:4 竖向画布，单人正面、从头顶到锁骨的紧凑大头特写。完整保留头顶、发际线、脸部轮廓、下巴与颈部；头顶接近画面上缘，只留少量空白，下边缘止于锁骨下缘，完整展示锁骨，不向下延伸至胸部。脸部居中并作为视觉主体，双眼清晰完整可见，直视镜头，镜头与眼睛齐平。两侧肩部自然裁切，只保留颈肩连接处，不为展示完整肩宽而拉远镜头；不展示锁骨以下的胸部、手臂或半身。不强求额头至下巴占画面高度80%–90%，以完整头顶和锁骨位置同时入镜、脸部尽量大为准。画面内不出现任何衣服、领口、肩带或衣料，只展示头部、颈部和锁骨区域。参考照片中的服装不作为本张身份资产的保留项；即使原图是高领，也应生成无衣领遮挡的颈部与锁骨，未见区域只作自然保守补全，不展示胸部。纯白电商摄影背景，柔和均匀棚拍光，无强烈阴影。
风格：超写实专业人物摄影，真实自然，4K，高细节。
```

### 独立大头照审查要点

- 提示词须同时明确完整头顶、顶部少量留白、3:4竖图、下沿至锁骨下缘、两侧裁肩、画面无衣服和脸部为主体；不得写“头肩区域完整”“完整肩宽”或半身构图。
- 生成图逐项核对取景上下边界、脸部大小与左右肩部裁切；头顶或下巴被切、锁骨未完整入镜、出现衣服或领口、胸部和手臂过多或为了完整肩宽导致脸小，均需调整后再由用户确认。
- 参考服装不进入独立大头照；高领参考须去除画面内衣领遮挡，但取景仍止于锁骨，不能扩展成裸露上半身。本要求适用于独立大头照，不改变下文人物1×4第一格的专用构图。

```text

服装设定：【角色风格】，适用于【性别与年龄感】与【体型范围】。
服装组成：【上装版型、颜色、材质】；【下装/裙装版型、颜色、材质】；【鞋履】；【配饰】；【必须保留的制服标识或设计细节】。
服装气质：【例如现代城堡管家、现代粉色王室、皇家高级护理、女性科研专业制服】，结构可信、材质真实、细节精致，不儿童化、不廉价。

构图：16:9 横版，1×3 网格，纯白电商摄影背景，柔和均匀棚拍光。使用无头无脸人体展示模特或隐形人台，完整展示同一套服装：
1. 第一格：正面全身，清楚展示服装正面结构、鞋履和配饰。
2. 第二格：左侧全身，清楚展示侧面轮廓、层次与材质。
3. 第三格：背面全身，清楚展示背部剪裁、后摆与鞋履。

三格必须是同一件完整服装，颜色、版型、材质、纽扣、腰线、鞋履与配饰完全一致。超写实服装电商棚拍，4K，高细节。
```

## 模板三：人物 1×4 三视图

### 参考图顺序

- 图一：服装参考图；只用于服装版型、层级、材质、配色、鞋履和配饰。
- 图二：人脸参考图；只用于脸型、五官比例、肤色、发型和自然皮肤质感。

```text
你是一位专业影视人物摄影师。请以图一的服装为唯一服装参考、以图二的人脸为唯一身份参考，生成一张固定 16:9 横向画布的人物资产验证图。画布内部使用单行等宽 1×4 网格；1×4 只表示四格排布，不表示画布比例，禁止生成 4:1、超宽幅或其他非 16:9 画布。

角色设定：【角色风格】，【性别与年龄感】，【体型与比例】。
服装：严格还原图一的服装版型、层级、材质、配色、鞋履与配饰；【服装描述】。
身份：严格保持图二的人脸、脸型、五官比例、肤色与发型；【发型要求】。
肤质：【肤质要求】，真实皮肤纹理，柔和自然光泽，不塑料、不油腻、不过度磨皮。

四格必须在同一张 16:9 画布内从左到右等宽排列，不得新增第二行、额外格、嵌套小图或改变格序。四格内容固定为：
1. 第一格：正面高清头部特写，白色电商摄影背景；完整保留头顶、发型、脸部、耳部与颈部，构图下沿严格停在颈部与肩线交界，肩部只允许保留最少边缘；禁止出现胸口、上半身、手臂或半身构图，服装不得成为可识别的第二套造型；用于人脸识别与肤质验证，表情自然克制，直视镜头。
2. 第二格：正面全身服装三视图，从颈部以下构图，完全不出现头脸；双臂自然下垂，站姿标准，清楚展示正面服装结构。
3. 第三格：左侧全身服装三视图，从颈部以下构图，完全不出现头脸；站姿标准，清楚展示侧面轮廓与服装层次。
4. 第四格：背面全身服装三视图，从颈部以下构图，完全不出现头脸；站姿标准，清楚展示背部剪裁、后摆与鞋履。

整体为超写实、专业电商棚拍、纯白背景、均匀柔光、干净阴影、人物比例真实协调。【清晰度要求】。最终输出画布必须严格保持 16:9 横向比例；若实际尺寸不是 16:9，该结果判为不合格候选，不得进入人物母版。
```

## 字段填写原则

- 角色风格描述身份与职业，例如“现代城堡管家”，不取代服装的细节描述。
- 性别、年龄感和体型必须写明；体型描述应自然、具体且符合角色职业。
- 人脸模板优先锁定脸、发际线、肤质；服装模板优先锁定服装，不承担人脸识别。
- 第一格必须是从头顶到颈肩交界的高清头部特写，肩部只保留最少边缘，禁止出现胸口、上半身、手臂或半身构图；避免左格出现与右侧服装三视图不一致的可识别服装信息，第一格只锁定人脸、发型与肤质。
- 三视图的后三格必须从颈部以下构图、完全不出现头脸，避免低清脸部干扰模型对图二人脸资产的识别。
- 人物 1×4 资产板的最终画布固定为 `16:9` 横向比例；`1×4` 仅指画布内四格排布，不得改成 `4:1` 超宽画布。生成后必须核对实际宽高比，非 `16:9` 结果只能保留为不合格候选。
- 若某次生成涉及真实产品、包装、工具或道具，必须额外引用对应实物参考图，不能只凭文字描述。
