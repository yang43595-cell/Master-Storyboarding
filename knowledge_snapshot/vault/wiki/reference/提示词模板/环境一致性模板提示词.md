# 环境一致性模板提示词

> 项目资产图生成步骤模板｜场景资产。适用于同一环境需要正反打、俯拍、全景或连续动作的场景。核心不是以单张场景图强行控制所有机位，而是建立“场景母图 + 反向回望 + 45°斜俯视 + 90°正俯视”的四图参考组。

## 先填写场景身份卡

```text
场景编号：SC-XXX
场景名称：
场景类型：室内 / 室外 / 半室内 / 综合空间 / 微观机制世界
一句话空间定义：
时代、地理与文化来源：
季节、时间、天气：
场景用途与主要人物动线：
正式风格：
主光来源与方向：
入口、出口与通道：
功能分区：入口区 / 核心行动区 / 辅助区 / 后景区 / 服务或储物区
核心固定资产：编号、数量、位置、朝向、尺寸、材质、颜色
永久固定项：空间边界、结构、门窗、通道、家具、核心资产、光线、窗外环境、色彩和材质
本次剧情状态：
仅允许变化项：
```

## 四图场景锁定模板

### 图一：场景母图

```text
生成【SC-XXX 场景名称】的场景母图，用作后续所有机位的唯一空间锚点。

场景身份：【一句话空间定义】。
背景设定：【时代、地理与文化来源】；【季节、时间、天气】。
空间拓扑：【入口、出口、通道、功能分区与人物动线】。
核心固定资产：【逐项写出编号、数量、固定位置、朝向、尺寸比例、材质与颜色】。
风格与材质：【正式风格】；【墙面、地面、木材、金属、玻璃、布料等材质】。
光影：【主光来源与方向】；【辅助光来源】；【室内外亮度关系】。
当前状态：【状态编号与仅允许变化项】。
构图：超宽主视觉或空间骨架，高空间可读性，完整呈现入口、核心行动区、通道、后景与固定资产关系。
本图固定：空间边界、建筑结构、门窗、入口、通道、功能分区、固定资产的数量与位置、时间天气、光源方向、整体色彩与材质。
```

### 图二：反向平视回望图

```text
以图一【SC-XXX 场景母图】为唯一场景参考，生成同一环境的反向平视回望图。

目的：补全场景母图中未展示的背面环境布置，并保持同一空间的拓扑、比例、光线、材质和时间。
摄影机：位于图一主要视点的相对方向，以自然平视高度回望核心行动区。
必须保持不变：【永久固定项】。
当前状态：【状态编号与仅允许变化项】。
本次只改变：摄影机的位置、朝向与构图；完整解释图一背面的入口、后景、服务区或固定资产关系。
```

### 图三：45°斜俯视全景图

```text
以图一【SC-XXX 场景母图】为唯一场景参考，生成同一环境的 45°斜俯视全景图。

目的：补全平视图中不易识别的前后距离、功能分区、主要通道与固定资产相对位置。
摄影机：自然的高位 45°斜俯视，保留真实空间透视与屋顶结构，不移动家具或重排物品。
必须保持不变：【永久固定项】。
当前状态：【状态编号与仅允许变化项】。
本次只改变：摄影机高度、位置与构图；清楚展示入口区、核心行动区、辅助区、后景区及核心资产的远近关系。
```

### 图四：90°正俯视空间总纲图

```text
同时以图一【场景母图】、图二【反向平视回望图】和图三【45°斜俯视全景图】为参考，生成同一环境的 90°垂直正俯视空间总纲图。

目的：把整个场景的边界、功能分区、入口出口、通道、固定资产数量和相对位置统一锁定。
构图：正上方垂直俯视，空间完整可读，保持真实装修语言、材质、光线关系与场景风格。
必须保持不变：【永久固定项】。
当前状态：【状态编号与仅允许变化项】。
清楚呈现：【空间边界】、【入口出口】、【通道】、【功能分区】、【核心固定资产编号与位置】、【主要人物动线】。
```

## 后续镜头引用模板

```text
场景参考：图一为场景视觉与固定资产参考；图二负责反向环境关系；图三负责远近与分区关系；图四负责整体平面拓扑。
生成同一场景中的【本镜头内容】。
摄影机：【位置、高度、方向、画面关系】。
固定不变：空间边界、建筑结构、门窗、入口、通道、功能分区、核心资产的数量与位置、材质、颜色、时间天气、窗外环境与光源方向。
当前状态：【状态编号】；本次仅变化：【动作、人物位置、视线，或剧情明确的单一状态变化】。
风格与光影：延续场景参考图组的【正式风格】与【光影锁】。
```

## 使用顺序

1. 先生成图一并由用户确认；图二、图三都只引用图一。
2. 图四同时引用图一、图二、图三，作为空间总纲。
3. 四张均为独立原图，审查拼图只用于检查，不能替代场景资产。
4. 后续镜头按各参考图职责使用；同一背景连续动作优先以同一场景机位图作为动作锚点，只变化本镜动作层。
